# Facebook Groups Strategy — โพสต์ในกลุ่มยังไงให้ได้คน ไม่โดนแบน

ตัวเร่งผู้ติดตาม #4 จาก [[facebook-growth-playbook]] · กลุ่ม TCG คือที่ที่ลูกค้าตัวจริงอยู่ — แต่กฎเข้ม โพสต์ผิด = โดนลบ/แบน

---

## 🔎 หากลุ่มยังไง (ค้นด้วยคำเหล่านี้ใน FB)
> กลุ่มเปลี่ยน/มีใหม่ตลอด → ค้นเอง + เช็คว่า active (มีโพสต์ทุกวัน) ก่อนเข้า

**ตามเกม:**
```
One Piece Card Game Thailand / OPCG ไทย / วันพีชการ์ดเกม
Pokemon TCG Thailand / โปเกมอนการ์ด ไทย
Yu-Gi-Oh! ไทย / ยูกิโอ การ์ด
Dragon Ball Fusion World Thailand / ดราก้อนบอล การ์ด
Naruto Kayou / การ์ดนารูโตะ
```
**ตามกิจกรรม (ลูกค้าเป้าหมายสูง):**
```
ซื้อขายแลกเปลี่ยนการ์ด / ตลาดการ์ดเกม / มือสองการ์ด
อวดการ์ด / เปิดซองการ์ด / รีวิวการ์ด
```
**ตามพื้นที่ (ใกล้สาขา — โฆษณาตู้ได้ตรง):**
```
ของกิน-เที่ยว + ชื่อย่าน เช่น "บางแค" "พระราม 2" "ศาลายา" "เวสต์เกต"
กลุ่มชุมชน/ห้าง ในย่านที่มีตู้
```

## ✅ เลือกกลุ่มที่ดี (ก่อนเข้า)
- **Active** — มีโพสต์ใหม่ทุกวัน, คนคอมเมนต์จริง (ไม่ใช่กลุ่มร้าง/สแปมล้วน)
- **สมาชิกเยอะพอ** (หลักพันขึ้น) แต่ดู engagement สำคัญกว่าจำนวน
- **กฎเปิดให้โพสต์ขาย/แนะนำได้** — บางกลุ่มห้ามขายเด็ดขาด → กลุ่มนั้นเน้นแค่ "แบ่งปัน/อวด" เท่านั้น

## 🥇 กฎทองข้อเดียวที่สำคัญสุด
**อ่าน "กฎกลุ่ม" (Group Rules) ก่อนโพสต์ทุกครั้ง** — แต่ละกลุ่มกติกาต่างกัน (บางกลุ่มขายได้เฉพาะวัน/ต้องติดแท็ก [ขาย] / ห้ามลิงก์) ทำผิดกฎ = โดนลบ+เตะ

## 🛡️ วิธีโพสต์ไม่โดนแบน (Anti-ban)
1. **สร้างตัวตนก่อนขาย** — เข้าไปคอมเมนต์/ช่วยตอบ/อวดของ ~1 สัปดาห์ก่อน ให้คนคุ้นหน้า อย่าเพิ่งโพสต์ขายวันแรก
2. **Value-first, ขายทีหลัง** — โพสต์แบบ "แบ่งปัน/อวด/รีวิว" เป็นหลัก · เอ่ยถึงตู้แบบเนียน ไม่ยัดขาย
3. **ห้ามลิงก์ตรงในโพสต์** (กลุ่มส่วนใหญ่ลดการมองเห็น/แบนลิงก์) → ถ้าจะให้ลิงก์ ใส่ในคอมเมนต์ หรือบอก "ทักอินบ็อกซ์/ดูที่เพจ"
4. **ห้ามก๊อปข้อความเดียวกันโพสต์รัวหลายกลุ่มพร้อมกัน** — FB จับเป็นสแปมทันที → **เขียนใหม่ทุกกลุ่ม + เว้นเวลา** (เช่น 1-2 กลุ่ม/วัน)
5. **โพสต์รูป/คลิปของจริง** (เปิดซองหน้าตู้เรา) — ดูจริงใจ ไม่เหมือนโฆษณา
6. **ตอบทุกคอมเมนต์** ในโพสต์ตัวเอง — สร้างบทสนทนา = กลุ่มชอบ + คนตามมาที่เพจ
7. **อย่าแท็กมั่ว/ยิงอินบ็อกซ์หาสมาชิก** — โดนรายงานง่ายสุด

## ✍️ 3 สูตรโพสต์ในกลุ่ม (เนียน ได้ผล)
**A. อวด pull (ปลอดภัยสุด ทุกกลุ่มชอบ)**
```
เปิดซอง {เซ็ต} จากตู้กดมา ได้ {ชื่อการ์ด} 🎴🔥 ดวงโอเคไหมครับ?
[รูป/คลิปการ์ด] — ใครเปิดเซ็ตนี้ได้อะไรเด็ดบ้าง มาอวดกัน!
```
*(ไม่ขายตรง แต่คนถามเองว่ากดที่ไหน → ตอบในคอมเมนต์)*

**B. ถามความเห็น (ดึงคอมเมนต์)**
```
เซ็ต {A} กับ {B} แนะนำเปิดอันไหนดีครับ? กำลังลังเล 🤔
```

**C. รีวิว/แบ่งปันความรู้**
```
สรุปการ์ดเด่นเซ็ต {เซ็ต} ที่น่าตามล่า 👇 {3-4 ตัว}
เผื่อใครกำลังเปิดอยู่ ลองส่องดูครับ
```
> ทั้ง 3 แบบ ถ้ามีคนถาม "ซื้อที่ไหน" → ตอบ "กดได้ที่ตู้ DivisionX มี 11 สาขา ทักเพจ/แอดไลน์ดูได้ครับ" (ตอบในคอมเมนต์ ไม่ยัดในโพสต์)

## 🔁 Funnel: กลุ่ม → เพจ/LINE
คนเห็นโพสต์ในกลุ่ม → กดดูโปรไฟล์/เพจเรา → เจอเพจที่ตั้งค่าดี (pinned/cover) → Follow + แอดไลน์
→ **เพจต้องพร้อมก่อน** ([[fb-page-setup]]) เพราะคนจากกลุ่มจะมาส่อง

## 🏠 ขั้นสูง: สร้างกลุ่มของเราเอง
"DivisionX Card Community" — โพสต์ restock/แจกการ์ด/อวด pull ได้อิสระ ไม่ติดกฎใคร · สร้างฐานแฟนระยะยาว (ทำเมื่อมีฐานคนพอแล้ว)

## ⚠️ Ban triggers (อย่าทำ)
ก๊อปโพสต์รัวหลายกลุ่ม · ลิงก์ขายตรงทุกโพสต์ · ยิงอินบ็อกซ์/แท็กมั่ว · โพสต์ขายในกลุ่มที่ห้ามขาย · โพสต์ถี่เกินในกลุ่มเดียว
