# ระดับ 1 — ตั้งเวลาโพสต์ล่วงหน้า (Business Suite + LINE) · ไม่ต้องโค้ด

ตั้งโพสต์ FB/IG + LINE broadcast ล่วงหน้าทั้งสัปดาห์ทีเดียว · ใช้คู่กับ [[facebook-content-plan]] (ปฏิทิน) + [[content_queue ใน Telegram reminder]] (แคปชั่น)

---

## ส่วน A · Meta Business Suite (FB + Instagram)
**ตั้งเวลาโพสต์ฟีด + Reels ล่วงหน้า — ฟรี ในตัว**

1. เข้า **business.facebook.com** (หรือแอป **Meta Business Suite**) → เลือกเพจ DivisionX Card
2. เมนูซ้าย → **Planner** (หรือ "เนื้อหา" → ปฏิทิน)
3. กด **สร้างโพสต์ (Create post)**
   - เขียนแคปชั่น (ก๊อปจาก [[facebook-content-plan]] / content_queue) + แนบรูป/คลิป
   - **เลือก "ตั้งเวลา (Schedule)"** → เลือกวัน+เวลา → ยืนยัน
4. **Reels:** กด สร้าง → Reels → อัปคลิป → เลือก "ตั้งเวลา" ได้เหมือนกัน
5. **ทำทีเดียวทั้งสัปดาห์:** นั่งตั้งโพสต์ จ.–อา. ตามปฏิทิน รวดเดียว (เช่น ทุกเช้าวันจันทร์ตั้งของทั้งสัปดาห์)
6. ดูภาพรวมใน **Planner** → เห็นทั้งเดือนว่าวันไหนมีโพสต์/ว่าง

**เวลาแนะนำ:** ฟีด ~12:00 และ 18:00–21:00 · Reels เย็นศุกร์/เสาร์

> ⚠️ **Reels เปิดซองสด** ที่ถ่ายจริง → ตั้งเวลาทันทีหลังถ่ายได้ (ไม่ต้องรอ batch) เพราะเป็นคอนเทนต์สด

## ส่วน B · LINE OA Scheduler (broadcast)
**ตั้ง broadcast เช้า-เย็นล่วงหน้า**

1. **LINE Official Account Manager** → เมนู **Broadcast** → สร้างข้อความใหม่
2. เขียนข้อความ (ใช้จาก [[chukes01-content-pack]] LINE #1–#6) + แนบรูป + ปุ่ม
3. กด **"กำหนดเวลาส่ง"** → เลือกวัน+เวลา (เช้า 09:30 / เย็น 17:30) → บันทึก
4. ตั้งล่วงหน้าทั้งสัปดาห์ได้เลย
> ระวัง quota ข้อความของแพ็กเกจ LINE OA (ดู [[step1-line-oa-setup-design]] ข้อ A8)

## ส่วน C · จังหวะทำงาน (workflow รายสัปดาห์)
- **ทุกจันทร์เช้า (~30 นาที):** เปิด Business Suite + LINE → ตั้งโพสต์/broadcast ทั้งสัปดาห์ตามปฏิทิน
- **ระหว่างสัปดาห์:** ถ่าย live pull → ตั้งเวลา/โพสต์สดเพิ่ม + ตอบคอมเมนต์
- **Telegram reminder (ระดับ 2 — ทำแล้ว)** จะเตือนเช้า-เย็น + ส่งแคปชั่นของวันมาให้ → ถ้าลืมตั้ง batch ก็ยังโพสต์ทันได้

## ✅ เช็กลิสต์เริ่มใช้

- [ ] ตั้ง LINE broadcast เช้า/เย็นทั้งสัปดาห์
