# Execution Playbook — 3 ขั้น 8 สเต็ป (ลงลึก)

คู่มือลงมือจริงของแผนการตลาดเต็มระบบ ([[full-system-marketing-plan]]) · แต่ละสเต็ปมีครบ: ทำอะไร / ใครทำ / ใช้อะไร / เวลา / ต้นทุน / ได้อะไร / วัดผล / จุดระวัง

> **ตัวย่อบทบาท:** **MKT** = ผู้รับผิดชอบการตลาด (คุณ) · **CC** = คนทำคอนเทนต์/โซเชียล · **OPS** = ทีมเติมของ

# 🟢 ขั้นที่ 1 — วางรากฐาน (เดือน 1) · ทำทั้ง 11 ตู้ · เกือบฟรี

## สเต็ป 1 — เปิด LINE OA เต็มรูปแบบ + QR ทั้ง 11 ตู้
**🎯 เป้าหมาย:** เปลี่ยน LINE OA จาก "มีเฉยๆ" เป็นเครื่องมือดึง/รักษาลูกค้า + ทุกตู้มีช่องทางให้คนแอด

**✅ สิ่งที่ต้องทำ (ตามลำดับ):**
1. ตั้ง **Greeting message** (ตอนแอดเพื่อน) — แนะนำตู้ + ของฮิต OP + ลิงก์แผนที่ตู้
2. ตั้ง **Rich menu** 4 ปุ่ม: "ตู้อยู่ไหนบ้าง (แผนที่ 11 ตู้)" · "ของใหม่สัปดาห์นี้" · "วิธีกดซื้อ" · "โปรสมาชิก"
3. ตั้ง **Auto-reply keyword** — พิมพ์ "ตู้/สาขา" → ส่งรายชื่อ+แผนที่ · "OP/วันพีช" → ของที่มีตอนนี้
4. ออกแบบ **ป้าย QR** ใน Canva (1 แบบใช้ได้ทุกตู้ หรือใส่ชื่อตู้/ทำเล) — ข้อความ: *"แอดไลน์ รู้ก่อนใครเวลาเติม OP ใหม่ + โปรเฉพาะสมาชิก"*
5. พิมพ์ป้าย (standee/sticker) → **OPS ติดหน้าตู้ทั้ง 11 ตู้** ตามรอบลงตู้

**👤 ใคร:** CC (ตั้งค่า+ออกแบบ) · OPS (ติดป้าย) · MKT (อนุมัติข้อความ)
**🛠️ ใช้:** LINE OA Manager (ฟรี) · Canva · ร้านพิมพ์ป้าย
**⏱️ เวลา:** setup 3–5 วัน + ติดป้ายตามรอบเติม
**💰 ต้นทุน:** ป้าย ~300–800/ตู้ × 11 ≈ **3,000–9,000 (ครั้งเดียว)** · LINE OA: เช็คแพ็กเกจ (ดูจุดระวัง)
**📤 ได้อะไร:** LINE OA ใช้งานได้จริง + QR ครบ 11 ตู้
**📊 วัดผล:** ผู้ติดตามใหม่/สัปดาห์ · จำนวน QR scan
**⚠️ จุดระวัง:** LINE OA ฟรีจำกัดจำนวน broadcast/เดือน — ส่งเช้า+เย็น (2/วัน) × ผู้ติดตามที่โต = อาจเกิน free quota เร็ว → **วางแผนอัปเกรดแพ็กเกจ** ก่อนฐานโต

## สเต็ป 2 — เครื่องคอนเทนต์ FB / TikTok / กลุ่ม
**🎯 เป้าหมาย:** สร้าง demand ต่อเนื่อง (เปิดซองสด + แจ้งเติมของ) เกาะชุมชน One Piece

**✅ สิ่งที่ต้องทำ:**
1. ตั้ง **content calendar** (ใช้ [[chukes01-content-pack]] เป็นแม่แบบ ปรับชื่อตู้):
   - 3–4 คลิป **live pull/เปิดซองสด**หน้าตู้/สัปดาห์
   - **restock alert** ทุกครั้งที่เติมของเด่น
   - **อวดการ์ดหายาก**ที่ลูกค้ากดได้ (social proof)
2. ถ่ายคลิปหน้าตู้จริง (เน้น OP13/15/16 + กล่อง PRB)
3. โพสต์: **เพจ FB** + **กลุ่ม One Piece TCG** (เน้นคุณค่า ไม่ขายตรง) + **TikTok**
4. **reuse ข้ามแพลตฟอร์ม** — TikTok → Reels → FB (ถ่ายครั้งเดียวใช้ 3 ที่)

**👤 ใคร:** CC (หลัก) · MKT (อนุมัติทิศทาง)
**🛠️ ใช้:** มือถือ + ไฟ + ขาตั้ง · CapCut/Canva ตัดต่อ · content pack templates
**⏱️ เวลา:** ต่อเนื่อง (3–4 คลิป/สัปดาห์)
**💰 ต้นทุน:** เนื้อหา = ฟรี (เวลา) · อุปกรณ์ถ่าย ~**5,000 (ครั้งเดียว)**
**📤 ได้อะไร:** flow คอนเทนต์สม่ำเสมอ ทุกแพลตฟอร์ม
**📊 วัดผล:** reach · engagement · follower growth · คลิปไหนดันยอด/ทราฟฟิก
**⚠️ จุดระวัง:** กลุ่ม FB ส่วนใหญ่ห้ามขายตรง → โพสต์แบบโชว์ของจริง/แบ่งปัน เช็คกฎแต่ละกลุ่มก่อน

## สเต็ป 3 — แก้การจัดของทุกตู้ (sell-through · กันยอดรั่ว)
**🎯 เป้าหมาย:** ดึงคนมาแล้วต้องมีของให้ซื้อ — อุดยอดที่รั่วเพราะของหมด/จัดผิด (ฟรี ROI สูงสุด)

**✅ สิ่งที่ต้องทำ:**
1. **รัน sell-through analysis ทุกตู้** (แบบที่ทำ chukes01) — หา 3 อย่าง/ตู้:
   - SKU ฮิตหมดกลางวันไหม (เติมไม่ได้ตอนห้างเปิด)
   - SKU ขายดีที่ถูกถอดออก (เช่น PRB02 ที่ chukes01)
   - slot allocation เพี้ยน (ของช้ากินช่องเยอะ เบียดของขายดี)
2. ส่ง **OPS รายการแก้ต่อตู้** (ทำช่วงห้างปิด):
   - ไม่ปล่อย OP เรือธงว่าง → front-load capacity ก่อนพีคเย็น 19–21 น.
   - เติม SKU ขายดีที่ถูกถอดกลับ
   - rebalance slot: ลดของช้า เพิ่มของเร็ว
3. ใช้ระบบ **slot refill tracking** ที่มีอยู่ ([[project_slot_refill_tracking_design]]) ติดตามว่าเติมจริงเท่าไหร่

**👤 ใคร:** MKT (วิเคราะห์ จาก dashboard) · OPS (ลงมือเติม/จัด)
**🛠️ ใช้:** Dashboard ยอดขาย · sell-through script · slot refill tracking
**⏱️ เวลา:** วิเคราะห์ 1–2 วัน + ปรับตามรอบเติมปกติ
**💰 ต้นทุน:** **ฟรี** (แค่จัดของให้ฉลาดขึ้น)
**📤 ได้อะไร:** รายการ quick win ต่อตู้ + planogram ที่ปรับแล้ว
**📊 วัดผล:** เวลา sell-through SKU ฮิต · บิล/วัน เพิ่ม · ยอด SKU ที่เติมกลับ
**⚠️ จุดระวัง:** เติมได้เฉพาะห้างปิด (หลัง 22:00–ก่อน 10:00) → ต้อง "เติมเผื่อ" ทั้งวัน ไม่ใช่เติมตอนหมด

## สเต็ป 4 — ตั้ง Baseline + ระบบวัดผล
**🎯 เป้าหมาย:** มีจุดอ้างอิงก่อนเริ่ม เพื่อพิสูจน์ว่าการตลาดได้ผลจริง (กรรมการเชื่อ)

**✅ สิ่งที่ต้องทำ:**
1. **จด baseline ทุกตู้** ณ วันเริ่ม: ยอด/วัน · บิล/วัน · AOV (มีจาก gap_analysis แล้ว — chukes01 19.5k/62บิล/AOV311 ฯลฯ)
2. **ตั้งเป้า tiered ต่อตู้** (ดาวเด่น 30k · แข็งแรง 20–25k · กลาง 12–15k · อ่อน 8–12k)
3. กำหนด **metric ที่จะติดตาม:** ยอด/ตู้ · บิล/วัน · ROAS · CAC · follower LINE · QR scan · sell-through
4. ตั้ง **รอบรายงาน:** สรุปรายสัปดาห์ (ภายใน) + รายเดือน (กรรมการ)

**👤 ใคร:** MKT
**🛠️ ใช้:** Dashboard · gap_analysis.mjs (รันซ้ำได้)
**⏱️ เวลา:** 1 วัน
**💰 ต้นทุน:** ฟรี
**📤 ได้อะไร:** ตาราง baseline + เป้าต่อตู้ + รอบรายงานที่ตกลงกัน
**⚠️ จุดระวัง:** จด baseline **ก่อน**เริ่มยิงคอนเทนต์/ads เสมอ ไม่งั้นวัด lift ไม่ได้

# 🔵 ขั้นที่ 2 — ทดสอบโฆษณาแบบเจาะจุด (เดือน 1–2) · โซนบางแค

## สเต็ป 5 — ยิง Ads + KOL โซนบางแค (Test Cluster)
**🎯 เป้าหมาย:** พิสูจน์ว่า "จ่ายเงินดึงคน" คุ้มไหม ที่โซนเดียวก่อน (chukes01 + wwv05 ซีคอนบางแค)

**ทำไมบางแค:** chukes01 ฐานแกร่งสุด (พิสูจน์ดีมานด์แล้ว) + wwv05 อยู่โซนเดียวกัน → ยิง ads ทีเดียวคุ้ม 2 ตู้ · ได้เทียบ "ตู้แกร่ง vs ตู้อ่อน" ในโซนเดียว

**✅ สิ่งที่ต้องทำ:**
1. **Geo-targeted ads** (FB/IG/TikTok): รัศมีเดอะมอลล์บางแค + ซีคอนบางแค + interest One Piece/TCG/อนิเมะ
2. งบทดสอบ **~300–500 บาท/วัน** · ครีเอทีฟ = คลิป live pull + "restock OP ที่ตู้บางแค"
3. **retarget** คนที่ดูคลิป/เข้าเพจ
4. จ้าง **micro-KOL สาย One Piece 1–2 ราย** (1–5 หมื่นฟอลฯ) ไลฟ์เปิดซองหน้าตู้จริง + **โค้ด/ลิงก์เฉพาะ** เพื่อวัดว่าใครพาคนมา
5. ใช้ **UTM/โค้ด/timing** แยกผล ads ออกจาก organic

**👤 ใคร:** MKT (จัดการ ads + ดีล KOL) · CC (ครีเอทีฟ)
**🛠️ ใช้:** FB/TikTok Ads Manager · KOL · content ที่มี
**⏱️ เวลา:** **3–4 สัปดาห์** (ให้ข้อมูลพอตัดสิน)
**💰 ต้นทุน:** ads ~9–15k + KOL ~3–8k = **~15–23k** (อยู่ในงบเฟส 1)
**📤 ได้อะไร:** แคมเปญรันจริง + ชุดข้อมูล ROAS โซนบางแค
**📊 วัดผล:** ROAS · ยอดตู้บางแค vs baseline · CAC · follower เพิ่ม · KOL คนไหนเวิร์ก
**⚠️ จุดระวัง:** อย่าตัดสินเร็วเกิน (ต้อง 3–4 สัปดาห์) · ระวังช่วงปล่อยเซ็ตใหม่ทำให้ตัวเลขเด้ง (แยก seasonal ออก)

## สเต็ป 6 — วัด ROAS → ตัดสินใจ Go / No-Go
**🎯 เป้าหมาย:** รู้ชัดว่าคุ้มไหม ก่อนขยายงบ (หัวใจของ "ลงตามผล")

**✅ สิ่งที่ต้องทำ:**
1. คำนวณ **ROAS** = ยอดที่เพิ่มขึ้น (vs baseline) ÷ ค่า ads
2. คำนวณแบบ **กำไรจริง** = (กำไรขั้นต้นที่เพิ่ม − ค่าธรรมเนียม Ksher) vs ค่าใช้จ่ายการตลาด ([[project_payment_gateway]])
3. ดู **CAC** (ต้นทุนได้ลูกค้า 1 คน) + **payback** (กี่วันคืนทุน)
4. ตัดสิน:
   - ✅ **คุ้ม (ROAS เป็นบวกชัด)** → ขยายไปโซนถัดไป (สเต็ป 7)
   - ⚠️ **ก้ำกึ่ง** → ปรับครีเอทีฟ/กลุ่มเป้าหมาย/KOL แล้วทดสอบรอบ 2
   - ❌ **ไม่คุ้ม** → หยุด ads โซนนั้น เก็บเฉพาะ organic

**👤 ใคร:** MKT
**🛠️ ใช้:** Dashboard · ตาราง baseline
**⏱️ เวลา:** 2–3 วัน (หลังแคมเปญครบ 3–4 สัปดาห์)
**📤 ได้อะไร:** รายงาน go/no-go + บทเรียน (creative/KOL/กลุ่มไหนเวิร์ก)
**⚠️ จุดระวัง:** กำหนด **เกณฑ์ ROAS ขั้นต่ำ ไว้ล่วงหน้า** (เช่น คืนทุน + กำไร) — ไม่ใช่ตัดสินด้วยความรู้สึก

# 🟣 ขั้นที่ 3 — ขยายสูตรที่ชนะ (เดือน 3+) · ทั้งฟลีต

## สเต็ป 7 — ขยายไปโซนอื่น ทีละโซน
**🎯 เป้าหมาย:** เอาสูตรที่พิสูจน์แล้วจากบางแค ขยายอย่างมีระบบ (ไม่เผาเงินพร้อมกันหมด)

**✅ สิ่งที่ต้องทำ:**
1. **ลำดับการเปิดโซน** (เลือกจากฐานยอด + ความหนาแน่นทำเล):
   - โซน 2: **พระราม 2** (chukes02 + wwv06)
   - โซน 3: **เหนือ/ออก** (wwv01 รามอินทรา + wwv02 บางกะปิ + chukes03 พระราม9)
   - โซน 4: **ตะวันตก** (wwv04 เวสต์เกต + wwv07 เวสต์วิลล์ + wwv03 ศาลายา)
   - โซน 5: **ชลบุรี** (chukes04 — เดี่ยว)
2. ทำซ้ำ **สเต็ป 5–6 ต่อโซน** (ads geo + KOL local + วัด ROAS)
3. ปรับครีเอทีฟตามทำเล (เช่น ศาลายา = ม.มหิดล กลุ่มนักศึกษา)
4. เปิดโซนถัดไป **เฉพาะเมื่อโซนก่อน ROAS เป็นบวก**

**👤 ใคร:** MKT + CC (อาจต้องเพิ่มคน/จ้าง freelance เมื่อสเกล)
**🛠️ ใช้:** เหมือนสเต็ป 5 ทำซ้ำต่อโซน
**⏱️ เวลา:** ~1 โซน/เดือน (เดือน 3 เป็นต้นไป)
**💰 ต้นทุน:** **งบเฟส 2: 80–120k/เดือน** (กระจายตามจำนวนโซนที่ active)
**📤 ได้อะไร:** หลายโซนรันพร้อมกัน + ROAS ต่อโซน
**📊 วัดผล:** ยอดต่อโซน vs baseline · ROAS รวม · ยอดฟลีตรวม
**⚠️ จุดระวัง:** อย่าเปิดทุกโซนพร้อมกัน — ขยายตาม cashflow/ROAS · ตู้อ่อนบางตู้อาจต้องการ "ของ/ทำเล" ไม่ใช่แค่ ads (ถ้า ads ไม่ขยับ = ปัญหา traffic ทำเล)

## สเต็ป 8 — Loyalty (สมาชิก/สะสมแต้ม) + Event
**🎯 เป้าหมาย:** เปลี่ยนคนซื้อครั้งเดียว → ลูกค้าประจำ + ทำตู้เป็น "หมุดหมาย" ของนักสะสม

**✅ สิ่งที่ต้องทำ:**
1. **LINE Loyalty:**
   - สะสมแต้ม/คูปอง · สิทธิ์ "รู้ restock ก่อนใคร" · ของสมนาคุณสมาชิก
   - ดึง repeat (รีเซลเลอร์ + นักสะสมซื้อซ้ำสูง)
2. **Event/Activation:**
   - **restock party** วันปล่อยเซ็ต OP ใหม่ (นัดเปิดซองหน้าตู้)
   - mini tournament / trade day · collab ร้านการ์ดในห้าง
   - ทำ **ตู้เด่นแต่ละโซน** เป็น destination
3. **ปฏิทิน restock อิงวันปล่อยเซ็ต OP 2026** — sync รอบเติม + คอนเทนต์ countdown กับวันจริง

**👤 ใคร:** MKT + CC + พาร์ทเนอร์ (ร้านการ์ด/KOL)
**🛠️ ใช้:** LINE OA loyalty features · งาน event
**⏱️ เวลา:** เดือน 3+ (เมื่อฐาน follower/ลูกค้าโตพอ)
**💰 ต้นทุน:** **งบเฟส 3 (ผูกกับยอด)** — reinvest จากกำไรที่เพิ่ม
**📤 ได้อะไร:** ระบบ retention + ปฏิทินอีเวนต์ประจำ
**📊 วัดผล:** repeat purchase rate · ยอดจากสมาชิก · คนร่วมอีเวนต์ → ยอดวันงาน
**⚠️ จุดระวัง:** ทำเมื่อฐานลูกค้าโตพอ (ทำเร็วไป = ไม่มีคนใช้) · loyalty ต้องคุ้ม margin (อย่าแจกจนกำไรหด)
