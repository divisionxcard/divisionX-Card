# สเต็ป 1 ลงลึก — LINE OA: ตั้งค่าทีละขั้น + แนวทางออกแบบกราฟฟิก

คู่มือลงมือจริงของ [[execution-playbook-8steps]] สเต็ป 1 · ทำตามได้ทีละคลิก + สเปคไฟล์ออกแบบครบ (ส่งดีไซเนอร์/ทำใน Canva เองได้)

---

# ส่วน A · ตั้งค่า LINE OA ทีละขั้น

## A0. เตรียมตัว / เข้าระบบ
- เข้า **LINE Official Account Manager**: `manager.line.biz` (เว็บ) หรือแอป LINE OA
- ใช้บัญชีที่เป็นเจ้าของ OA อยู่แล้ว (เรามี OA แล้ว → ข้ามขั้นสมัคร)
- พิจารณายืนยันเป็น **Verified Account** (โล่สีน้ำเงิน) — เพิ่มความน่าเชื่อถือ + ขึ้นค้นหาใน LINE ได้ (สมัครฟรี รออนุมัติ)

## A1. โปรไฟล์พื้นฐาน (Home > Settings > Account settings)
| ช่อง | ใส่อะไร |
|---|---|
| ชื่อบัญชี | DivisionX Card (ตู้กดการ์ดสะสม) |
| รูปโปรไฟล์ | โลโก้ DivisionX (640×640px) |
| รูปปก (status) | ภาพการ์ด OP + ตู้ + ข้อความ "ตู้กดการ์ดในห้าง" (1080×878px) |
| คำอธิบาย | "ตู้กดการ์ดสะสม One Piece/Pokemon · 11 สาขาในห้าง · แอดรับแจ้งรอบเติม+เซ็ตใหม่" |
| ลิงก์/ที่ตั้ง | ลิงก์เพจ FB + รายชื่อสาขา |

## A2. Greeting Message (ข้อความต้อนรับตอนแอดเพื่อน)
ตั้งที่ **Home > Greeting messages** · ใส่ข้อความ + รูป + ปุ่ม:
```
🎴 ยินดีต้อนรับสู่ DivisionX Card!
ตู้กดการ์ดสะสม One Piece / Pokemon ใน 11 สาขา

✅ รู้ก่อนใครเวลาเติม OP ใหม่ + เซ็ตใหม่มาถึง
✅ โปรเฉพาะสมาชิก LINE
📍 ดูสาขาใกล้คุณ → กดเมนูด้านล่าง

พิมพ์ "ตู้" = ดูสาขาทั้งหมด · "OP" = ของที่มีตอนนี้
```
(แนบรูป welcome 1040×1040 + ปุ่มลิงก์ "ดูสาขาทั้งหมด")

## A3. Rich Menu (เมนูล่างถาวร) — Home > Rich menus
**Layout แนะนำ: แบบใหญ่ 6 ช่อง (2 แถว × 3 คอลัมน์) ขนาด 2500×1686px**

| ช่อง | ไอคอน/ข้อความ | ปลายทางเมื่อกด |
|---|---|---|
| 1 (บนซ้าย) | 📍 สาขาทั้งหมด | ลิงก์/รูปแผนที่ 11 ตู้ |
| 2 (บนกลาง) | 🔥 ของใหม่สัปดาห์นี้ | ข้อความ + รูปของที่เพิ่งเติม |
| 3 (บนขวา) | 🎴 วิธีกดซื้อ | คลิป/รูปสอนกดตู้ |
| 4 (ล่างซ้าย) | 🎁 โปรสมาชิก | คูปอง/สิทธิพิเศษ |
| 5 (ล่างกลาง) | 📅 เซ็ตใหม่เร็วๆนี้ | ปฏิทินปล่อยเซ็ต OP |
| 6 (ล่างขวา) | 💬 แชทสอบถาม | เปิดแชท |

> เริ่มง่าย: ถ้ายังไม่พร้อม 6 ช่อง ใช้ **แบบเล็ก 3 ช่อง (2500×843px)**: สาขา · ของใหม่ · โปรสมาชิก ก่อนก็ได้

## A4. Auto-response / Keyword (Home > Auto-response messages)
ตั้ง **โหมดตอบอัตโนมัติ** + keyword:

| ลูกค้าพิมพ์ | ระบบตอบ |
|---|---|
| ตู้ / สาขา / ที่ไหน | รายชื่อ 11 สาขา + แผนที่ + เวลาเปิด |
| OP / วันพีช | "ตอนนี้มี OP13/15/16 + กล่อง PRB ทุกสาขา 🔥 ดูสต็อกล่าสุด..." |
| ราคา | ตารางราคาซอง/กล่องคร่าวๆ |
| เติม / restock | "เราเติมของทุกวัน! แอดไว้รับแจ้งรอบเติมเช้า-เย็น" |

## A5. Broadcast (ส่งข้อความหาทุกคน) — Home > Broadcast
- ใช้ **คอนเทนต์จาก** [[chukes01-content-pack]] (LINE #1–#6)
- **ตั้งเวลาล่วงหน้า (Schedule)**: เช้า **09:30** (#เติมของเช้า) + เย็น **17:30** (#รีมายด์พีคเย็น) — ตั้งทีเดียวทั้งสัปดาห์ได้
- **Segment (เมื่อฐานโต):** ส่งเฉพาะกลุ่มสนใจ/โซน เพื่อประหยัด quota + ตรงกลุ่ม
- ใส่รูป + ปุ่ม CTA ทุกครั้ง (ดูสเปครูป B4)

## A6. Card Message / Coupon
- **Card message** (การ์ดเลื่อนได้) — โชว์ของใหม่หลายตัว/สาขาในข้อความเดียว
- **Coupon** — สร้างคูปองสมาชิก (เช่น "สะสมครบ X แถมซอง") ใช้ในสเต็ป 8 loyalty

## A7. Admin & สิทธิ์ (Settings > Permission management)
- เพิ่ม **CC (คนคอนเทนต์)** เป็น admin/operator · MKT เป็น admin หลัก
- แยกสิทธิ์: ใครโพสต์ได้ ใครเห็นสถิติ

## A8. แพ็กเกจ / Message Quota — ⚠️ ตัดสินใจก่อนฐานโต
- LINE OA คิดเงินตาม **จำนวนข้อความ broadcast/เดือน** (free quota → เกินแล้วซื้อเพิ่ม/อัปแพ็กเกจ)
- ส่ง 2 ครั้ง/วัน × 30 วัน × จำนวนผู้ติดตาม = โตเร็วมาก → **เช็คแพ็กเกจปัจจุบันของไทย** (Free/Basic/Pro) แล้ววางงบส่วนนี้ไว้
- ประหยัด quota: ใช้ **segment** (ไม่ส่งหาทุกคนทุกครั้ง) + เน้นข้อความที่ทำให้คนซื้อจริง

## A9. สถิติที่ต้องดู (Insight)
ผู้ติดตามใหม่/หลุดตาม · อัตราเปิดอ่าน broadcast · คลิก CTA · เทียบกับยอดขายตู้ (ผ่าน dashboard ของเรา)

# ส่วน B · แนวทางออกแบบกราฟฟิก (Design System + สเปคไฟล์)

## B0. Design System (ใช้ร่วมทุกชิ้น — LINE + FB + สไลด์ ให้แบรนด์เป็นหนึ่งเดียว)
**โทน:** พรีเมียม + การ์ดสะสม + พลังเปิดซอง (FOMO) — ไม่ใช่ตู้กดทั่วไป

**สี (เหมือนสไลด์นำเสนอ):**
| สี | โค้ด | ใช้ |
|---|---|---|
| น้ำเงินเข้ม | `#0d1424` / `#131c30` | พื้นหลังหลัก |
| ทอง | `#f6b73c` / `#ffd479` | เน้น/ปุ่ม/หัวข้อ (พรีเมียม) |
| เขียวมิ้นต์ | `#46e0b0` | accent รอง/ป้าย "ใหม่" |
| ขาวนวล | `#eef2f9` | ตัวอักษรบนพื้นเข้ม |

**ฟอนต์:** หัวข้อ = **Prompt** (หนา) · เนื้อหา = **Noto Sans Thai** (อ่านง่าย) — ฟรีทั้งคู่จาก Google Fonts

**โทนภาพถ่าย:** การ์ด/ซองคมชัด พื้นเรียบ แสงดี · ภาพ live pull = พลัง สด จริง · มีโลโก้มุมทุกชิ้น

## B1. สเปคไฟล์ทุกชิ้น (ขนาดจริง — ส่งดีไซเนอร์ได้เลย)
| ชิ้นงาน | ขนาด (px) | ใช้ที่ไหน |
|---|---|---|
| โลโก้/รูปโปรไฟล์ | 640 × 640 | LINE profile, FB, มุมทุกกราฟฟิก |
| รูปปก LINE | 1080 × 878 | หน้าโปรไฟล์ OA |
| Rich menu ใหญ่ | 2500 × 1686 | เมนูล่าง LINE (6 ช่อง) |
| Rich menu เล็ก | 2500 × 843 | เมนูล่าง LINE (3 ช่อง) |
| รูป welcome/broadcast | 1040 × 1040 | greeting + broadcast |
| Card message | 1040 × 1040 | การ์ดเลื่อน |
| ป้าย QR หน้าตู้ | A5 (148×210mm) / A4 | ติดหน้าตู้จริง |
| โพสต์ FB/IG | 1080 × 1080 | เพจ/กลุ่ม |
| TikTok/Reels | 1080 × 1920 | คลิปแนวตั้ง |

## B2. Rich Menu — แนวทางออกแบบ
- พื้นน้ำเงินเข้ม + เส้นแบ่ง 6 ช่องบางๆ สีทอง
- แต่ละช่อง: **ไอคอนใหญ่ + ข้อความสั้น** (เช่น 📍 + "สาขา")
- ช่อง "ของใหม่" / "เซ็ตใหม่" ใส่ป้าย "NEW" สีเขียวมิ้นต์
- โลโก้เล็กมุมบน · อย่ายัดข้อความเยอะ (นิ้วกดบนมือถือ ต้องชัด)

## B3. ป้าย QR หน้าตู้ — สำคัญสุด (จุดเปลี่ยนคนเดินผ่าน → ผู้ติดตาม)
**Layout (แนวตั้ง A5):**
```
┌─────────────────────┐
│  [โลโก้ DivisionX]   │
│                     │
│  แอดไลน์ รู้ก่อนใคร! │ ← หัวใหญ่ ฟอนต์ Prompt สีทอง
│  🎴 รอบเติม OP ใหม่   │
│  🎁 โปรเฉพาะสมาชิก    │
│                     │
│   [ QR code ใหญ่ ]   │ ← ใหญ่ สแกนง่ายจากระยะยืน
│   สแกนเลย @divisionx │
│                     │
│  พื้นน้ำเงิน+ทอง      │
└─────────────────────┘
```
- **QR ต้องใหญ่** (สแกนจากระยะยืนหน้าตู้) · contrast สูง (QR เข้มบนพื้นอ่อน หรือกลับกัน)
- ข้อความ benefit ชัด (ทำไมต้องแอด) ไม่ใช่แค่ "แอดเรา"
- วัสดุ: สติกเกอร์กันน้ำ/อะคริลิคตั้งโต๊ะ ทนการใช้งานในห้าง

## B4. Broadcast / โพสต์ — template ที่ทำซ้ำได้
ทำ **template 4 แบบใน Canva** (เปลี่ยนแค่รูป/ข้อความ ใช้ซ้ำทุกวัน):
1. **เติมของเช้า** — พื้นสว่าง ☀️ + "เติมสดเช้านี้" + รูป OP
2. **พีคเย็น** — โทนเย็น 🌆 + "แวะก่อนกลับบ้าน"
3. **ของใหม่/restock** — ป้าย "NEW" เขียวมิ้นต์ + รูปของ
4. **เซ็ตใหม่/countdown** — 🚨 ตัวเลขนับถอยหลังใหญ่ + ชื่อเซ็ต

ทุก template: โลโก้มุม · สี/ฟอนต์ตาม design system · ปุ่ม CTA ("ดูสาขา")

## B5. เครื่องมือ + วิธีทำเอง (ถ้าไม่จ้างดีไซเนอร์)
- **Canva** (ฟรี) — มี template LINE rich menu/โพสต์สำเร็จ ปรับสี/ฟอนต์ตาม B0
- ตั้ง **Brand Kit ใน Canva**: ใส่สี (#0d1424/#f6b73c/#46e0b0) + ฟอนต์ (Prompt/Noto Sans Thai) + โลโก้ → ทุกชิ้นคุมโทนอัตโนมัติ
- ทำ template ครั้งเดียว → duplicate ใช้ซ้ำ (CC ทำเองได้ ไม่ต้องพึ่งดีไซเนอร์ทุกครั้ง)
- ถ่ายภาพสินค้า: มือถือ + ไฟ + พื้นเรียบ (ดำ/ขาว) ให้การ์ดเด่น

## B6. Checklist ส่งงานออกแบบ (ทำเอง/จ้าง)
- [ ] โลโก้ไฟล์ความละเอียดสูง (PNG พื้นใส) — *มีไหม? ถ้ามีส่งมา จะได้ฝัง*
- [ ] รูปโปรไฟล์ 640×640 + ปก 1080×878
- [ ] Rich menu 2500×1686 (6 ช่อง) + ปลายทางแต่ละปุ่ม
- [ ] ป้าย QR หน้าตู้ A5 (เวอร์ชันพิมพ์)
- [ ] Broadcast template 4 แบบ
- [ ] Brand Kit ใน Canva (สี/ฟอนต์/โลโก้)
