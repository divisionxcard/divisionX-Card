กดครั้งเดียว → ขึ้นเพจพร้อมรูป → บันทึกลิงก์โพสต์กลับเข้าระบบ

เอกสารนี้คือขั้นตอนที่ **เจ้าของต้องทำเอง** (ผมทำแทนไม่ได้ เพราะต้องล็อกอินบัญชี Facebook จริง)

## ขั้นตอน (ครั้งเดียวจบ ~15 นาที)

### 1 · สร้างแอปบน Meta

1. เข้า **developers.facebook.com** → *My Apps* → **Create App**
2. ชื่ออะไรก็ได้ เช่น `DivisionX Poster` · ประเภทเลือกที่มี **Facebook Login for Business**
3. เข้าแอป → **Settings → Basic** → จดไว้ 2 ค่า
   - **App ID**
   - **App Secret** (กด Show)
4. ปล่อยให้แอปอยู่โหมด **Development** — อย่ากด Switch to Live เพราะไม่จำเป็น

### 2 · ขอ token ชั่วคราวจาก Graph API Explorer

1. เข้า **developers.facebook.com/tools/explorer**
2. มุมขวาบน เลือก **แอปที่เพิ่งสร้าง**
3. ช่อง *User or Page* เลือก **User Token**
4. กด **Add a Permission** ติ๊กให้ครบ 4 ตัว:
   ```
   pages_show_list
   pages_manage_posts
   pages_read_engagement
   pages_manage_engagement
   ```
5. กด **Generate Access Token** → ล็อกอิน → เลือกเพจ **DivisionX Card** → อนุญาต
6. ก๊อป token ที่ได้ (ยาวมาก) — **อันนี้อายุแค่ 1-2 ชม.** ยังใช้จริงไม่ได้

### 3 · แลกเป็น token ที่ไม่มีวันหมดอายุ

บนเครื่องตัวเอง ที่โฟลเดอร์โปรเจกต์:

```bash
node scripts/fb-token.mjs <APP_ID> <APP_SECRET> <TOKEN_ที่ก๊อปมา>
```

สคริปต์จะแลก 2 ต่อให้ (token สั้น → token ยาว 60 วัน → page token) แล้วพิมพ์ออกมาแบบนี้:

```
── DivisionX Card
   FB_PAGE_ID=1234567890
   FB_PAGE_ACCESS_TOKEN=EAAG...
   สิทธิ์โพสต์: ✅ มี   token: ✅ ไม่มีวันหมดอายุ
```

> ถ้าบรรทัด token ไม่ขึ้น `✅ ไม่มีวันหมดอายุ` **อย่าเพิ่งใช้** — แปลว่าแลกไม่ครบขั้น
> ให้ทำข้อ 2 ใหม่แล้วรันสคริปต์ทันที (token ต้นทางหมดอายุไปก่อนได้)

### 4 · ใส่ค่าเข้าระบบ

**บนเครื่อง** — เพิ่มใน `deploy/.env.local`
```env
FB_PAGE_ID=1234567890
FB_PAGE_ACCESS_TOKEN=EAAG...
```

**บนเว็บจริง** — Vercel → โปรเจกต์ → *Settings → Environment Variables*
เพิ่ม 2 ตัวเดียวกัน (Production + Preview) แล้ว **Redeploy**

### 5 · รัน migration

เอา `backend/database/migrations/065_marketing_content_post_link.sql`
ไปรันใน **Supabase → SQL Editor** (เพิ่มคอลัมน์ `post_id` / `post_url`)

### 6 · เช็กว่าติดแล้ว

เปิด `/marketing` → โซน **รอโพสต์** ต้องขึ้นว่า
*“กด ‘โพสต์ขึ้นเพจ’ เพื่อยิงขึ้น **DivisionX Card** ได้เลย”*
ถ้ายังขึ้นกล่องเทาว่ายังต่อไม่ได้ ในกล่องจะบอกสาเหตุตรง ๆ ว่าติดตรงไหน

## ระบบกันพลาดที่ใส่ไว้

โพสต์ขึ้นเพจสาธารณะแล้ว **ลบจากหน้าเว็บไม่ได้** จึงกันไว้หลายชั้น:

| ชั้น | กันอะไร |
|---|---|
| กล่องยืนยันก่อนโพสต์ | โชว์แคปชั่น + บอกว่ามีรูปไหม ก่อนกดจริง |
| `post_id` ในตาราง | เคยโพสต์แล้วยิงซ้ำไม่ได้ (Facebook **ไม่กันซ้ำให้** — ยิง 2 ครั้งได้ 2 โพสต์) |
| เช็กสถานะ | ต้อง `approved` ก่อน ยิง API ตรงข้ามขั้นไม่ได้ |
| เช็กช่องว่าง | แคปชั่นที่ยังมี `{ชื่อสาขา}` ค้าง → ปุ่มกดไม่ได้ + route ปฏิเสธ |
| กรณีโพสต์ติดแต่ DB พัง | คืน `post_id` กลับมาพร้อมคำเตือน **“อย่ากดซ้ำ”** ไม่ใช่ error เปล่า ๆ |

**โหมดทดสอบ** — route รับ `dryRun: true` จะอัปรูปขึ้น Facebook แต่ไม่เผยแพร่
(`published=false` · ไฟล์หายเองใน ~24 ชม. · ไม่แตะ DB) ใช้ตรวจว่า token/รูปใช้ได้จริง
โดยไม่มีอะไรโผล่บนเพจ · **ใช้ได้เฉพาะโพสต์ที่มีรูป** เพราะ `/feed` ไม่มีโหมดนี้

## เมื่อ token ใช้ไม่ได้ขึ้นมา

Page token ไม่มีวันหมดอายุ **แต่ถูกเพิกถอนได้** — เปลี่ยนรหัสผ่าน Facebook, ถอดสิทธิ์แอป,
หรือหลุดจากแอดมินเพจ · ระบบจะขึ้นข้อความบอกตรง ๆ ว่าให้ไปออกใหม่ ไม่ใช่ error อังกฤษดิบ ๆ
วิธีแก้คือทำข้อ 2-4 ใหม่ (ข้อ 1 ไม่ต้องทำซ้ำ)

## ยังไม่ได้ทำ

- **Instagram** — ต้องผูก IG Business เข้ากับเพจ แล้วยิง `/media` + `/media_publish` 2 ต่อ
  (แคปชั่น IG มีอยู่แล้วในระบบจากฟีเจอร์หลายช่องทาง)
- **ตั้งเวลาโพสต์** — ตอนนี้กดแล้วขึ้นทันที · Graph API รับ `scheduled_publish_time` ได้อยู่แล้ว
  เหลือแค่ต่อ UI กับตัวจับเวลา
- **ดึงยอด engagement กลับ** — เก็บ `post_id` ไว้แล้วเพื่อการนี้ ยังไม่มีตัวดึง
