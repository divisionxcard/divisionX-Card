# Content Pack — chukes01 (เดอะมอลล์บางแค) · Pilot 30k/วัน

ชุดคอนเทนต์ LINE OA + Facebook สำหรับตู้นำร่อง · ก๊อปวางได้เลย · อิงข้อมูลขายจริง 30 วัน

## 🎯 กลยุทธ์คอนเทนต์ (อิงข้อมูล)
- **One Piece = พระเอก** (OP13/15/16 = ยอดเกินครึ่ง) → เนื้อหาเกาะ OP เป็นหลัก
- **ดึงทราฟฟิกเช้า** — ช่วง 10-12 น. ขายบางมาก → broadcast เช้า "เติมของสด" ทุกวัน
- **ปั่นพีคเย็น 19-21 น.** (~35% ของยอด) → โพสต์/รีมายด์ช่วง 17-18 น.
- **PRB02 กล่อง** = ของพรีเมียมราคา 2,800-4,800/กล่อง → ใช้เป็น hero โพสต์ของแพง/chase

> แทนค่าในวงเล็บ `{...}` ก่อนโพสต์ · {ชั้น} = ชั้น/โซนที่ตั้งตู้จริง · {เซ็ต} = เซ็ตที่เพิ่งเติม

## 📲 LINE OA — Broadcast Templates

### 1. เติมของเช้า (ส่ง ~09:30 ทุกวัน — ดึงคนช่วงเช้าที่บาง)
```
☀️ อรุณสวัสดิ์ชาวการ์ด!
เติมของสดเช้านี้แล้วที่ตู้ DivisionX 🎴
📍 เดอะมอลล์บางแค ชั้น {ชั้น}
✅ One Piece OP13 / OP15 / OP16 มาเต็มช่อง
มาก่อนได้ก่อน ของหมดเร็วมาก 🔥
แวะกดก่อนเข้างาน/ก่อนช้อปได้เลย!
```

### 2. รีมายด์ก่อนพีคเย็น (ส่ง ~17:30)
```
🌆 เย็นนี้ว่างไหม? แวะตู้การ์ดก่อนกลับบ้าน
📍 DivisionX @เดอะมอลล์บางแค ชั้น {ชั้น}
🎴 OP13 / OP15 ยังมี · PRB กล่องใหญ่ก็มา!
เปิดซองสดๆ หน้าตู้ ลุ้นการ์ดหายากกันได้เลย ✨
```

### 3. ของแพง/พรีเมียมกลับมา (PRB02 box)
```
💎 ของหายากกลับมาแล้ว!
PRB กล่องใหญ่ (Booster Box) เข้าตู้ DivisionX แล้ว
📍 เดอะมอลล์บางแค ชั้น {ชั้น}
มีจำนวนจำกัดมาก ❗ ใครรอ box อยู่ รีบเลย
กดเองได้ ไม่ต้องต่อคิว ไม่ต้องจองล่วงหน้า
```

### 4. เซ็ตใหม่มาถึง (วันปล่อยเซ็ต OP ใหม่)
```
🚨 เซ็ตใหม่มาแล้ว! {เซ็ต}
เป็นเจ้าแรกที่ได้เปิดที่ตู้ DivisionX
📍 เดอะมอลล์บางแค ชั้น {ชั้น} · เริ่มกดได้ {เวลา} น.
🔥 วันแรกของหมดไว — แอดไลน์ไว้รับแจ้งเตือนรอบเติม
```

### 5. โชว์ของที่ลูกค้ากดได้ (social proof)
```
🎉 ยินดีด้วยกับลูกค้าที่กด {ชื่อการ์ด} ได้จากตู้เรา!
ตู้ DivisionX @เดอะมอลล์บางแค ของจริง ลุ้นจริง
ใครจะเป็นคนต่อไป? 👀 แวะมาเปิดดวงกันได้เลย
📍 ชั้น {ชั้น} · เปิดตามเวลาห้าง
```

### 6. สุดสัปดาห์ (ส่งศุกร์เย็น / เสาร์เช้า)
```
🎴 เสาร์-อาทิตย์นี้ มาเปิดซองที่ตู้การ์ด DivisionX!
📍 เดอะมอลล์บางแค ชั้น {ชั้น}
OP13/15/16 ครบ · เติมสดทุกวัน · กดเองได้ ไม่ต้องต่อคิว
ชวนเพื่อนมาเปิดด้วยกัน สนุกกว่าเยอะ 😎
```
