# Facebook Growth Playbook — ทำคอนเทนต์ให้คนสนใจ + เพิ่มผู้ติดตาม

ต่อยอดจาก [[facebook-content-plan]] (มีปฏิทิน+แคปชั่นแล้ว) · ไฟล์นี้ = **กลไกการโต** ทำยังไงให้ยอด follow ขึ้นจริง

---

## 🎡 Growth Flywheel (เข้าใจก่อนว่าโตยังไง)
**Reels เข้าถึงคนใหม่ → คนเข้ามาดูเพจ → กด Follow → เห็น pinned/คอนเทนต์ → แอดไลน์/ไปกดตู้**
→ FB 2026 ดัน **Reels + คอนเทนต์ที่คน "แชร์/เซฟ/คอมเมนต์จริง"** มากสุด · ยอด reach ส่วนใหญ่มาจากคนที่ "ยังไม่ตามเพจ" (แปลว่าโตได้)

## 🔑 4 หลักที่ทำให้คอนเทนต์ปัง
1. **Reels มาก่อน** — คลิปสั้นแนวตั้ง 9:16 คือเครื่องเข้าถึงคนใหม่ที่แรงสุด (รูปนิ่งเข้าถึงเฉพาะคนตามเพจ)
2. **3 วินาทีแรกต้องหยุดนิ้ว** — เปิดด้วยภาพ/คำที่สะดุด เช่น ฉีกซองช้าๆ + ข้อความ "ลุ้นใบนี้..." ไม่ใช่อินโทรยาว
3. **อย่าวางลิงก์ในโพสต์** — FB ลด reach โพสต์ที่มีลิงก์ออกนอก → **เขียนโพสต์ปกติ แล้วเอาลิงก์ใส่คอมเมนต์แรก** (พิมพ์ "ลิงก์อยู่คอมเมนต์ 👇")
4. **กระตุ้น 3S: Share / Save / Comment** — ถามคำถามให้คนตอบ · ทำคอนเทนต์ที่คน "อยากเซฟไว้" (เช่น สรุปเซ็ต) · ชวนแท็กเพื่อน

## 🎬 ฟอร์แมตที่เวิร์กสุด (เรียงตามพลังโต)
| ฟอร์แมต | ทำไมปัง |
|---|---|
| **Reels เปิดซองสด** | ลุ้นไปกับคนดู → คนดูจบ + แชร์ · ถ่ายครั้งเดียวลง FB/TikTok/IG |
| **Reels "ได้ chase card!"** | จังหวะเปิดได้การ์ดแรร์ = ไวรัล · ตัดให้สั้น กระชับ |
| **Carousel รวมการ์ดเด่น/รีวิวเซ็ต** | คนปัด+เซฟ → algorithm ดัน |
| **โพล/คำถาม** | คอมเมนต์เยอะ = reach พุ่ง (เช่น "สายไหนกันบ้าง?") |
| **before/after เติมตู้** | "ตู้เต็มแล้ว! รีบมา" สร้าง FOMO |

## 🚀 5 ตัวเร่งผู้ติดตาม (Follower Accelerators)
1. **🎁 กิจกรรมแจกการ์ด (ตัวเร่งแรงสุด)** — กติกา: **กดติดตามเพจ + ไลก์ + แชร์ + แท็กเพื่อน 2 คน** → สุ่มแจก 1 ซอง/สัปดาห์
   - ต้นทุนต่ำ (1 ซอง) แต่ดึง follow + reach มหาศาล · พ่วง "แอดไลน์ด้วยรับสิทธิ์ลุ้นเพิ่ม"
2. **🤝 Collab กับครีเอเตอร์สาย TCG** — โพสต์ร่วม (collab post) เข้าถึงผู้ติดตามของทั้งคู่ · ให้เขาไลฟ์เปิดซองหน้าตู้
3. **📲 ดึงจากช่องทางอื่น** — QR/ป้ายหน้าตู้ + LINE broadcast + เว็บ → ใส่ "ตามเราบน FB"
4. **👥 กลุ่ม FB** — โพสต์ value ในกลุ่ม One Piece TCG (อวดของ/รีวิว ไม่ขายตรง) → คนตามมาที่เพจ (ส่วน 3️⃣ ทำต่อ)
5. **💬 ตอบทุกคอมเมนต์ใน 1 ชม.แรก** — algorithm ดันโพสต์ที่ตอบไว + สร้างความผูกพัน

## 📅 Sprint 30 วันแรก (เน้นเร่งผู้ติดตาม)
- **สัปดาห์ 1:** ลง Reels เปิดซอง 3-4 คลิป + pinned post + เริ่มตอบคอมเมนต์ทุกอัน · ตั้ง baseline (ผู้ติดตาม/reach วันนี้)
- **สัปดาห์ 2:** จัด **กิจกรรมแจกการ์ดครั้งที่ 1** (follow+share+tag) + ลงกลุ่ม FB 2-3 กลุ่ม
- **สัปดาห์ 3:** Collab/เชิญ KOL ไลฟ์เปิดซองหน้าตู้ + Reels "ได้ chase"
- **สัปดาห์ 4:** สรุปผล → คลิปไหน reach ดีทำซ้ำ · แจกรอบ 2 · เริ่มคิดยิง ads ดันคลิปที่ดีสุด (boost)

## 📊 ตัวเลขที่ต้องดู (รายสัปดาห์)
- **ผู้ติดตามเพิ่ม/สัปดาห์** (เป้าหลัก) · **reach คนที่ยังไม่ตามเพจ** (วัดการเข้าถึงใหม่)
- **แชร์ + เซฟ + คอมเมนต์** ต่อโพสต์ (สัญญาณ algorithm) · **คลิปไหน watch-through สูง** → ทำซ้ำ/boost
- ดูใน **Meta Business Suite → Insights**

## ⚠️ ข้อควรเลี่ยง
- โพสต์รัวแล้วหายไปหลายวัน (algorithm ลงโทษความไม่สม่ำเสมอ) → **4-6 โพสต์/สัปดาห์สม่ำเสมอ**
- ลิงก์ในตัวโพสต์ (ใส่คอมเมนต์แทน) · ขายตรงรัวๆ (สลับกับคอนเทนต์สนุก/ความรู้)
- ซื้อผู้ติดตามปลอม (เสีย reach ระยะยาว)
