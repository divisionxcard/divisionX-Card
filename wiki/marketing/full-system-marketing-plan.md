# แผนการตลาดเต็มระบบ — DivisionX Card (11 ตู้)

แผนยกระดับจาก pilot ตู้เดียว → ทั้งฟลีต · approach: **Hybrid** (engine ฟรีทำทั้งฟลีตทันที + paid ที่สเกลตาม ROI)

---

## 1. เราอยู่ตรงไหน (Fleet Diagnosis · ข้อมูลสด 2026-06-22)

| Tier | ตู้ | ยอด/วัน |
|---|---|--:|
| 🌟 ดาวเด่น | chukes01 บางแค | 19,545 |
| 💪 แข็งแรง | chukes02 พระราม2 · chukes04 ชลบุรี | 12–14k |
| 🔶 กลาง | wwv01 รามอินทรา · chukes03 พระราม9 | 6.8–7.3k |
| 🔻 อ่อน (7 ตู้) | wwv02–07 | 2–4.5k |

**รวม ≈ 78,589/วัน · ศักยภาพเต็ม 330k/วัน → ทำได้แค่ 24%**

## 2. ยุทธศาสตร์หลัก (Strategic Thesis)
1. **ขุมทรัพย์ = ปลุก 7 ตู้ WW** — ดัน chukes01 20→30k ได้ +10k (เพดานเดียว) · ปลุก WW ตู้ละ +5k = **+35k/วัน** · ปัญหา WW = awareness/traffic (บิล/วันแค่ 10–21 vs VMS 39–63) ที่การตลาดแก้ตรงๆ
2. **VMS = optimize & defend** — พิสูจน์แล้ว เน้นรีดเพดาน (sell-through + ปั่นกระแส) อย่าให้หลุด
3. **One Piece = เครื่องยนต์ทั้งฟลีต** — OP13/15/16 + PRB เป็น top SKU ทุกตู้ → คอนเทนต์/แคมเปญชุดเดียวใช้ได้ทั้งระบบ
4. **Hybrid = ฟรีก่อน เสียเงินตาม ROI** — engine ฟรีลงทั้งฟลีตเลย · paid เริ่มที่ตู้พิสูจน์แล้ว ขยายเมื่อเห็น ROAS

## 3. สามเครื่องยนต์ (The 3 Engines)

### A) Demand Engine — ทั้งฟลีต · เกือบฟรี (ทำทันที)
- **LINE OA** ศูนย์กลาง: broadcast restock เช้า/เย็น · rich menu เช็คตู้ · QR ทุกตู้
- **FB กลุ่ม One Piece TCG + เพจ + TikTok**: live pull, อวดของ, restock alert, countdown เซ็ตใหม่
- **ปฏิทิน restock อิงวันปล่อยเซ็ต OP** — sync รอบเติม + คอนเทนต์กับวันจริง (ทั้งฟลีต)
- คอนเทนต์ชุดเดียว ([[chukes01-content-pack]]) ปรับชื่อตู้/ทำเล ใช้ได้ทุกตู้

### B) Local Activation — paid · เจาะเป็น cluster · ROI-gated
**จัดกลุ่มตู้ตามโซน → ยิง ads/KOL ทีเดียวคุ้มหลายตู้:**
- **บางแค:** chukes01 + wwv05 (ซีคอน) ← co-market ได้ 2 ตู้โซนเดียว
- **พระราม 2:** chukes02 + wwv06
- **ตะวันตก/นนทบุรี:** wwv04 เวสต์เกต + wwv07 เวสต์วิลล์ + wwv03 ศาลายา
- **ตอน/ออกเหนือ:** wwv01 รามอินทรา + wwv02 บางกะปิ + chukes03 พระราม9
- **ชลบุรี:** chukes04 (เดี่ยว)

แต่ละ cluster: geo ads รัศมีห้าง + micro-KOL ไลฟ์หน้าตู้ + event/restock party
→ **เปิดทีละ cluster เมื่อ cluster ก่อนพิสูจน์ ROAS** (ไม่เปิดพร้อมกันหมด)

### C) Operational Excellence — ฟรี · ROI สูงสุด (ทำทันทีทั้งฟลีต)
รีดวิธีจาก pilot chukes01 ไปทุกตู้:
- **ไม่ปล่อย OP เรือธงว่าง** (เติมไม่ได้กลางวัน → front-load capacity)
- **เติม SKU ขายดีที่ถูกถอด** (เช่น PRB02 ที่ chukes01) กลับ
- **rebalance slot** ลด SKU ขายช้า เพิ่มตัวขายดี
- **buffer SKU ขายดีช่วงพีคเย็น 19–21 น.**
> นี่คือ "อย่าทำพังตอนคนมา" — ฟรี แต่กันยอดรั่ว

## 4. เป้าแบบ Tiered (ไม่ใช่ flat 30k ทุกตู้)
30k คือ north star ของทำเลท็อป · เป้าจริงเป็นขั้นบันได:

| Tier | เป้า 6 เดือน | จากปัจจุบัน |
|---|--:|---|
| ดาวเด่น (chukes01) | 30k | ×1.5 |
| แข็งแรง (chukes02/04) | 20–25k | ×1.6 |
| กลาง (wwv01/chukes03) | 12–15k | ×2 |
| อ่อน (WW 7 ตู้) | **8–12k** | ×3–4 |

**เป้าฟลีต 6–12 เดือน ≈ 150–180k/วัน** (จาก 78.6k = ~2 เท่า) — ท้าทายแต่ทำได้จริง

## 5. 💰 คำแนะนำงบ (ผูกกับ ROI ไม่ใช่ตัวเลขลอย)
**หลักการ:** เริ่ม lean เก็บหลักฐาน → สเกลเฉพาะตัวที่วัด ROAS ได้ · มาตรฐาน retail = 8–12% ของยอดขาย (ฟลีตทำ ~2.36M/เดือน → เพดานบน ~190–280k) แต่**เริ่มต่ำกว่านั้นมาก**

| เฟส | งบ/เดือน | ลงกับอะไร |
|---|--:|---|
| **เฟส 1 (เดือน 1–2)** | **40–60k** | engine ฟรี (เวลา) + chukes01 ads/KOL (15–25k) + **1 cluster WW ทดสอบ** (wwv01 ดีสุด ~15–20k) + ป้าย QR ×11 ตู้ (one-time ~10–15k) |
| **เฟส 2 (เดือน 3–4)** | **80–120k** | ขยายสูตรชนะไป 2–3 cluster WW เพิ่ม + event |
| **เฟส 3 (เดือน 5+)** | **ผูกกับยอด** | reinvest ~10–15% ของยอดที่การตลาดดันขึ้น · ตู้/ช่องไหน ROAS ต่ำ = ตัด |

**กฎเหล็ก:** ไม่ลงเงินกับตู้/ช่องทางที่ยังวัด CAC/ROAS ไม่ได้ · winner เท่านั้นที่ได้งบเพิ่ม

## 6. องค์กร & จังหวะ (Cadence)
- **รายวัน:** LINE broadcast เช้า 09:30 + เย็น 17:30 (ทั้งฟลีต ตั้งล่วงหน้า)
- **รายสัปดาห์:** 3–4 คลิป live pull · review ยอดรายตู้ · ปรับ slot
- **รายเดือน:** เปิด/ปิด cluster ตาม ROAS · สรุป KOL · วางปฏิทินเซ็ตใหม่
- **ทีม:** กำหนดคนทำคอนเทนต์ + คนคุมเติมของ (sell-through) + คนดูตัวเลข (ใช้ dashboard ที่มี)

## 7. การวัดผล (มีระบบเก็บอยู่แล้ว = ได้เปรียบ)
- **Fleet dashboard:** ยอด/วัน/ตู้ · บิล/วัน · AOV · sell-through OP
- **การตลาด:** ฟอลฯ LINE OA · QR scan→ยอด · ROAS ต่อ cluster · CAC
- **Gate:** cluster ผ่านเมื่อ ROAS เป็นบวกชัด → ปลดงบ cluster ถัดไป

## 8. Roadmap 90 วัน (Hybrid)
- **เดือน 1:** engine ฟรีลงทั้งฟลีต (LINE/FB/TikTok/QR) + Operational Excellence ทุกตู้ + ยิง paid ที่ chukes01 (pilot) + เริ่มทดสอบ cluster บางแค (chukes01+wwv05)
- **เดือน 2:** วัดผล chukes01+บางแค → ถ้าเวิร์ก เปิด cluster พระราม2 + รามอินทรา
- **เดือน 3:** ขยาย cluster ที่เหลือตาม ROAS + เปิด loyalty (LINE points) + event ตู้ท็อปต่อ cluster
