# ระบบยิงแอด Facebook + TikTok อัตโนมัติ — แผนออกแบบ

> เวอร์ชันอ่านสวย/ส่งต่อได้: ดูลิงก์ `artifact` ใน frontmatter
> ไฟล์นี้คือฉบับที่แก้ต่อได้และอยู่กับ repo

ตัวเลขธุรกิจดึงจาก DB จริง 2 ก.ย. 2026 · ข้อมูลแพลตฟอร์มตรวจ ณ ก.ย. 2026
(Meta Marketing API v25.0 · TikTok Business API v1.3)

## เส้นฐานที่ใช้ออกแบบ

| | |
|---|---|
| ยอดขายรวม | **฿37,550/วัน** (30 วันล่าสุด · 13 ตู้) |
| ต่อตู้ | ฿1,133 – ฿4,547/วัน |
| ความผันผวนรายวัน | **83%** (sd/mean) |
| คอนเทนต์ในระบบ | 36 ชิ้น · โพสต์จริง 2 · เอนเกจกลาง 3/โพสต์ |
| เป้าที่ตั้งไว้ | ฿30,000/วัน/ตู้ = **7–10 เท่าของวันนี้** |

## ห้าข้อเท็จจริงที่กำหนดรูปร่างของระบบ

1. **เรามียอดขายรายวันรายตู้** — ของที่แพลตฟอร์มมองไม่เห็น → ระบบวัดผลต้องสร้างรอบตัวนี้
2. **ผูกคนซื้อกับคนดูแอดรายคนไม่ได้** — Meta ปิด Offline Conversions API ตั้งแต่ พ.ค. 2025
   ปัจจุบันต้องส่งผ่าน CAPI `action_source: physical_store` ซึ่งต้องมี email/phone
   **ตู้ไม่เก็บอะไรเลย** → **ROAS รายชิ้นแอดใช้ไม่ได้**
3. **ยอดเหวี่ยง 83%/วัน** → ทุกการทดสอบต้องมีกลุ่มควบคุม
4. **TikTok = วิดีโอเท่านั้น + บังคับป้าย AIGC** (นโยบาย 21 ก.ค. 2026)
   สเปก 9:16 · 1080×1920 · H.264 · <500MB · 15–30 วิ
5. **ขั้นต่ำ TikTok $20/ad group/วัน (~฿700)** เทียบกับยอดตู้ ~฿2,900/วัน
   → ยิงรายตู้ไม่คุ้ม ต้องยิงเป็นกลุ่มสาขาแล้ววัดผลรายตู้

## สถาปัตยกรรม 6 ชั้น

| ชั้น | สถานะ |
|---|---|
| 1 หาไอเดีย (`marketing_ideas`) | มีแล้ว |
| 2 เขียนคอนเทนต์ (`marketing_content`) | มีแล้ว |
| 3 โพสต์ + เก็บผล (`post_metrics`) | มีแล้ว |
| 4 โรงงานสื่อโฆษณา (9:16 หลายเวอร์ชัน + คลังฟุตเทจ) | **สร้างใหม่** |
| 5 ตัวยิงแอด (Meta MAPI v25 · TikTok v1.3) | **สร้างใหม่** |
| 6 ตัวตัดสินผล (จับคู่ช่วงยิงกับยอดขายรายตู้) | **สร้างใหม่** |

⚠️ ชั้น 4–6 ต้องแยกขาดจากกัน — ตัวยิงห้ามรู้จักวิธีวัด ตัววัดห้ามรู้จักวิธียิง

## แผน 10 สัปดาห์

| เฟส | สัปดาห์ | ด่านผ่าน |
|---|---|---|
| 0 ตั้งบัญชี + เส้นฐาน | 1–2 | ยิง API สร้าง/หยุดแคมเปญ ฿1 ได้ทั้งสองเจ้า · มีเส้นฐาน 14 วัน |
| 1 โรงงานสื่อ | 2–4 | กดปุ่มเดียวได้ครีเอทีฟพร้อมยิง 9 ชิ้นผ่านสเปก |
| 2 ยิงมือ + เรียนรู้ | 4–5 | รู้ CPM/CTR/CPC จริง และรู้ว่าครีเอทีฟแบบไหนคนหยุดดู |
| 3 ตัวยิงอัตโนมัติ | 5–7 | ครบรอบ 7 วันไม่มีคนแตะ · ไม่มีวันไหนงบเกินเพดาน |
| 4 การทดลองวัดผล | 6–10 | ได้ส่วนต่างพร้อมช่วงความเชื่อมั่น |
| 5 ตัดสินใจ | 10 | ตอบได้ว่าแอด 1 บาททำให้ยอดขึ้นกี่บาท |

**เฟส 0 รายละเอียด:** Meta BM → ยืนยันธุรกิจ → Ad Account (THB) → ผูกเพจ →
**System User token** (ไม่หมดอายุ) สิทธิ์ `ads_management` + `ads_read` + `business_management` →
ขอ Marketing API Access Tier (Limited พอ) · TikTok Business Center → Advertiser (THB) → ขอสิทธิ์ API

**เฟส 4 การออกแบบทดลอง:** จับคู่ตู้จากยอดเฉลี่ย+รูปแบบรายวันช่วงเส้นฐาน ·
6 ตู้เปิดแอด 6 ตู้ควบคุม · รัน 4 สัปดาห์แล้วสลับข้าง 2 สัปดาห์ ·
ปรับด้วยยอดช่วงก่อนหน้าของตู้เดียวกัน · **ห้ามแตะอย่างอื่นระหว่างทดลอง**

## KPI สามชั้น

| ชั้น | ตัวชี้วัด | เกณฑ์เริ่มต้น | เชื่อได้แค่ไหน |
|---|---|---|---|
| 1 สื่อทำงานไหม | CTR · CPM · ดูจบ 3 วิ | CTR ≥ 1% · ดูจบ 3 วิ ≥ 25% | สูง แต่ไม่ได้บอกว่าขายได้ |
| 2 คนสนใจจริงไหม | คลิกหน้าหาตู้ · เพิ่มเพื่อน LINE | ต้นทุนเพิ่มเพื่อน ≤ ฿20 | กลาง — สะพานเดียวที่วัดรายคนได้ |
| 3 ยอดขายขึ้นจริงไหม | ส่วนต่างยอดรายตู้ · กำไรส่วนเพิ่ม/ค่าแอด | กำไรส่วนเพิ่ม > ค่าแอด | สูงสุด ต้องมีกลุ่มควบคุม |

(ซึ่งยังเป็นเงินจริงปีละหลายแสน) เราจะพิสูจน์ไม่ได้ในกรอบนี้ — ต้องยอมรับตั้งแต่ต้น

## สายการผลิตสื่อ

**ข้อเสนอที่ต่างจากที่ทำอยู่: ให้ฟุตเทจจริงเป็นแกน ไม่ใช่ AI**
ถูกกว่า · ผ่านนโยบาย AIGC ง่ายกว่า · คนเชื่อมากกว่า · คู่แข่งลอกไม่ได้
AI เอาไว้ทำกราฟิกประกอบ พาดหัว และเวอร์ชันย่อย

| ชิ้นงาน | ผลิตยังไง | ต้นทุน | ป้าย AIGC |
|---|---|---|---|
| ภาพนิ่ง 1:1 / 4:5 | ระบบเดิม (OpenAI) | ~฿2 | ไม่บังคับ |
| วิดีโอ 6/15/30 วิ | ฟุตเทจจริง + ffmpeg | ~฿0 | ไม่ต้อง |
| วิดีโอมีฉาก AI | AI + ประกอบ | สูง | **บังคับ** |
| Spark Ads | ดันโพสต์จริงของแบรนด์ | ~฿0 | ตามต้นทาง |

บังคับในโค้ด: ผูก `content_id` เดิม · ฝังรหัสชุดทดลองในชื่อแอด ·
ราคาบนสื่อดึงจาก `machine_stock.sell_price` ห้ามพิมพ์มือ

## งบและความเสี่ยง

| รายการ | ต่อเดือน |
|---|---|
| Meta (2 กลุ่ม × ฿300/วัน) | ฿18,000 |
| TikTok (2 ad group ติดขั้นต่ำ) | ฿42,000 |
| ครีเอทีฟ AI | ~฿500 |
| **รวม** | **~฿60,000** (5.3% ของยอดขาย) |

**ทางเลือกงบต่ำ:** Meta อย่างเดียว ฿300/วัน กลุ่มเดียว = ~฿9,000/เดือน

⚠️ **ตู้ที่ของใกล้หมดต้องหยุดแอดอัตโนมัติ** — ระบบรู้สต็อกหน้าตู้อยู่แล้ว
จ่ายเงินพาคนไปเจอตู้ว่างแย่กว่าไม่ยิงเลย ข้อนี้ต้องอยู่ในเฟส 3

ความเสี่ยงอื่น: บัญชีโดนระงับ (ยืนยันธุรกิจให้ครบ เริ่มงบต่ำ) ·
งบทะลุเพดาน (บังคับในโค้ด + แจ้ง Telegram) ·
API เปลี่ยนเวอร์ชัน (Meta ออกใหม่ทุก ~6 เดือน เลิกรองรับใน 2 ปี — v24 หมดอายุ 6 ต.ค. 2026)
