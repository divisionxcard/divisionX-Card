# Hermes กับ Tavily ทำงานร่วมกันยังไง

> **สรุปหนึ่งบรรทัด:** Hermes คือคนทำงาน · Tavily คือแว่นตาที่ใส่ไว้มองโลกภายนอก
> Tavily ไม่ตัดสินใจอะไรเลย ไม่รู้จักตู้เราสักตู้ มีหน้าที่เดียวคือไปอ่านเว็บมาให้เมื่อ Hermes สั่ง

## ทำไมต้องมีเอกสารนี้

เพราะเคยเข้าใจผิดมาแล้วว่าปัญหา "Hermes ตอบมั่ว" เกิดจากโมเดลไม่ฉลาด
ความจริงคือ**ตัวค้นเว็บอ่านหน้าเว็บไม่ได้** ซึ่งเป็นคนละเรื่องกันคนละชั้นกัน
ถ้าไม่เข้าใจว่าใครทำหน้าที่อะไร จะแก้ผิดจุดแล้วเสียเงินฟรี

---

## Hermes — คนทำงาน

เอเจนต์ที่รันบนเครื่องเจ้าของ คุยผ่าน Telegram · `cwd` ตั้งไว้ที่ `c:/Projects/divisionX Card`
จึงอ่านไฟล์ในโปรเจกต์ได้ทั้งตอนแชทและตอนรันงานตามเวลา

| หน้าที่ | รายละเอียด |
|---|---|
| ตอบคำถามทาง Telegram | สต็อกหน้าตู้ · ยอดขาย · ต้องเติมอะไร · การ์ดชุดนี้มีอะไร |
| ตรวจคอนเทนต์ทุก 30 นาที | เทียบกฎแบรนด์ แล้วให้ verdict ผ่าน/ต้องแก้/ไม่ควรใช้ |
| วางปฏิทินโพสต์ทุก 9 โมง | ส่งสรุปเข้า Telegram ว่าจะลงอะไรวันไหน |

## Tavily — แว่นตา

ตัวค้นเว็บและอ่านหน้าเว็บ ให้บริการผ่านเครื่องมือสองตัวของ Hermes:
`web_search` (หา URL) และ `web_extract` (อ่านเนื้อหาเต็มหน้า)

**ไม่ใช่โมเดล ไม่ใช่สมอง** — เป็นแค่ท่อส่งข้อมูลจากอินเทอร์เน็ตเข้ามา

---

## หัวใจของระบบ — ลำดับการหาคำตอบ 3 ชั้น

Hermes **ไม่ได้ค้นเว็บทุกครั้ง** มันไล่ตามลำดับนี้ และนี่คือส่วนที่สำคัญที่สุดของเอกสารนี้

```
คำถามเข้ามา
    │
    ├─ ชั้น 1  เรื่องตู้เรา · ยอดขาย · สต็อก · คอนเทนต์
    │          → MCP 13 ตัว → Supabase
    │          list_machines · get_stock · get_sales · get_restock_alerts
    │          get_marketing_ideas · get_content_queue · get_content_for_review
    │          review_content · get_post_performance · get_post_plan
    │          schedule_content · get_sync_status · (sync_data ปิดไว้)
    │          ★ ความจริงของธุรกิจเรา — Tavily ไม่มีทางรู้เรื่องนี้
    │
    ├─ ชั้น 2  เรื่องการ์ด · กฎการเล่น · ระดับความหายาก
    │          → อ่านไฟล์ใน deploy/tasks/ (6 ค่าย · 20 จาก 22 SKU)
    │          ★ ดึงจากเว็บผู้ผลิตโดยตรงแล้ว แม่นกว่าค้นเว็บสด
    │
    └─ ชั้น 3  เรื่องที่สองชั้นบนไม่มีคำตอบ
               → Tavily: web_search แล้ว web_extract
               ★ ข่าวใหม่ · สินค้าที่ยังไม่มีในคลัง · ราคาตลาด
```

### ดูจากคำถามจริง

| คำถาม | ใครทำงาน |
|---|---|
| "ตู้ไอคอนสยามต้องเติมอะไร" | **MCP อย่างเดียว** — Tavily ไม่ถูกเรียกเลย |
| "การ์ด FB09 ใบไหนแรงสุด" | **อ่าน `dbfw_cards.json`** — ไม่ต้องค้นเว็บ |
| "Kayou ออกชุด Transformers ยัง" | **Tavily** — คลังเรายังไม่มีข้อมูลนี้ |
| "ยอดขาย OP-16 เดือนนี้เทียบราคาตลาด" | **ทั้งสามชั้น** |

## ซัพพอร์ตกันยังไง

**Tavily ช่วย Hermes** — ก่อนหน้านี้ Hermes ตาบอดเรื่องโลกภายนอก ตัวค้นเก่า (`ddgs`)
อ่านหน้าเว็บไม่ได้เลย ระบบตอบตรง ๆ ว่า *"search-only backend and cannot extract URL content"*
Hermes จึงเห็นแค่คำโปรย ~200 ตัวอักษร แล้วต้องเดาเนื้อหาที่เหลือ — **นั่นคือที่มาของอาการแต่งข้อมูล**

**Hermes คุมจุดอ่อนของ Tavily** — Tavily ไม่รู้ว่าเว็บไหนน่าเชื่อ มันคืนทุกอย่างที่เจอ
กฎใน `hermes/SOUL.md` หัวข้อ "ค้นข้อมูล" จึงบังคับ 5 ข้อ:

1. อ่านคลังความรู้ใน `deploy/tasks/` ก่อนไปค้นเว็บ
2. ห้ามสรุปจากผลค้นหา ต้อง `web_extract` อ่านหน้าจริงก่อน
3. ห้ามพิมพ์ URL ขึ้นมาเอง คัดลอกจากผลลัพธ์เครื่องมือเท่านั้น
4. เว็บทางการชนะบล็อกร้านค้า — ถ้าใช้บล็อกต้องกำกับ "(ยังไม่ยืนยันจากผู้ผลิต)"
5. ไม่รู้ให้บอกว่าไม่รู้

**คลังความรู้ช่วยทั้งคู่** — ทุกคำถามที่ตอบได้จากไฟล์ คือหนึ่งครั้งที่ไม่ต้องเผาโควตา Tavily
และได้คำตอบที่แม่นกว่า เพราะมาจากผู้ผลิตโดยตรง

## ตั้งค่าอยู่ที่ไหน

| อะไร | ที่อยู่ |
|---|---|
| คีย์ Tavily | `hermes/.env` → `TAVILY_API_KEY` |
| เลือกตัวค้นเว็บ | `hermes/config.yaml` → `web.backend` · `search_backend` · `extract_backend` |
| กฎการค้นข้อมูล | `hermes/SOUL.md` หัวข้อ "ค้นข้อมูล" |
| โฟลเดอร์ทำงาน | `hermes/config.yaml` → `cwd` |
| เครื่องมือข้อมูลตู้ | `deploy/mcp/dvx_mcp_server.py` |
| คลังความรู้การ์ด | `deploy/tasks/*_cards.json` · `*_rules.json` · `*_faq.json` |

**แก้ `config.yaml` หรือ `.env` แล้วไม่ต้อง restart gateway** — ทั้งสองไฟล์แคชด้วย mtime+size
เอกสารของ `load_env()` เขียนเองว่า *"invalidates the cache when the user edits .env mid-process"*
(ต่างจากรายชื่อผู้ใช้ Telegram ที่อ่านตอน start — อันนั้นต้อง restart)

## จุดที่ต้องระวัง

> [!warning] โควตา Tavily หมดแล้วจะตกกลับไป ddgs **เงียบ ๆ**
> ฟรี 1,000 ครั้ง/เดือน · ถ้าหมดจะไม่มี error ให้เห็น
> อาการคือคำตอบเริ่มมั่วเหมือนเดิม ถ้าวันไหนรู้สึกว่า Hermes ตอบแปลก ให้เช็กข้อนี้ก่อน

> [!warning] Tavily ไม่ใช่แหล่งความจริงเรื่องธุรกิจเรา
> ถ้ามันบอกอะไรที่ขัดกับตัวเลขจาก MCP **ให้เชื่อ MCP เสมอ**

> [!note] ถ้าไม่ตั้ง `web.backend` เลย ระบบจะเลือก Firecrawl อัตโนมัติ
> เพราะ probe ของ Nous ตอบว่าพร้อม ทั้งที่บัญชีไม่มีเครดิต แล้วค้นไม่ได้แบบเงียบ ๆ
> — เคยเกิดจริง 24 ส.ค. 2026 ก่อนจะเปลี่ยนมาใช้ Tavily

## ทำไมไม่ใช้ Perplexity

เคยพิจารณาแล้ว ตรวจเอกสาร API ของเขาเอง **ไม่มีพารามิเตอร์ `tools`** เลย
ใช้เป็นสมองของ Hermes ไม่ได้ เพราะ Hermes ต้องให้โมเดลเรียกเครื่องมือเอง
(อ่านไฟล์คลังความรู้ · ดึงยอดขาย/สต็อกผ่าน MCP) ถ้าเรียกไม่ได้ก็ไม่รู้จักตู้เราเลย

ส่วน Search API ของเขาคืนแค่ snippet ไม่ใช่หน้าเต็ม · ไม่มี free tier ($5 ต่อ 1,000 ครั้ง) ·
และ Hermes ไม่รู้จักชื่อ backend `perplexity` (รายชื่อที่รองรับคือ
`parallel · firecrawl · tavily · exa · searxng · brave-free · ddgs · xai`) ต้องแก้โค้ด Hermes

**เก็บไว้ใช้เฉพาะงานค้นยาก ๆ เป็นครั้งคราวได้** เช่นสินค้าตลาดจีนที่ไม่มีเว็บทางการ
แต่ไม่เหมาะเป็นเครื่องมือประจำ
