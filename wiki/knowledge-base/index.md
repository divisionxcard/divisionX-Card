## ⚡ TL;DR — ตัวตนของเจ้าของใน 6 บรรทัด
1. **ตัดสินด้วยข้อมูล ไม่ใช่ความรู้สึก** — ทุกอย่างมี baseline, metric, และเกณฑ์ที่ตั้งไว้ล่วงหน้า
2. **ฟรีก่อน เสียเงินตาม ROI** — ทำสิ่งที่ฟรี/กันยอดรั่วให้ครบก่อน ค่อยลงเงินเฉพาะที่พิสูจน์ผลได้
3. **พิสูจน์เล็ก ขยายเมื่อชนะ** — ทดสอบที่จุดเดียว วัด ROAS แล้วค่อยสเกลสูตรที่ชนะ
4. **มองช่องว่างเป็นโอกาส** — "ปัญหาคือคนไม่รู้จัก ไม่ใช่ของไม่ดี"
5. **เขียนแบบลงมือได้จริง** — สเต็ป/เช็กลิสต์/ตาราง/ใครทำอะไร ครบ ไม่ลอย
6. **เสียง 2 โหมด** — มืออาชีพ-มีตัวเลขกับกรรมการ · เพื่อนสายการ์ด FOMO-แต่ไม่โอเวอร์กับลูกค้า

## 📚 คลังความรู้การ์ด — ข้อมูลจากผู้ผลิตโดยตรง

ไม่ได้อยู่ในโฟลเดอร์นี้ แต่ **agent ต้องรู้ว่ามีอยู่** เพราะแม่นกว่าการค้นเว็บมาก
อยู่ที่ `deploy/tasks/` ดึงจากเว็บทางการของผู้ผลิตแล้วทั้งหมด:

| ไฟล์ | ครอบคลุม |
|---|---|
| `opcg_cards.json` · `opcg_rules.json` | One Piece — การ์ด 3,796 ใบ + กฎ 482 ข้อ (ไทย) |
| `dbfw_cards.json` · `dbfw_faq.json` | Dragon Ball Fusion World — 2,333 ใบ + Q&A ทางการ 450 ข้อ (ไทย) |
| `kayou_cards.json` | Naruto + My Little Pony (KAYOU) — 2,953 ใบ |
| `pkm_cards.json` · `pkm_rules.json` | Pokémon |
| `ygo_cards.json` | Yu-Gi-Oh OCG — 300 ใบ |
| `ua_cards.json` | Solo Leveling (UNION ARENA) — 92 แบบ + กฎ 156 ข้อ |

**ถามเรื่องการ์ดเมื่อไหร่ ให้เปิดไฟล์พวกนี้ก่อนค้นเว็บ**
ทุกไฟล์มีคีย์ `_important` / `_usage` เขียนข้อห้ามไว้ — ต้องอ่านและทำตาม
(เช่น KAYOU เป็นการ์ดสะสมไม่ใช่เกมการ์ด · ยูกิโอกับ Solo Leveling ชื่อการ์ดเป็นภาษาญี่ปุ่น)
