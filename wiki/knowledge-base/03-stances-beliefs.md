# 03 · จุดยืนและความเชื่อหลัก

หลักการที่เจ้าของยึดเวลาตัดสินใจ — AI agent ใช้เป็น "เกณฑ์" ประเมินไอเดีย/แผน ก่อนเสนอ

---

## 💰 เรื่องเงินและการลงทุน
- **กฎเหล็ก: ไม่ลงเงินกับตู้/ช่องทางที่ยังวัด CAC/ROAS ไม่ได้** — วัดผลไม่ได้ = ไม่จ่าย
- **winner เท่านั้นที่ได้งบเพิ่ม** — โซน/ช่องไหน ROAS ต่ำ = ตัด
- **เริ่ม lean เก็บหลักฐาน → สเกลเฉพาะที่พิสูจน์แล้ว** ("เริ่มเล็ก ขยายเมื่อพิสูจน์ได้")
- **ความเสี่ยงต้องต่ำ** — เริ่มงบน้อย ฟรีคือส่วนใหญ่ ถ้าไม่เวิร์กหยุดได้ทันที

## 📊 เรื่องการตัดสินใจ
- **ตัดสินด้วยข้อมูล ไม่ใช่ความรู้สึก** — "กำหนดเกณฑ์ ROAS ขั้นต่ำไว้ล่วงหน้า ไม่ใช่ตัดสินด้วยความรู้สึก"
- **ต้องมี baseline ก่อนเริ่มเสมอ** — ไม่งั้นพิสูจน์ผลไม่ได้
- **อย่าตัดสินเร็วเกินไป** — ให้เวลาแคมเปญ 3–4 สัปดาห์ก่อนสรุป · แยก seasonal ออกจากผลจริง
- **พิสูจน์ที่จุดเดียวก่อนขยาย** — อย่าเปิดทุกโซนพร้อมกัน เผาเงิน

## 🛠️ เรื่องลำดับการทำงาน
- **แก้ของก่อนยิงคอนเทนต์** — "ดึงคนมาแล้วต้องมีของให้ซื้อ"
- **ของฟรี/แก้ operation มาก่อน** — ROI สูงสุด กันยอดรั่ว ("อย่าทำพังตอนคนมา")
- **สม่ำเสมอสำคัญกว่าถี่** — โพสต์ 4–6/สัปดาห์สม่ำเสมอ ดีกว่าลงรัวแล้วหาย (algorithm ลงโทษความไม่สม่ำเสมอ)

## 🧭 เรื่องมุมมองต่อปัญหา
- **ช่องว่าง = โอกาส ไม่ใช่ปัญหา**
- **ปัญหาคือจำนวนลูกค้า/awareness ไม่ใช่ของไม่ดี** (เมื่อข้อมูลชี้แบบนั้น)
- **เป้าต้องสมจริง เป็นขั้นบันได** ("สมจริง ไม่ใช่ฝัน")

## 🤝 เรื่องคอมมูนิตี้และการสื่อสาร
- **Value-first ขายทีหลัง** — ในกลุ่ม/คอมมูนิตี้เน้นแบ่งปัน/อวดของจริง ไม่ยัดขาย
- **เคารพกฎกลุ่มเสมอ** — "อ่านกฎกลุ่มก่อนโพสต์ทุกครั้ง" คือกฎทองข้อเดียวที่สำคัญสุด
- **สร้างตัวตนก่อนขาย** — คุ้นหน้าก่อน อย่าโพสต์ขายวันแรก
- **ของจริง ลุ้นจริง** — โชว์ pull/ของจริงหน้าตู้ ดูจริงใจกว่าโฆษณา

## 🤖 เรื่อง AI และคอนเทนต์
- **สร้าง original เท่านั้น** — เรียนรู้จากคู่แข่งได้ แต่ห้ามก๊อป/reword ตรงๆ (เสี่ยง IP + ToS + ไม่ได้ผลจริง)
- **Human-in-the-loop จำเป็น** — AI ร่างได้ แต่คนรีวิว/อนุมัติเสมอ เพื่อคุมคุณภาพ + กัน IP
- **ใช้ข้อมูลตัวเอง = ปลอดภัย** — ต่อยอดจากระบบ/ข้อมูลที่มี ไม่มีปัญหาลิขสิทธิ์
- **ต่อยอดของที่มี ก่อนสร้างใหม่** — ชี้จุดแข็งว่า "มีระบบ/AI insight อยู่แล้ว ต่อยอดง่าย"

## 🔍 เรื่องความโปร่งใส
- **วัดผลได้ทุกบาท + รายงานกรรมการทุกเดือน** — โปร่งใส โซนไหนคุ้มขยาย โซนไหนตัด บอกชัด
