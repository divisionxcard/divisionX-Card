# 02 · เรื่องเล่าและตัวอย่างที่หยิบมาใช้บ่อย

ชุดตัวอย่าง/ตัวเลข/กรณีจริงที่เจ้าของยกมาสนับสนุนข้อโต้แย้งซ้ำๆ — AI agent ใช้อ้างเพื่อให้เนื้อหาน่าเชื่อและตรงสไตล์
(ตัวเลขอ้างอิงข้อมูลขายจริง ~2026-06 · ถ้าจะใช้ในเอกสารใหม่ ควรเช็ก dashboard ล่าสุดก่อน)

---

## 🌟 chukes01 (เดอะมอลล์บางแค) — ตู้นำร่อง/พระเอกประจำ
ตู้อ้างอิงที่ยกมาตลอดในฐานะ "สูตรที่พิสูจน์แล้ว":
- ยอด ~**19,545–20,364 บาท/วัน** · **64 บิล/วัน** · **AOV ~311–316**
- **ยอดช่วงเช้า 10–12 น. บางมาก** = โอกาสโตง่ายสุด (ที่มาของกลยุทธ์ broadcast เช้า)
- **พีคเย็น 19–21 น. ~35% ของยอด**
- Baseline pilot: ตั้งเป้าดันจาก 20,364 → **24,000 (สัปดาห์แรก)** → 30k
- เป็นตู้ที่ใช้ทดสอบทุกอย่างก่อนขยาย (content pack, sell-through, ads โซนบางแค)

## 🔻 PRB02 ที่หายไป — ตัวอย่าง "ยอดรั่ว" ที่ยกบ่อยสุด
SKU ขายดี (กล่อง Booster Box ราคา **2,800–4,800/บิล**) ที่ถูกถอดออกจากตู้ตั้งแต่ 5 มิ.ย. (เหลือ 0) → ใช้เป็นหลักฐานประจำว่า "ของขายดีที่ถูกถอด = ยอดที่รั่วไปฟรีๆ" และเป็นงานแก้ลำดับแรกใน Operational Excellence

## 📊 ภาพรวมฟลีต — "24% ของศักยภาพ"
ประโยคเปิดที่ใช้ตลอด:
- ยอดรวมฟลีต ≈ **78,600 บาท/วัน** (~2.36 ล้าน/เดือน)
- ศักยภาพเต็ม (ทุกตู้ 30k) = **330,000/วัน** → ตอนนี้ทำได้ **แค่ 24%**
- กรอบ: **"ช่องว่างนี้ = โอกาส ไม่ใช่ปัญหา — สินค้า/ระบบพร้อม แค่ยังไม่มีการตลาด"**

## 🆚 VMS vs WW — หลักฐาน "คนไม่รู้ว่ามีตู้"
ตัวอย่างเปรียบเทียบที่ใช้พิสูจน์ว่าปัญหาคือ awareness ไม่ใช่ของ:
- ตู้ VMS: **39–63 บิล/วัน** · ตู้ WW: **10–21 บิล/วัน** · **สินค้าเหมือนกัน**
- สรุป: ปัญหาตู้ WW คือ "คนไม่รู้ว่ามีตู้" → การตลาดแก้ได้ตรงๆ

## 💎 "ขุมทรัพย์ = ปลุก 7 ตู้ WW"
ตรรกะจัดลำดับโอกาสที่ยกซ้ำ:
- ดัน chukes01 20→30k ได้ **+10k** (เพดานเดียว)
- ปลุก 7 ตู้ WW ตู้ละ +5k = **+35,000/วัน** ← โอกาสใหญ่กว่า ~3 เท่า

## 🎴 One Piece = เครื่องยนต์ทั้งฟลีต
- **OP13 / OP15 / OP16** = สินค้าขายดีอันดับ 1 ทุกตู้ (OP13/15/16 ยอดเกินครึ่งที่ chukes01)
- ผลลัพธ์เชิงกลยุทธ์: **แคมเปญ/คอนเทนต์ชุดเดียวใช้ได้ทั้งระบบ**

## 🔧 OP16 over-allocated — ตัวอย่าง rebalance slot
OP16 ใช้ 8 ช่อง แต่ขายแค่ **5.8/วัน** → ย้าย 2 ช่อง cap12 ไปเป็น OP13/OP15 (ตัวขายดีอันดับ 1–2) · ใช้เป็นตัวอย่างการ rebalance slot ที่กันของช้าเบียดของเร็ว

## 💰 งบแบบเป็นเฟส (ตัวเลขอ้างอิงประจำ)
- **เฟส 1 (เดือน 1–2): 40,000–60,000/เดือน** — พิสูจน์โมเดล
- **เฟส 2 (เดือน 3–4): 80,000–120,000/เดือน** — ขยายสูตรชนะ
- **เฟส 3 (เดือน 5+): ผูกกับยอด** — reinvest ~10–15% ของยอดที่การตลาดดันขึ้น
- อ้างมาตรฐานค้าปลีก = **8–12% ของยอดขาย** (แต่ "เราเริ่มต่ำกว่ามาก")
- เป้าฟลีต: **78,600 → 150,000–180,000/วัน (×2) ใน 6–12 เดือน**
