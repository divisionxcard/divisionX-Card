# Wiki Changes Log

โฟลเดอร์นี้เก็บ "เหตุการณ์สำคัญ" ที่ส่งผลกระทบต่อระบบ — ใช้เป็น **context** ให้ LLM agent เข้าใจว่าทำไมตัวเลขถึงเปลี่ยน

## เมื่อไหร่ควรสร้างไฟล์ใหม่ในโฟลเดอร์นี้?

| เหตุการณ์ | สร้างไฟล์ไหม | Template |
|---------|-----------|----------|
| รับสต็อกล็อตใหม่ปกติ | ❌ ไม่ต้อง (stock_in table มีอยู่แล้ว) | - |
| รับล็อตใหม่ที่ทุนเปลี่ยน +/- 10%  | ✅ ใช่ | `lot-cost-change.md` |
| Reset สต็อกทั้งระบบ | ✅ ใช่ | `_template-stock-reset.md` |
| ย้ายสต็อกระหว่างตู้ปริมาณมาก | ✅ ใช่ | `inter-machine-transfer.md` |
| ปรับราคาขาย SKU | ✅ ใช่ | `price-change.md` |
| เพิ่ม/ปิด SKU | ✅ ใช่ | `sku-lifecycle.md` |
| เพิ่ม/ปิดตู้ | ✅ ใช่ | `machine-lifecycle.md` |
| ทดสอบ/promotion ระยะสั้น | ✅ ใช่ | `promotion.md` |

## โครงสร้างไฟล์

ไฟล์ทั้งหมดควรใช้ naming pattern:

```
YYYY-MM-DD-<short-slug>.md

ตัวอย่าง:
2026-05-22-lot-OP15-cost-up.md
2026-06-01-stock-reset.md
2026-05-30-promo-naruto.md
```

## วิธี LLM Agent ใช้ไฟล์เหล่านี้

ใน prompt ของ agent จะมีคำสั่ง:
```
"ก่อนวิเคราะห์ กรุณาอ่าน wiki/changes/ ในช่วง 30 วันที่ผ่านมา 
 ถ้ามีไฟล์ที่อ้างถึง SKU/ตู้ที่กำลังวิเคราะห์ → ใช้เป็น context"
```

ทำให้ LLM ตีความตัวเลขที่เปลี่ยนแปลงได้ถูกต้อง — แทนที่จะ flag "ผิดปกติ" ทุกอย่าง
