## ต้นเหตุ: `py`

[`.mcp.json`](../../.mcp.json) เขียนว่า

```json
"command": "py",
"args": ["-3", "deploy/mcp/dvx_mcp_server.py"]
```

`py.exe` (Python launcher) อยู่ที่ `%LOCALAPPDATA%\Programs\Python\Launcher\`
ซึ่ง **ไม่อยู่ใน PATH ที่ Claude Code ส่งต่อให้ process ลูก** — ไม่ได้อยู่ใน `C:\Windows\`
อย่างที่หลายเครื่องเป็น และไม่ได้อยู่ใน `WindowsApps` ด้วย

ผลคือทุก session ขึ้น `divisionx (CONNECTION_CLOSED)` — ข้อความนี้บอกแค่ว่า "ต่อไม่ติด"
**ไม่ได้บอกว่าหาไฟล์ไม่เจอ** คนอ่านจึงไปเดาว่า server พัง แล้วลงมือเขียนทางอ้อมแทนที่จะสงสัย PATH

ตัว server ไม่เคยพังเลยสักวัน — สั่งรันด้วย python เต็ม path แล้ว handshake ผ่านทันที:

```
server replied: {'name': 'divisionx', 'version': '1.0.0'}
```
