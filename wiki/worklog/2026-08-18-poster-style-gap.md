# ทำไมคอนเทนต์ถึงไม่ถูกอนุมัติ — คำตอบคือรูป ไม่ใช่แคปชั่น

ตามหาคอขวดกันมาหลายชั้น สุดท้ายเจ้าของบอกตรง ๆ ว่า **ไม่อนุมัติเพราะรูปยังไม่สวยพอ**
ไม่ใช่เพราะข้อความหรือกระบวนการ

## ที่ทำไปในรอบนี้

ไปดูของจริงก่อน — โหลดโปสเตอร์ที่ระบบสร้างมาดู 2 ใบ แล้วพบปัญหาที่ใหญ่กว่าความสวย:

1. **ระบบมีสองภาษาการออกแบบในตัวเอง** — ใบทองอลังการ (กรอบทอง สมอ เข็มทิศ) กับใบฟ้าเรียบ
   โพสต์สลับกันแล้วคนจำไม่ได้ว่าเป็นแบรนด์เดียวกัน
2. **ใบทองขัดกับอัตลักษณ์ที่เจ้าของกำหนดเอง** (ฟ้านีออน+โครเมียม บนกรมท่า ไม่ใช่ดำ-ทอง)
3. ของประดับแย่งซีนจนซองเหลือพื้นที่ ~15% ของภาพ

เจ้าของส่งภาพอ้างอิงมา 4 ใบ (โปสเตอร์ผู้จัดจำหน่าย One Piece TCG) จึงทำ
[`poster_template_v2.html`](../../deploy/tasks/poster_template_v2.html) ตามแนวนั้น:
ดำ-ทอง/แดงคอนทราสต์สูง · ตัดของประดับ · ซองใหญ่ขึ้นเป็นเกือบครึ่งภาพ · แถบ CTA เต็มความกว้าง

ตัวอย่างเทียบของเดิม/ของใหม่เก็บไว้ที่ `docs/poster-samples/`

## บทเรียนจากการเรนเดอร์จริง

**ต้องเรนเดอร์ถึงจะรู้** — สองบั๊กนี้อ่านโค้ดอย่างเดียวไม่มีทางเจอ:

- ตัวสร้าง `{{HERO}}` ฝั่ง Python ส่ง `<div class="stage">` มาเองพร้อม `<img class="refl">`
  เทมเพลตใหม่ตั้งชื่อคลาสรากว่า `.stage` เหมือนกัน → CSS กรอบเต็มภาพไปโดนกล่องซอง
  **ได้ซองซ้อนสองใบเต็มภาพ** · แก้โดยเปลี่ยนชื่อรากเป็น `.poster`
- รูปตู้ที่วางมุมซ้ายล่างทับข้อความจุดขายข้อสาม → ซ่อนรูปตู้เมื่อมีรูปสินค้าแล้ว
  (ภาพอ้างอิงที่เจ้าของเลือกก็ไม่มีรูปตู้เลยสักใบ)

## 🔴 ช่องว่างจริงที่ปิดด้วยการแต่งเทมเพลตไม่ได้

ภาพอ้างอิงทั้ง 4 ใบมี **การ์ดจริงรายใบเรียงเป็นกริด 6-8 ใบ** เป็นหัวใจของงาน

คลังรูปของเรามี: **ซอง 45 ตัว · กล่อง 40 ตัว · การ์ดรายใบ 0**

ต่อให้จัดหน้าเก่งแค่ไหน "ซองเดี่ยวใหญ่ ๆ" ก็เป็นคนละพลังกับกริดการ์ด
**นี่คือปัญหาเรื่องวัตถุดิบ ไม่ใช่ปัญหาเรื่องโค้ด** — เจ้าของจึงตัดสินใจพักไว้ก่อน ซึ่งถูกแล้ว

## สถานะที่ทิ้งไว้

- **เทมเพลตหลักไม่ได้เปลี่ยน** — v2 เรียกได้ด้วย `--template` เท่านั้น ระบบเดิมทำงานเหมือนเดิมทุกอย่าง
- สายพานที่เหลือ (ตรวจ → อนุมัติ → ลงปฏิทิน → โพสต์เอง → เก็บผล) ทำงานได้ครบ
  **ไม่ผูกกับว่าใครเป็นคนทำรูป** — ถ้าเจ้าของหรือกราฟิกทำรูปมาเอง ระบบรับช่วงต่อได้ทันที

## ถ้าจะกลับมาทำต่อ ต้องเริ่มที่วัตถุดิบ

1. หาแหล่งรูปการ์ดรายใบต่อชุด (งานหาแหล่ง ไม่ใช่งานเขียนโค้ด — ต้องคุยเรื่องที่มาของรูปก่อน)
2. หรือถ่ายเอง: การ์ดที่เปิดได้จากตู้จริง ซึ่งได้ของแถมคือ "ของจริงจากตู้เรา" ที่โปสเตอร์คู่แข่งไม่มี
3. หรือจ้างกราฟิกทำ key visual ประจำชุด แล้วให้ระบบวางข้อความ/ตัวเลขจากฐานข้อมูลทับ
