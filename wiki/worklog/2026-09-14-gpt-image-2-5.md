# ระบบสร้างโปสเตอร์เปลี่ยนเป็น GPT Image 2.5 (Flare)

เจ้าของสั่ง: *"ช่วยปรับระบบการเชื่อม API การสร้างรูป เป็น ChatGPT image 2.5"*

OpenAI ออก ChatGPT Images 2.5 เมื่อ 8 ก.ย. 2026 · ใน API แยกเป็น 2 รุ่น ราคาต่อ token เท่ากัน

| รุ่น | ตำแหน่งที่ OpenAI วางไว้ |
|---|---|
| `gpt-image-2.5-flare` | ตัวเริ่มต้นที่แนะนำ · เร็วกว่า Images 2.0 ราวครึ่งหนึ่ง |
| `gpt-image-2.5-sunburst` | ตัวละเอียด คุมการแก้ภาพแน่นกว่า · ใช้เวลานานกว่า |

## ทำไมเลือก Flare ไม่ใช่ Sunburst

route สร้างภาพรันบน Vercel ที่มีเพดาน 300 วิ และ `gpt-image-2` เดิมก็ใช้ไป 145-153 วิแล้ว
ตัวที่ "นานกว่า" เสี่ยงโดนตัดหลังวาดเสร็จ = จ่ายเงินแต่ไม่ได้ภาพ และไม่เหลือเวลายิงซ้ำ
ตอนโดนตัวกรองเนื้อหาบล็อก (ซึ่งเกิดแบบสุ่มจริง ดู [[2026-08-27-ai-becomes-primary]])

อยากลอง Sunburst เปลี่ยนแค่ `openai_model` ใน `deploy/tasks/image_style.json` — ไม่ต้องแตะโค้ด

## ตรวจก่อนแก้ (ฟรีทั้งหมด)

- `GET /v1/models/<id>` → key ของเราเข้าถึงได้ทั้ง 2 รุ่น
- **ไม่มี `OPENAI_IMAGE_MODEL` ตั้งทับ** ทั้งใน Vercel และ `.env.local` — ถ้ามี แก้ JSON ไปก็ไม่มีผล
- เครดิตคงเหลือราว **$2.91** (ยอด $4.22 ที่บันทึก 28 ส.ค. − ค่าใช้จ่าย $1.31 ตั้งแต่นั้น)

### `input_fidelity` — ทดสอบแบบแยกผลไม่ได้

เอกสารคู่มือไม่พูดถึงพารามิเตอร์นี้เลย ลองยิงค่าผิดเพื่อดู error (คำขอที่ถูกปฏิเสธไม่เสียเงิน):

```
input_fidelity=bogus                → ทั้ง 3 รุ่น: "Supported values are: 'high' and 'low'"
input_fidelity=high + quality=bogus → ทั้ง 3 รุ่น: error เรื่อง quality
```

ตัวควบคุมคือ `gpt-image-2` ซึ่งพิสูจน์แล้ว 19 ส.ค. ว่า**ปฏิเสธ**พารามิเตอร์นี้ แต่ก็ได้ผลเหมือนรุ่น 2.5
แปลว่า API ตรวจ "ค่า" ก่อนตรวจ "รุ่นรองรับไหม" — วิธีนี้บอกอะไรไม่ได้ ต้องยิงให้วาดจริงถึงจะรู้

→ เลือกทางที่พิสูจน์แล้วว่าปลอดภัย: **ไม่ส่งให้รุ่น 2.5**

## ยิงจริง 1 ใบ

ส่งแบบเดียวกับที่ route ส่ง: `/images/edits` · 1024×1024 · quality high · แนบซอง PRB 02 จริง
· ไม่ส่ง `input_fidelity` · พาดหัวไทยที่มีวรรณยุกต์ซ้อนสระบน

| | gpt-image-2 (เดิม) | gpt-image-2.5-flare |
|---|---|---|
| เวลา | 145-153 วิ | **26 วิ** |
| ต้นทุน | $0.171-0.209 (1024×1536 / 1024×1280) | **$0.062** (1024×1024) |
| ตัวหนังสือบนซอง | ถูก | ถูกครบ — PRB-02 · BANDAI NAMCO · プレミアムブースター · 対象年齢9才以上 · THE BEST Vol.2 · 全179種+30種 |
| ไทย | ถูก | ถูกทุกตัว — "ชุดใหม่ลงตู้แล้ว" · "ในห้างใกล้บ้าน ไม่ต้องต่อคิว" |

usage: input 1,245 tokens (ภาพ 1,024 · ข้อความ 221) · output 1,756 tokens

⚠️ **ใบเดียวไม่ใช่หลักฐานว่าผ่านเสมอ** · ต้นทุนเทียบกันไม่ตรงเป๊ะเพราะขนาดภาพต่างกัน
· response ของ API **ไม่มีฟิลด์ `model`** — ยืนยันรุ่นที่ใช้จริงได้จาก `attempts` ที่ route คืนเท่านั้น

## แก้โค้ด 2 จุดที่จะพังถ้าเปลี่ยนรุ่นเฉย ๆ

### 1. เงื่อนไข `input_fidelity` ถูกโดยบังเอิญ

```js
if (style.openai_input_fidelity && !/^gpt-image-2/.test(model))   // เดิม
```

รุ่น 2.5 ขึ้นต้นด้วย `gpt-image-2` เลยรอดไปได้ **ด้วยความบังเอิญ** ถ้ารุ่นหน้าชื่อ `gpt-image-3`
จะโดนส่งพารามิเตอร์ไปแล้วพังซ้ำรอย 19 ส.ค. → เปลี่ยนเป็น**รายชื่อที่อนุญาต**
`openai_input_fidelity_models: ["gpt-image-1", "gpt-image-1.5"]` รุ่นใหม่ปลอดภัยโดยปริยาย

### 2. ตัวดัก error ที่เคยกลืนปัญหาพารามิเตอร์

ตัวดักเดิมเจอ 400 ที่ข้อความมีคำว่า `model` → ถือว่ารุ่นนี้ตาย → เลื่อนไปตัวสำรองเงียบ ๆ
error เรื่องพารามิเตอร์ส่วนใหญ่มีคำว่า model อยู่ด้วย **นี่คือบั๊กที่ทำให้ภาพทุกใบมาจาก gpt-image-1.5
ทั้งที่ตั้งใจใช้ gpt-image-2** และตอนเปลี่ยนรุ่นคือช่วงที่พารามิเตอร์ไม่เข้ากันโผล่มากที่สุด

→ OpenAI ระบุชื่อพารามิเตอร์ที่ผิดใน `error.param` (เห็นจากการทดสอบข้างบน) ถ้ามีและไม่ใช่ `model`
ให้ throw ออกไปให้เห็นทันที ไม่เลื่อนรุ่น

## ที่ไม่ได้ทำ

- **ไม่ลด `MIN_GEN_MS` (170 วิ)** แม้ Flare จะใช้ 26 วิ — เพดานใช้ร่วมกันทุกรุ่นในคิว
  ถ้า Flare ล้ม ตัวสำรองลำดับแรก `gpt-image-2` ยังต้องใช้ ~150 วิ
  ที่ได้จากความเร็วคือ ตอนนี้ยิงซ้ำหลังโดนตัวกรองบล็อกได้จริง 1-2 รอบ
- **ไม่ทดสอบ Sunburst** — ประหยัดเครดิตที่เหลือน้อย
- **ยังไม่ได้กดสร้างจากหน้าเว็บจริง** — การกดจะเขียนรูปทับคอนเทนต์จริง จึงให้เจ้าของเลือกใบเอง
