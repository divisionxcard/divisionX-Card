# ให้ AI เขียนแคปชั่นจริงจากไอเดีย

## บริบท (why)
กด "เริ่มทำคอนเทนต์" แล้วได้แค่บรรทัดโจทย์ (`มุมที่จะเล่า`) ยังต้องไปรัน
`content_suggester.py` ในเครื่องเองอยู่ดี — เจ้าของบอกว่าอยากได้ **แคปชั่นจริงมาให้ตรวจเลย**
ก่อนกดอนุมัติ ซึ่งตรงกับธีสิสของหน้านี้ที่ว่าคนควรทำแค่ "ตัดสินใจ" ไม่ใช่ "ผลิต"

## สิ่งที่ทำ
- `POST /api/marketing/content/generate` — เรียก Ollama บนเครื่อง (ฟรี) แล้ว
  อัปเดต caption + เลื่อน `draft` → `pending`
- โทนแบรนด์อยู่ใน `deploy/tasks/content_voice.json` ปรับได้โดยไม่ต้องแก้โค้ด
  (กลั่นจาก [[04-voice-style]] — วลีติดปาก + โทนโหมดโซเชียล)
- UI: เลือกไอเดีย → ร่างขึ้นกล่องทันทีพร้อมป้าย **"AI กำลังเขียน…"** แล้วแคปชั่นมาทับ
  ไม่รอ generate ให้เสร็จก่อน (ไม่งั้นปุ่มค้างเป็นนาที) · มีปุ่ม "เขียนใหม่" ด้วย

## 🐛 บั๊กภาษา — สั่งเฉย ๆ ไม่พอ ต้องให้ตัวอย่าง

ตอน seed เคยเจอโพสต์ภาษาญี่ปุ่นหลุดเข้าคิว คราวนี้ไล่หาสาเหตุจริงจัง

**ทดสอบ 1** — prompt สั่งชัดว่า *"เขียนภาษาไทยเท่านั้น ห้ามภาษาญี่ปุ่น/อังกฤษทั้งประโยค"*
qwen2.5:14b ตอบกลับมาเป็น**ภาษาจีนทั้งโพสต์**:

```
🎉海岛首个《航海王》卡牌快闪店开张啦！…DivisionX Card的《航海王》OP-13系列正在等你来开箱哦～
ตรวจภาษา: ไทย 0 ตัว · จีน 68 ตัว
```

**ทดสอบ 2** — เพิ่ม *ตัวอย่างแคปชั่นภาษาไทย* ใน prompt + ย้ำคำสั่งภาษาไว้ท้าย user message

| โมเดล | ผล | เวลา |
|---|---|---|
| qwen2.5:14b | ✅ ไทย 60 ตัว · จีน 0 | 13 วิ (เดิม 28) |
| qwen2.5:7b | ✅ ไทย 98 ตัว · จีน 0 | 13 วิ |

> **บทเรียน:** qwen เป็นโมเดลจีน การสั่งเป็น "ข้อความ" ไม่ชนะ prior ของโมเดล
> ต้อง**ให้ตัวอย่างในภาษาที่ต้องการ** ถึงจะยึดได้ · ผลพลอยได้คือเร็วขึ้นเท่าตัว
> (เดาว่าเพราะโมเดลไม่ต้องลังเลเรื่องรูปแบบเอาต์พุต)

**ด่านสุดท้าย:** ถึงจะแก้ prompt แล้ว ก็ยังนับอักษรไทย/จีนก่อนบันทึกอยู่ดี
ถ้าไม่ผ่านคืน 422 **ไม่เขียนลง DB** — กันโพสต์ผิดภาษาหลุดเข้าคิวซ้ำรอยเดิม

## จุดตัดสินใจ
- **เลือก Ollama ไม่ใช่ Claude** — ฟรี และเครื่องนี้มี qwen2.5:14b อยู่แล้ว
  แลกกับข้อจำกัดว่าใช้ได้เฉพาะตอนเปิดเว็บบนเครื่องที่มี Ollama
  ถ้า deploy Vercel จะคืน **503 พร้อมข้อความอธิบาย** ไม่ใช่ error งง ๆ
  (มี TODO คาไว้ในไฟล์ว่าจะต่อ Claude ยังไงถ้าจะให้ทำงานบน Vercel)
- **ไม่รอ generate ให้เสร็จก่อนตอบ** — 13-60 วิเป็นเวลานานเกินจะให้ปุ่มค้าง
  ร่างขึ้นกล่องก่อน แล้วแคปชั่นมาทับทีหลัง
- **ตัวอย่างโทนอยู่ในไฟล์ config ไม่ใช่ในโค้ด** — เจ้าของปรับเสียงแบรนด์เองได้
