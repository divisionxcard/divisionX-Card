# ให้ AI เขียนแคปชั่นจริงจากไอเดีย

## บริบท (why)
กด "เริ่มทำคอนเทนต์" แล้วได้แค่บรรทัดโจทย์ (`มุมที่จะเล่า`) ยังต้องไปรัน
`content_suggester.py` ในเครื่องเองอยู่ดี — เจ้าของบอกว่าอยากได้ **แคปชั่นจริงมาให้ตรวจเลย**
ก่อนกดอนุมัติ ซึ่งตรงกับธีสิสของหน้านี้ที่ว่าคนควรทำแค่ "ตัดสินใจ" ไม่ใช่ "ผลิต"

  อัปเดต caption + เลื่อน `draft` → `pending`

  (กลั่นจาก [[04-voice-style]] — วลีติดปาก + โทนโหมดโซเชียล)
- UI: เลือกไอเดีย → ร่างขึ้นกล่องทันทีพร้อมป้าย **"AI กำลังเขียน…"** แล้วแคปชั่นมาทับ

## 🐛 บั๊กที่ 2 — ข้อความ error ชี้ผิดทาง (25af2f3)

เจ้าของกดแล้วเจอ *"ต่อ Ollama ไม่ได้ — เปิดแอป Ollama บนเครื่องนี้ก่อน"*
แต่ไล่ดูแล้ว **Ollama เปิดอยู่และต่อได้ปกติ**:

```
curl localhost:11434        → 200
node fetch localhost:11434  → qwen2.5:14b, qwen2.5:7b ✅
node fetch 127.0.0.1:11434  → ✅   (ตัด IPv6/IPv4 ออกไป)
pipeline เต็มจาก cwd ของ dev server → 36 วิ · ไทย 183 ตัว · ผ่าน ✅
```

**ต้นเหตุอยู่ในโค้ดผมเอง** — ตัวจับ error เขียนไว้ว่า:

```js
const offline = /ECONNREFUSED|fetch failed|aborted|ENOTFOUND/i.test(String(e))
```

`aborted` คือ **timeout** ไม่ใช่ต่อไม่ติด → พอโมเดลเขียนนานเกิน 3 นาที
ระบบไปขึ้นข้อความว่า "เปิดแอป Ollama ก่อน" ทำให้ไล่ผิดทางทั้งหมด

**แก้:** แยกเป็น 2 ด่านคนละความหมาย
- `probeOllama()` เช็กก่อนเริ่มงานยาว (timeout 5 วิ) — ต่อไม่ได้ → **503** พร้อมบอก host ที่ลองต่อ
  และเช็กด้วยว่ามีโมเดลที่ตั้งไว้จริงไหม ถ้าไม่มีก็บอกชื่อโมเดลที่มี + คำสั่ง `ollama pull`
- ผ่าน probe แล้วพังตอนเขียน → **504** "เขียนไม่เสร็จใน 3 นาที" + แนะให้ลดเป็น 7b

> **บทเรียน:** ข้อความ error ที่เดาสาเหตุผิด แย่กว่าข้อความที่บอกว่าไม่รู้สาเหตุ
> เพราะมันพาไปแก้ผิดจุด — ควรแยกด่านให้ชัดว่าอะไรพังตรงไหน
