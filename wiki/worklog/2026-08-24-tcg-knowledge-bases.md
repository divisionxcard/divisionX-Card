เจ้าของขอให้ค้นข้อมูลค่ายที่ยังไม่มีคลังความรู้ให้ครบข้ามคืน

มีคลังแล้ว 2 ค่าย (One Piece 22 SKU · Pokemon 3 SKU)

## ทำอะไรไปแล้ว

### 1. Dragon Ball Fusion World — `dbfw_kb.py`

ค่าย **9 SKU มากสุด** และเป็นค่ายเดียวนอกจาก One Piece ที่มีเว็บทางการภาษาไทย

โครงต่างจาก One Piece แม้เป็น Bandai เหมือนกัน (คนละ codebase):

| | One Piece | Fusion World |
|---|---|---|
| รายชื่อชุด | `<option value>` | `<li><a data-val>` |
| ขอ cardlist | POST `series=` | GET `?search=true&category[]=` |
| ข้อมูลการ์ด | มาพร้อมหน้ารายการ | ต้องยิง `detail.php` แยกรายใบ |

**บั๊กที่เจอตอนเขียน:** หั่น HTML ด้วยการ split ที่ `cardDataCell` แล้วเนื้อหาแต่ละช่อง
ล้ำไปช่องถัดไป — ช่อง "หาได้ที่ไหน" ลากยาวไปถึงเมนูท้ายเว็บ
แก้ด้วยการนับความลึกของ `<div>` เพื่อหาแท็กปิดของตัวเอง ใช้ regex ตัดที่ `</div>` ตัวแรกไม่ได้
เพราะหลายช่องมี div ซ้อน (สีมี `colValue` · คุณสมบัติมี `is-front`/`is-back`)

เพิ่มแคชรายใบไว้ด้วย มี ~2,300 ใบ ถ้าไม่แคชแล้วรันซ้ำจะเสียเวลา 40 นาทีทุกรอบ

### 2. KAYOU (Naruto + MLP) — `kayou_kb.py` · 24 ซีรีส์ 2,953 ใบ

เขียนตัวเดียวได้ 2 ค่าย 6 SKU เพราะใช้ payload เดียวกัน

**กับดัก 2 ข้อที่ตัวตรวจจับได้ก่อน:**

1. คีย์จริงคือ `editions` ไม่ใช่ `products` — และเป็น **list หลายเวอร์ชันกล่อง**
   Heaven Scroll S1 มี 5 เวอร์ชัน · Moon Edition S2 มี 7 เวอร์ชัน
   อัตราออกการ์ดไม่เท่ากัน **ห้ามหยิบ `[0]` มาใช้แทนทั้งหมด**

2. ถอด escape ด้วย `replace('\\"','"')` **พังทุกหน้าของ Naruto**
   เพราะเจอ `Who\'s Top Dog` ซึ่ง `\'` ถูกกฎ JS แต่ผิดกฎ JSON
   ต้องแปลง `\'` ก่อน แล้วให้ `json.loads` ถอดที่เหลือ (`\\n` `\\uXXXX`) เอง
   — MLP ผ่านหมดเพราะบังเอิญไม่มี apostrophe ในชื่อการ์ด ถ้าเทสต์แค่ MLP จะไม่เจอบั๊กนี้

### 3. Yu-Gi-Oh OCG — `ygo_kb.py` · 4 ชุด 300 ใบ

**กับดักการแบ่งหน้า ทดสอบแล้วเจอจริง:**

```
rp=100   → ได้แค่ 53/28/28/30 ใบ   ← ตัดข้อมูลเงียบ ๆ
rp=99999 → ได้ 80/80/80/60 ใบ      ← ตรงกับที่ทางการประกาศ
```

เคสเดียวกับ PostgREST 1000 แถวที่เคยทำยอดขายหาย 82,000 บาท (ดู [[dvx-db]])
สคริปต์จึงเทียบจำนวนกับ `expected_count` ทุกครั้ง ไม่ตรงคือเตือนทันที

ข้อมูลเป็นภาษาญี่ปุ่นล้วน — ทดสอบ `request_locale=en/ko` แล้วคืน 0 ใบ
เพราะสินค้าเราเป็นซองพิมพ์ญี่ปุ่นจริง

## Hermes — ตั้งงานข้ามคืน แต่เจอว่าค้นเว็บไม่ได้เลย

ก่อนปล่อยงานทิ้งไว้ ยิงทดสอบหนึ่งครั้งแล้วได้ error:
*Your Nous Portal account has no usable paid credits*

ระบบเลือก Firecrawl อัตโนมัติเพราะ probe ของ Nous ตอบว่าพร้อม ทั้งที่ไม่มีเครดิต
**พังแบบเงียบ** — cron รันผ่าน สถานะ ok แต่ไม่ได้ข้อมูล
ถ้าไม่ทดสอบก่อน เช้ามาจะได้ไฟล์เปล่า 9 รอบ

แก้ด้วยการติดตั้ง `ddgs` (DuckDuckGo ฟรี) + ตั้ง `web.backend` ใน config
รายละเอียดอยู่ใน memory [[reference_hermes_web_search]]

### สาเหตุจริงที่ Hermes ค้นข้อมูลไม่แม่น — ไม่ใช่เพราะโมเดลฟรี

ยิงทดสอบเองแล้วระบบตอบตรง ๆ ว่า

> DuckDuckGo (ddgs) is a **search-only backend and cannot extract URL content**

Hermes จึงเห็นแค่คำโปรย ~200 ตัวอักษรต่อผลลัพธ์ แล้วต้องเดาเนื้อหาที่เหลือเอง
ซ้ำร้ายผลค้นเองก็แย่ — ค้น "Dragon Ball Fusion World official card list"
ได้ **Mercari กับ TikTok** ไม่ใช่เว็บทางการ Bandai ที่มีอยู่จริง

> เปลี่ยนโมเดลไม่ช่วย — โมเดลฉลาดแค่ไหนก็สรุปจากคำโปรย 3 บรรทัดให้แม่นไม่ได้

### แก้แล้ว — เปลี่ยนไปใช้ Tavily (บ่ายวันเดียวกัน)

เจ้าของสมัคร Tavily ให้ (ฟรี 1,000 ครั้ง/เดือน ไม่ต้องผูกบัตร) ตั้งค่าใน
`hermes/.env` + `hermes/config.yaml` แล้ว **ผลต่างวัดได้ทันที**:

| | ddgs (เดิม) | Tavily |
|---|---|---|
| ผลอันดับต้นเมื่อค้นเว็บทางการ Dragon Ball | Mercari · TikTok | **dbs-cardgame.com · dragon-ball-official.com** |
| ความยาวคำโปรย | ~200 ตัวอักษร | ~1,000–1,400 |
| อ่านหน้าเว็บเต็ม | **ทำไม่ได้เลย** | ได้ 3,432 และ 12,981 ตัวอักษร |

**ไม่ต้อง restart gateway** — ทั้งสองไฟล์แคชด้วย mtime+size
พิสูจน์ด้วยการรันโดยไม่ยัดคีย์เข้า `os.environ` เลย ระบบยังหาเจอจาก `.env` เอง

เขียนกฎลง `hermes/SOUL.md` ด้วย 5 ข้อ — **อ่านคลังความรู้ใน `deploy/tasks/` ก่อนไปค้นเว็บ** ·
ห้ามสรุปจากผลค้นหาต้อง `web_extract` ก่อน · ห้ามพิมพ์ URL เอง ·
เว็บทางการชนะบล็อกร้านค้า · ไม่รู้ให้บอกว่าไม่รู้

⚠️ ถ้าโควตาหมด ระบบจะตกกลับไป ddgs **เงียบ ๆ** — อาการคือคุณภาพคำตอบตกฮวบโดยไม่มี error

### ทำไมไม่เลือก Perplexity

เจ้าของถามถึง Perplexity ตรวจเอกสาร API เขาแล้ว **ไม่มีพารามิเตอร์ `tools`** เลย
ใช้เป็นสมองของ Hermes ไม่ได้ เพราะ Hermes ต้องให้โมเดลเรียกเครื่องมือเอง
(อ่านไฟล์คลังความรู้ · ดึงยอดขาย/สต็อกผ่าน MCP)

ส่วน Search API ของเขาคืนแค่ snippet ไม่ใช่หน้าเต็ม · ไม่มี free tier ($5/1,000 ครั้ง) ·
และ Hermes ไม่รู้จักชื่อ backend `perplexity` ต้องแก้โค้ด → Tavily ชนะทุกข้อ
