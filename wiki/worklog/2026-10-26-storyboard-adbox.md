## 1. คลังรูปแบบไวรัล (`deploy/tasks/video_patterns.json`)

8 รูปแบบ ทุกแบบมีหลักฐานจากข้อมูลเรา:

| รูปแบบ | หลักฐานเด่น |
|---|---|
| ของเข้าตู้ + ตามล่าใบเด่น | เพจคู่แข่งตู้การ์ด 9.4× · 5.6× · 3.8× |
| ความเชื่อใจ: ของแท้ ลุ้นเอง | เพจคู่แข่งตู้การ์ด 70.2× · หัวข้อความเชื่อใจมัธยฐาน 3.3× |
| เกาะอีเวนต์ / วันวางขาย | เพจทางการ 9.0× · งานแข่ง 7.2× |
| 3 อันดับ นับถอยหลัง (strict) | ร้านการ์ด 2.1× · 1.9× |
| รู้จัก X ใน 30 วิ | YouTube 291 วิว/ชม. |
| ท้าเลือก A/B | YouTube แนวท้าลอง/พิสูจน์ 27,551 · 13,030 วิว/ชม. |
| เรื่องเล่าสนุกในโลกค่าย | YouTube 1,737 วิว/ชม. |
| ทายจากใบ้ แล้วเฉลย | YouTube 700 วิว/ชม. |

- `trust_facts` = ข้อความความเชื่อใจที่ใช้ได้ (ซองปิดผนึก ของแท้ 100% · กดเองไม่ต้องต่อคิว · จ่าย QR · เช็กหน้าเว็บ) — **"ไม่คัดซอง" ยังไม่ยืนยัน = ห้าม**

## 2. ตัวเขียนสตอรี่บอร์ด (`lib/storyboard.js` + `/api/video/storyboard`)

ไอเดีย + สินค้า/สต็อก/สาขาจริง + รูปแบบ (หมุนไม่ซ้ำ 3 ร่างล่าสุด) → Gemini → `compile` → ร่าง R2 `video-edits/` → `/video/editor?id=`
- ภาพเลือกจาก **รายการที่มีจริง** เท่านั้น: ซองจริง (`sku:`) · รูปตู้สาขา (`assets/branches/`) · รูปตู้ · ภาพฉากในคลัง **เฉพาะค่ายเดียวกัน** · คลิป Flow
- กันคำต้องห้าม (เช็กหน้าตู้ · เบอร์เก่า · ยอดขาย/% ยกเว้น "ของแท้ 100%" · ไม่คัดซอง) → ตัดฉากทิ้ง · ลบตัวเลขยอดขายภายในก่อนส่ง AI · ห้ามชื่อร้านอื่น
- **ผูกกับบรรทัดเสียงพากย์** (`line`/`span` — ดู `agents/video/TIMELINE.md`): runner ตั้งเวลาตามเสียงจริง (`hf_timeline.anchor`) · คนแก้เวลาเอง = ถอดการผูก

ข้อผิดพลาดที่เจอตอนทดสอบกับไอเดียจริง (แก้แล้ว):
1. ไอเดีย "OP-17 มาแรง" ได้ 3 อันดับ → AI **จัดอันดับ OP-16/PRB-01 ขึ้นเอง** ทั้งที่ไม่มีข้อมูล → รูปแบบที่ต้องมีข้อมูลเฉพาะเป็น `strict`
2. "เก้าสิบหุกงาน" — สะกดตัวเลขเป็นคำผิด → บังคับเขียนเป็นตัวเลข ให้เสียงพากย์อ่านเอง
3. "ของแท้ 100%" โดนตัดเพราะตัวกันเปอร์เซ็นต์ → ยกเว้น (และแก้ regex ไม่ให้เริ่มจับกลางตัวเลข "00%")
4. สลับรูปซองเลี่ยงภาพซ้ำ → พูดถึง OP-17 แต่โชว์ OP-13 → สลับได้เฉพาะภาพฉาก/คลิปบรรยากาศ
5. AI เอ่ยชื่อร้านการ์ดที่จัดแข่ง → ห้ามชื่อร้าน/เพจ/แบรนด์อื่น
6. ทัวร์นาเมนต์ One Piece ได้ภาพฉากฟ้าชมพูของโพสต์โปเกมอน → ไล่ค่ายของภาพจากคอนเทนต์ต้นทาง ใช้เฉพาะค่ายเดียวกัน
7. ` ` ใน regex ถูกเครื่องมือเขียนไฟล์แปลงเป็นอักขระจริง (กับดักเดิม) → `\u{a0}` + ธง `u`

**ผลรันจริงบน GitHub** (ร่างทัวร์นาเมนต์ One Piece · ไม่เสียเงิน): เสียงพากย์จริง 17.4 วิ (ประมาณไว้ 24.5) · ผูกบรรทัด 10 ชิ้น ·
คลิปยาว 18.0 วิ พอดีเสียง · ด่านตรวจผ่าน 6/6 · ภาพรวมเฟรม: ตัวหนังสือขึ้นตรงบรรทัดที่พูดทุกฉาก
(ถ้าไม่ผูก ท้ายคลิปค้างเงียบ ~7 วิ และตัวหนังสือคลาดจากเสียง)

## 3. กล่องส่งแอด (`/api/video/ads` · หน้า /video โหมดจากไอเดีย)

- ทีมแนบภาพแคป/คลิปอัดจอ (≤ 18 MB · PUT ตรงเข้า R2 `research/ads/` ส่วนตัว) + ลิงก์ + วันที่เริ่มวิ่ง + หมายเหตุ
- Gemini ดูไฟล์ → โครง (เปิด · จังหวะ · ตัวหนังสือ · ปิด · ทำไมได้ผล · ร้านเราทำได้ไหม) + รูปแบบที่เสนอ (ห้ามลอกข้อความเขา)
- "เพิ่มเข้าคลังรูปแบบ" → `research/video-patterns-extra.json` → ตัวเขียนสตอรี่บอร์ดอ่านรวม · หลักฐาน = แอดวิ่งมากี่วัน
- ทดสอบ: คลิป 14 MB ถอดได้ใน 13 วิ ถูกโครง (คำถามชวนคิด → อธิบายเป็นขั้น → ชวนคอมเมนต์) → เพิ่มเข้าคลังแล้วตัวเขียนเห็น · ลบข้อมูลทดสอบแล้ว

## 4. ให้ระบบออกแบบ: เคลื่อนไหว 4 + ไวรัล 9 + "AI คิดเองอิสระ" (บ่าย 26 ต.ค.)

เจ้าของส่งภาพปุ่ม 4 รูปแบบ: *"ไอเดียที่มีให้เลือกค่อนข้างจำกัดมากในการให้ AI เขียน อยากให้มีหลากหลายและอิสระในการทำให้มากกว่านี้"*

- โหมด "ให้ระบบออกแบบ" มีปุ่มรูปแบบไวรัล (พร้อมหลักฐาน) + **✨ AI คิดเองอิสระ** (ไม่มีโครงบังคับ ดูคลังเป็นแรงบันดาลใจ)
  · "ให้ระบบเลือก" = สุ่มจากทุกแบบ (เคลื่อนไหว 1/3 · สตอรี่บอร์ด 2/3) · ระบบเลือกไอเดียเด็ดที่ยังไม่เคยทำเอง (ไม่ซ้ำ 15 ร่างล่าสุด)
  · ดูแผนก่อน → การ์ดแผน → **อนุมัติ · เริ่มทำคลิป** (ไม่ต้องเข้าห้องตัดต่อ) · เปิดแก้ในห้องตัดต่อ · คิดแบบใหม่
- AI ออกแบบหน้าตาเองต่อฉาก: style · pos (ไม่ทับซับ y ≈ 0.69–0.78) · size · anim · cut · motion · **sticker** (รูปซองลอยทับภาพฉาก)
  · รูปแบบในคลังเป็นแนวทาง สลับ/รวม/เพิ่ม/ตัดฉากได้ — ตาม memory "AI ออกแบบต้องมีอิสระ" (บังคับแค่ความจริง/กฎหมาย/ภาษาไทย)

เจอตอนทดสอบไอเดียจริง (แก้แล้ว):
1. คลิปร้านการ์ดอื่นจัดแข่ง → AI เล่า "ค่าสมัคร 800 บาท" เหมือนงานของเรา · อีกชิ้น "ผมเล่นครั้งแรก ตามที่ (ชื่อร้าน) แนะนำ"
   → กฎ: ห้ามเล่าเรื่อง/ราคา/กิจกรรมของที่อื่นเหมือนของเรา · ห้าม "ผม/เรา" เล่าประสบการณ์คนอื่น · ราคาเป็นบาทในเรื่องจากที่อื่น = ตัดฉาก
2. ชื่อร้านอยู่ใน **หัวข้อ** ไอเดีย ("…เด็คที่กายหงิดแนะนำ") ตัวล้างที่มาไม่ได้แตะ → ลบชื่อช่อง YouTube · เพจที่ตัวเฝ้าเพจติดตาม
   (ยกเว้นเพจทางการของค่าย) · คู่แข่งในเรดาร์ ออกจากหัวข้อ/สรุป/มุม + ตัดฉากที่ยังมีชื่อ
3. ยาว 51 วิ (ต่อท้ายด้วยฉากชวนมาตู้ 3 ฉาก) → งบความยาว: เกินเพดาน+5 วิ ตัดฉากก่อนฉากปิดทีละฉาก · ชวนมาตู้ ≤ 2 ฉาก
4. "สี่สิบหนาที" สะกดตัวเลขเป็นคำผิด + "OP-11 มาแล้ว" ทั้งที่ข้อมูลบอกแค่ "มาแรง" — วันนั้น flash-latest โควตาหมด ตกไป lite
   → เติม `gemini-3-flash-preview` ก่อน lite ใน `lib/geminiText.js` (ยิงทดสอบ 200) · รุ่นนี้ทำตามกฎได้ (ตัวเลขเป็นเลข · ไม่อ้างของใหม่)
