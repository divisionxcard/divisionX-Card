# ทำให้ AI ไม่เขียนคอนเทนต์ซ้ำ — ต้นตอ 3 ชั้นที่ไม่ใช่เรื่อง prompt

## บริบท (why)

เจ้าของขอว่า *"อยากให้ AI พัฒนาการเขียนคอนเทนต์ใหม่ ๆ ต่อยอดจากข่าวที่หามาได้
เพื่อไม่ให้คอนเทนต์ซ้ำ ทำให้ส่งผลกระทบต่อเอ็นเกจเมนต์"*

ท่าแรกที่คิดคือ "แก้ prompt ให้สั่งว่าอย่าซ้ำ" — **แต่ไปดูข้อมูลจริงก่อนแล้วพบว่า
ปัญหาไม่ได้อยู่ที่ prompt เลย** มันอยู่ที่ input ที่ป้อนเข้าไป

## 🔍 ต้นตอ 3 ชั้น (ทุกข้อมีหลักฐานจาก DB)

### 1. `angle` เป็น template ตายตัว
`idea_collector.angle_for()` คืนข้อความจาก 7 แบบตายตัวตาม franchise

```
 8 ครั้ง · เกาะกระแส One Piece — โยงเข้าซอง One Piece ที่มีในตู้ ชวนมาเปิดที่สาขาใกล้บ้าน
 8 ครั้ง · คอนเทนต์เจาะสาขานี้ — โพสต์บอกทำเล/ของที่มี หรือยิงแอดรัศมีรอบห้าง
 7 ครั้ง · เกาะกระแสวงการการ์ด — โยงเข้าตู้ DivisionX ว่ามีอะไรให้เปิดบ้าง
```

ข่าว One Piece 8 ชิ้น → AI ได้โจทย์เดียวกันเป๊ะทุกครั้ง จะไม่ซ้ำได้ยังไง
แถม **#13 คายข้อความ angle กลับมาเป็นแคปชั่นตรง ๆ** (บันทึกลง DB ไปแล้วด้วย)

### 2. `summary` ของข่าวเป็น HTML ดิบ — **28 จาก 28 ชิ้น**
Google News RSS ใส่ `description` มาเป็นแค่ลิงก์:
```html
<a href="https://news.google.com/rss/articles/CBMiUEFV...?oc=5" target="_blank">
```
โค้ดเดิมส่งก้อนนี้เข้า prompt เป็น **"รายละเอียดเพิ่ม"** = ให้โมเดลอ่านขยะ
แปลว่าที่ผ่านมา AI แทบไม่มีเนื้อข่าวจะต่อยอดเลย มีแค่หัวข้อ

### 3. AI ไม่เคยเห็นสิ่งที่ตัวเองเขียนไปแล้ว
```
#1: 🔥 ฟิวชั่นดวลมังกร! 🌋 FB-09 Dragonball Fusion World หมดไว รีบมากดเลยนะ!!
#3: 🔥 ฟิวชั่นดวลมังกร! 🌋 FB-06 Dragonball Fusion World หมดไว รีบมากดเลยนะ!!
```
**ซ้ำกัน 88% ต่างแค่รหัส SKU** — นี่คือของจริงที่เคยผ่านเข้าคิวมาแล้ว

## ❌ ทางที่ลองแล้วไม่เวิร์ก — ดึงเนื้อข่าวเต็ม

"ต่อยอดจากข่าว" ที่ดีที่สุดคือให้ AI อ่านข่าวจริง ลองไปสองทาง:

1. **fetch URL ตรง ๆ** → ได้ JavaScript 34,000 ตัวอักษร ภาษาไทย **0 ตัว**
   Google News เป็นหน้า JS redirect ไม่มี server-side redirect
2. **ถอด article id** (`CBMiT0FV...`) เป็น URL จริง → base64 ถอดได้แต่ข้างในเป็น
   token ทึบ `AU_yqLPobouaCmd...` ไม่มี URL ฝังอยู่

**ตัดสินใจไม่ฝืน** — จะต้องไปเรียก batchexecute ภายในของ Google ซึ่งพังง่ายและ
Google เปลี่ยนบ่อย ไม่คุ้มกับความเปราะที่ได้มา
(ข้อดีคือ `title` ของข่าวยาว ~130 ตัวอักษรและมีเนื้อหาพอสมควรอยู่แล้ว)

## สิ่งที่ทำแทน

**1. สุ่มรูปแบบโพสต์** — `content_formats` 8 แบบใน `content_voice.json`
เกาะข่าว · ตั้งคำถาม · จัดอันดับ · สอนมือใหม่ · เล่าเรื่อง · ของใกล้หมด · เทียบให้เห็น · เบื้องหลัง

สุ่ม 1 แบบต่อการเขียน 1 ครั้ง และ**เลี่ยงแบบที่เพิ่งใช้** → ปุ่ม "เขียนใหม่" ได้ของต่างจริง
แก้/เพิ่มได้ในไฟล์ JSON ไม่ต้องแตะโค้ด

**2. `cleanSummary()`** ล้าง tag/URL/entity ทิ้ง เหลือน้อยกว่า 25 ตัวอักษรถือว่าไม่มีเนื้อ → ไม่ส่ง

**3. ให้ AI เห็นแคปชั่นล่าสุด 8 ชิ้น** เป็นรายการ *"ห้ามเขียนซ้ำแนวนี้"*
ระบุชัดว่าต้องต่างทั้ง **ประโยคเปิด · โครงสร้าง · มุมที่เล่า**
> ต้องเขียนกำกับให้ชัดว่าเอาไว้ "เลี่ยง" ไม่ใช่ "ตัวอย่าง" ไม่งั้นโมเดลจะเลียนแบบยิ่งกว่าเดิม

**4. `angle` เปลี่ยนป้าย** เป็น *"บริบท ห้ามลอกข้อความนี้ไปใช้"* กัน #13 เกิดซ้ำ

**5. ตรวจความคล้ายอัตโนมัติ** — Jaccard บน 4-gram ระดับตัวอักษร
ถอด emoji/แฮชแท็ก/ช่องว่างก่อนเทียบ เพราะ *สองโพสต์ที่ต่างแค่ emoji คือซ้ำในสายตาคนอ่าน*

เกิน 50% → ให้ AI เขียนใหม่อัตโนมัติ 1 รอบด้วยรูปแบบอื่น + บอกว่าไปคล้ายอันไหน
**รับเฉพาะตอนที่คล้ายน้อยลงจริง** ถ้ายังซ้ำก็ขึ้นป้ายเตือนบนการ์ดให้คนตัดสิน — ระบบไม่ทิ้งเอง

## ผลทดสอบ (ข้อมูลจริง · Gemini · ข่าวเดียวกัน 3 รอบ)

| รอบ | รูปแบบที่สุ่มได้ | คล้ายของเก่า |
|---|---|---|
| 1 | เบื้องหลัง | 20% |
| 2 | สอนมือใหม่ | 15% |
| 3 | เทียบให้เห็น | 18% |

คล้ายกันเอง **12–16%** · เทียบกับของเดิมที่ซ้ำกัน **88%**
ตัววัดแยกได้ชัด: คู่ที่ซ้ำจริง 88% · คู่ที่ต่างจริง 0%

ที่น่าสนใจคือ 3 รอบเล่าคนละมุมสนิท — รอบ 2 ถึงขั้นสอนวิธีดูการ์ด SEC/Parallel
ซึ่งเป็นคอนเทนต์ที่ระบบเดิมไม่มีทางเขียนออกมาได้เลยเพราะ angle บังคับให้ "เกาะกระแส" อย่างเดียว

## แถม — บั๊กที่เจอระหว่างทาง
`generate()` ฝั่งเว็บเขียนทับ item ทั้งก้อนด้วย response ที่ไม่มี `sku` embed
→ **ปุ่ม "ใช้รูป SKU" หายหลังกดเขียน** เป็นบั๊กคลาสเดียวกับที่ `patch()` เคยเจอ
และมีคอมเมนต์เตือนไว้แล้วแต่ไม่ได้แก้ที่ `generate()` ด้วย — แก้แล้ว

## บทเรียน
**"AI เขียนซ้ำ" ไม่ค่อยใช่ปัญหาของ prompt — มันคือปัญหาของ input**
ถ้าป้อนโจทย์เดียวกันซ้ำ ๆ ไม่ว่าจะเขียน prompt ดีแค่ไหนก็ได้ของคล้ายเดิม
ก่อนแก้ prompt ให้ไปดูก่อนว่า *สิ่งที่ป้อนเข้าไปมันต่างกันจริงไหม*
