# ปุ่ม SKU ในหน้ายอดขาย — เรียงตามลำดับที่ใช้จัดของจริง

เจ้าของขอปุ่มแทรกระหว่าง "ช่วงวันที่" กับ "ยอดขาย" ที่กล่องรายการขายแยก SKU ต่อตู้
เรียงตามค่ายแล้วตามเลขชุด เพื่อไล่เทียบกับใบจัดของได้ ไม่ใช่เรียงตามตัวอักษร

## กับดักที่ 1 — ลิสต์ที่เจ้าของส่งมาเป็น "ชื่อที่เห็นบนจอ" ไม่ใช่ `sku_id`

ต่างกัน 3 แบบ ถ้าใส่ตรง ๆ จะ**ไม่ error แต่ SKU นั้นตกไปท้ายตารางเงียบ ๆ**

| เจ้าของเขียน | `sku_id` จริง |
|---|---|
| `OP01` `PRB01` `EB01` `FB01` | มีเว้นวรรค — `OP 01` `PRB 01` `EB 01` `FB 01` |
| `PKM M5 Abyss Eye` | **`PKM Ghost`** — เปลี่ยนชื่อแสดงแล้ว id เดิม |
| `YGH The Rivals` | **`YGH The Revals`** — id ยังติดคำสะกดผิดจากหลังบ้าน |

สองตัวหลังมาจากเคสเดียวกับที่ทำให้ตัวตรวจจับ swap เข้าใจผิดว่าเป็นการเปลี่ยนสินค้า
(ดู [[2026-08-19-slot-swap-alerts-missing]]) — ชื่อเปลี่ยนแต่ `sku_id` ไม่เปลี่ยน

ตรวจลิสต์กับ DB แล้ว: 47 ตัว ไม่ซ้ำ ไม่มีตัวไหนสะกดผิด
SKU ที่ใช้งานอยู่แต่ไม่อยู่ในลิสต์มีตัวเดียว (`YGH The Heroes`) → ไปต่อท้าย เรียงตามยอดขาย ไม่หาย

## กับดักที่ 2 — เพิ่มปุ่มอย่างเดียวไม่พอ มีของพังตามอีก 2 อย่าง

โค้ดเดิมสมมติว่า "ตารางนี้เรียงจากมากไปน้อยเสมอ" ซึ่งพอมีโหมด SKU ก็ไม่จริงอีกต่อไป

**แถบสัดส่วน** คำนวณจาก `skuList[0][sortBy]` (แถวแรก = ค่าสูงสุด)
โหมด SKU แถวแรกคือ OP 01 ไม่ใช่ตัวขายดีสุด → แถบเกิน 100%
และ `r["sku"]` ไม่มีอยู่จริง → `NaN`

**เหรียญ 🥇🥈🥉** ติดให้ 3 แถวแรก = "ขายดีสุด"
โหมด SKU จะกลายเป็น **OP 01 ได้เหรียญทองทุกครั้ง** ทั้งที่อาจขายได้น้อย

## เข้าใจโจทย์ผิดหนึ่งรอบ

เจ้าของบอก "ช่องสัดส่วนไม่ต้องมี" → ผมตัดออกทั้งหมด
ที่จริงหมายถึง**ซ่อนเฉพาะตอนกดโหมด SKU** โหมดยอดขาย/จำนวนยังต้องมี

บทเรียนเดิมกับ [[2026-08-19-branches-white-background]] — คำสั่งสั้นที่ตีความได้หลายระดับ
ควรถามหนึ่งคำถามก่อนลงมือ เร็วกว่าทำแล้วรื้อ

## วิธีที่ลงตัว

รวมเงื่อนไขเป็นตัวแปรเดียว `ranked = sortBy !== "sku"` ประกาศระดับ `machines.map`
ให้ `thead` / `tbody` / `tfoot` ใช้ตัวเดียวกัน

`ranked` คุม 4 อย่างพร้อมกัน เพราะทั้งหมดแปลว่า "อันดับตามตัวเลข" ซึ่งโหมด SKU ไม่มี:
หัวตารางสัดส่วน · แถบในแถวข้อมูล · `<td/>` ในแถวรวม · เหรียญ + พื้นเน้น 3 แถวแรก

ถ้าเช็ก `sortBy` แยกกัน 3 ที่ วันหลังแก้แล้วหลุดที่ใดที่หนึ่ง คอลัมน์จะเหลื่อมทันที

## ⚠️ `<td/>` เปล่าในแถวรวมคือจุดที่พลาดง่ายที่สุด

ตอนตัดคอลัมน์ต้องตัด `<td/>` ในแถวรวมท้ายตารางด้วย ถ้าลืม ตัวเลขรวมจะเลื่อนไปหนึ่งช่อง
**โดยไม่มี error ไม่มีอะไรฟ้อง** — เห็นได้ด้วยตาเท่านั้น

จึงนับคอลัมน์ทั้ง 3 แถวทุกครั้งหลังแก้:

```
ranked=true    หัว 8 · ข้อมูล 8 · ท้าย 4 เซลล์ + colSpan 4 = 8 ✓
ranked=false   หัว 7 · ข้อมูล 7 · ท้าย 3 เซลล์ + colSpan 4 = 7 ✓
```
