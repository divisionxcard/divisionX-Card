# ห้องตัดต่อวิดีโอ — สร้างข้ามคืน

เจ้าของลอง Hero AI Studio แล้วชอบ**หน้าตัดต่อ**ของมัน (timeline หลายแทร็ก ·
การ์ดซับแก้ได้รายใบ · ขยับจังหวะตัด · ใส่โลโก้) เลยสั่งก่อนนอน:

> "อยากได้หน้าการใช้งานในรูปแบบนี้ ปรับแต่งแก้ไขรายละเอียดได้ทุกจุด
> ขอแบบละเอียดขั้นสุดที่มืออาชีพเห็นแล้วต้องว้าว แต่คนไม่มีความรู้ตัดต่อก็ใช้ได้"

## ทำไมระบบเราสร้างห้องตัดต่อได้ง่ายกว่าที่คิด

เพราะโรงงานวิดีโอเป็น **plan-driven** ตั้งแต่แรก — คลิปทั้งตัวถูกนิยามด้วย JSON
ก้อนเดียว การ "ตัดต่อ" จึงไม่ใช่การแก้ไฟล์วิดีโอ แต่คือการแก้ `plan.edit`
แล้วเรนเดอร์ซ้ำ ซึ่งเร็วมากเพราะ:

- เสียงพากย์แคชไว้ (ของแพงสุด) — แก้ภาพ/ซับไม่ต้องจ่าย TTS ใหม่
- `edit.timing` ทำให้ข้าม whisper (ของช้าสุด) — คนตัดสินเวลาเองแล้ว ไม่ต้องให้เครื่องเดา

วัดจริง: **แก้ → เรนเดอร์ใหม่ → ได้ mp4 ใน ~25-35 วินาที**

## หลักการที่ตัดสินทุกดีไซน์: "เสียงคือนาฬิกา ภาพคือผู้ตาม"

เสียงพากย์เป็นก้อนต่อเนื่องก้อนเดียว แก้จากห้องตัดต่อไม่ได้ สิ่งที่แก้ได้ทั้งหมด —
จุดตัดภาพ ซับ ภาพประกอบ โลโก้ — ล้วนอ้างเวลาบนเสียง

ผลที่ตามมา: **"สลับฉาก" = สลับภาพ ไม่ใช่สลับเสียง** (เสียงเล่าเรียงเดิมเสมอ)
และ playhead ของทั้งห้องผูกกับ `<audio>.currentTime` ตัวเดียว ไม่มีนาฬิกาซ้อน

## พรีวิวสด — ตัดสินใจที่ทำให้ "ว้าว" เป็นไปได้

mp4 ที่เรนเดอร์แล้วเบิร์นซับลงไปแล้ว — เอามาพรีวิวการแก้ซับไม่ได้ (จะเห็นสองชั้น)

ทางออก: **ไม่ใช้ mp4 พรีวิวเลย** — ประกอบสดจากของที่มีอยู่แล้วในโฟลเดอร์งาน:
`frames/` (ภาพฉาก) + `voice.wav` (เสียง+นาฬิกา) + ซับวาดเป็น HTML + Ken Burns
เป็น CSS transform → ทุกการแก้เห็นผล**ทันที** ไม่ต้องรออะไรเลย
เรนเดอร์จริงค่อยกดเมื่อพอใจ

## เทคนิคมือโปรที่ใส่ให้คนธรรมดาใช้เป็น

- **waveform ใต้จุดตัด** — ช่องเงียบในคลื่นเสียงมองเห็นได้ ตัดภาพลงจังหวะได้เอง
- **snap** — ลากอะไรก็ดูดเข้าจุดตัด/ขอบซับ/วินาทีเต็ม เลิกเล็งเอง
- **reading-speed check** — ซับที่อ่านไม่ทัน (>40 ตัวอักษร/วิ) ขึ้นขอบเหลืองเตือนเอง
- **safe area** — เส้นไกด์โซนที่ UI ของ TikTok บัง จะได้ไม่วางซับใต้ปุ่มไลก์
- **ลากแล้วค่อยบันทึกตอนปล่อย** — undo หนึ่งก้าวต่อหนึ่งการลาก ไม่ใช่ร้อยก้าวต่อ pixel
- **คีย์ลัดพร้อมแถบช่วยจำ** — Space/ลูกศร/S แยกซับ/M รวมซับ/Ctrl+Z
