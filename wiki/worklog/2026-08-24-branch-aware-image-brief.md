# บรีฟภาพรู้แล้วว่าตู้ตั้งอยู่ตรงไหนจริง ๆ ในห้าง

## คำถามที่ตั้งต้น

เจ้าของถามว่า — คอนเทนต์ไหนที่ใช้รูปสถานที่จริง อยากให้ Hermes ไปหาข้อมูล
เกี่ยวกับสถานที่นั้นบนอินเทอร์เน็ตก่อน แล้วค่อยเอากลับมาบรีฟ จะลดความผิดพลาดได้ไหม

## คำตอบ: ไม่ต้องไปหาในเน็ต — เรามีข้อมูลที่แม่นกว่าอยู่แล้ว

`machines.config.branch` เก็บครบทั้ง 12 สาขา ตั้งแต่เมื่อไหร่ไม่รู้ แต่มีของจริง:

```
pf01      ไอคอนสยาม          ชั้น 6  หน้าร้าน Karun Thai Tea
chukes02  เซ็นทรัลพระราม 2   ชั้น 4  หน้าจุดขายป๊อบคอร์น ชั้นโรงหนัง
wwv06     เซ็นทรัลพระราม 2   ชั้น G  ติดบันไดเลื่อน หน้า BreadTalk
wwv05     ซีคอนบางแค         ชั้น 4  ด้านหลัง MK
```

ข้อมูลระดับ "หน้าร้าน Karun Thai Tea" **หาในอินเทอร์เน็ตไม่เจอ** —
เป็นของที่คนไปติดตั้งตู้จดไว้เอง เน็ตให้ได้อย่างมากก็ "ไอคอนสยามเป็นห้างริมเจ้าพระยา"
ซึ่งกว้างเกินกว่าจะช่วยให้ภาพเนียนขึ้น

และต่อให้อยากเรียก Hermes จริงก็เรียกไม่ได้ — route สร้างภาพรันบน Vercel
ส่วน Hermes เป็น Telegram gateway ที่รันบนเครื่องเจ้าของ Vercel ยิงเข้าไม่ถึง

## ปัญหาจริงคือข้อมูลไม่เคยถูกส่งเข้าบรีฟ

บรีฟรู้แค่ **จำนวน** สาขา ไม่เคยรู้ว่าสาขาไหน:

```js
const { data: machines } = await db.from("machines").select("machine_id")...
const branches = (machines || []).length          // 12 — จบแค่นี้
`- Number of branches (real, from database): ${branches}`
```

นี่คือสาเหตุของโปสเตอร์ **#35** ที่เจ้าของทัก — แคปชั่นเขียนว่า
"ไปเดินไอคอนสยามทีไร ก็ต้องแอบแวะมากดซองการ์ดตรงนี้บ้าง"
แต่ภาพวาดตู้ตั้งริมถนนตอนกลางคืน เพราะโมเดลไม่มีทางรู้ว่าไอคอนสยามคือชั้น 6 ในห้าง

## สิ่งที่ทำ

`matchBranch()` เทียบแคปชั่น + ชื่อไอเดีย กับ `display_name` ของทุกสาขา
แบบตัดช่องว่างทิ้งก่อน (`เซ็นทรัลพระราม2` = `เซ็นทรัลพระราม 2`)
บวก alias สำหรับชื่อที่คนเขียนเป็นอักษรโรมันบ่อย (`ICONSIAM`)

เจอ → ต่อท้ายบล็อก `SETTING` ด้วยชั้นและจุดสังเกตจริงของสาขานั้น
ไม่เจอ → ใช้บรีฟห้างกลาง ๆ เหมือนเดิม ไม่บังคับให้เลือกสาขามั่ว

## ทดสอบ

ดึงข้อมูลจริงทั้ง 12 ตู้มารัน **ผ่าน 10/10 เคส** เคสที่ตั้งใจล่อให้พลาด:

| เคส | ทำไมล่อ | ผล |
|---|---|---|
| `เซ็นทรัลเวสต์เกต` vs `เซ็นทรัลเวสต์วิลล์` | prefix ซ้ำกันยาว | แยกถูก |
| `เดอะมอลล์บางแค` vs `ซีคอนบางแค` | ลงท้ายเหมือนกัน | แยกถูก |
| `เซ็นทรัลพระราม2` ไม่เว้นวรรค | ไทยไม่มีช่องว่างคำ | จับได้ |
| `การ์ด One Piece OP-11 มาใหม่` | ไม่ควรจับสาขาไหนเลย | คืน null ถูก |

## ข้อจำกัดที่ยังเหลือ

เซ็นทรัลพระราม 2 มี **2 ตู้** (chukes02 ชั้น 4 · wwv06 ชั้น G) ตอนนี้เลือกตัวแรก
ตามลำดับ `machine_id` — ทั้งคู่เป็นของจริงเลยไม่ผิด แต่ถ้าวันหน้าอยากเจาะจงตู้
ต้องให้คนเลือกตอนสร้างคอนเทนต์
