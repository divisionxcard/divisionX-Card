# หน้าสาขาเปลี่ยนเป็นพื้นขาว + กราฟฟิกพื้นหลัง

ต่อจาก [[2026-08-19-retire-wwv02]] · เจ้าของขอเปลี่ยนพื้นหลังหน้า `/branches` เป็นสีขาว
แล้วตามด้วย "เรียบเกินไป" จึงใส่กราฟฟิกเพิ่ม

## บทเรียนของผม: ตีความคำว่า "พื้นหลัง" กว้างเกินไป

เจ้าของพิมพ์ว่า "ปรับสีพื้นหลังของหน้านี้เป็นสีขาวได้ไหม" ผมอ่านแล้วเข้าใจว่า
**ธีมทั้งหน้า** เลยลงมือแยก `BranchesView.jsx` ออกมาใช้ร่วมกัน สร้างหน้า `/branches-light`
ไว้เทียบ เขียนชุดตัวแปรสีโทนขาวครบทั้งชุด (การ์ด ปุ่ม ป้ายชั้น ขอบ เงา)

เจ้าของต้องส่งภาพหน้าจอ**ตีลูกศรแดงชี้ที่ขอบซ้ายกับขอบขวา**มาบอกว่า
"ผมหมายถึงเฉพาะพื้นหลังนี้ ไม่เกี่ยวกับจุดอื่น"

ของจริงคือแก้ **2 บรรทัด** ลบที่ทำไปทั้งหมดทิ้ง

**ที่ควรทำตั้งแต่แรก:** คำว่า "พื้นหลัง" มีความหมายได้หลายระดับ (พื้นหน้า / พื้นการ์ด / ธีมทั้งหน้า)
ถามหนึ่งคำถามสั้น ๆ ก่อนแตะโค้ดจะเร็วกว่าทำเผื่อไปทั้งชุด
สังเกตว่าตอนเลือกลายพื้นหลังผมถามก่อน แล้วงานจบรอบเดียว — ต่างกันชัด

## สิ่งที่แก้จริง

```
main            background → #FFFFFF (ทับเฉพาะหน้านี้ ไม่แตะ --dx-bg-page ใน globals.css)
.bx-count       #7A8BA8 → #55647E
```

การ์ด/แบนเนอร์/ชิปติดต่อ **ไม่ต้องแก้** เพราะมีพื้นหลังทึบของตัวเองอยู่แล้ว
มีแค่ `.bx-count` ท้ายหน้าที่วางบนพื้นหลังตรง ๆ ไม่มีกล่อง จึงพังตามไปด้วย

| | บนกรมท่าเดิม | บนขาว |
|---|---|---|
| `.bx-count` `#7A8BA8` | 5.25:1 ✓ | 3.45:1 ✗ |
| `.bx-count` `#55647E` | — | 5.98:1 ✓ |

## กราฟฟิกพื้นหลัง — CSS ล้วน 0 ไบต์

เจ้าของเลือกแบบ "แสงฟ้าเรืองจากด้านบน + จุดไข่ปลา" จาก 4 ตัวเลือกที่เสนอ

ทำด้วย `background-image` 2 ชั้น ไม่โหลดไฟล์ภาพเลย — **bundle เท่าเดิมที่ 87.7 kB**
เหตุผลที่ห้ามใช้ไฟล์ภาพ: หน้านี้ลูกค้าเปิดจากเน็ตในห้าง และก่อนหน้านี้เพิ่งตัด
โลโก้ 25 KB ([[2026-08-11-branches-page]]) กับภาพ hero 147 KB ออกไป
จะเอาน้ำหนักกลับมาใส่เพื่อลายพื้นหลังไม่ได้

แสงฟ้าวางจุดศูนย์กลางไว้ **เหนือขอบบนของหน้า** (`at 50% -60px`) แสงจึงไล่ลงมาเหมือน
ออกมาจากแบนเนอร์ ทำให้แบนเนอร์กรมท่าไม่ลอยโดดบนพื้นขาว
ไม่ใช้ `background-attachment:fixed` เพราะแสงต้องอยู่กับหัวหน้า ไม่ใช่ตามจอไปตลอด

## ⚠️ ความทึบจุด 12% คือเพดาน ไม่ใช่ค่ากลาง ๆ

`.bx-count` วางบนพื้นลายนี้ตรง ๆ วัดกรณีแย่สุด (ตัวหนังสือทับจุดพอดี):

| ความทึบจุด | คอนทราสต์ | |
|---|---|---|
| **12%** | 4.66:1 | ผ่านเกณฑ์ 4.5:1 แบบเฉียด |
| 18% | 4.07:1 | ตก |
| 25% | 3.45:1 | ตก |

บนบริเวณที่แสงฟ้าเข้มสุดได้ 4.89:1 ยังผ่าน

จดเพดานไว้ในคอมเมนต์ในโค้ดแล้ว — ลายพื้นหลังเป็นของที่คนชอบมาปรับให้ "เห็นชัดขึ้น"
ทีหลังโดยไม่รู้ว่ามีตัวหนังสือแขวนอยู่บนนั้น
