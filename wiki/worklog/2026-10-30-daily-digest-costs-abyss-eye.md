### เปลี่ยน id "PKM Ghost" → "PKM M5 Abyss Eye" (c2e6a3b + ย้ายแถว)
- `UPDATE skus SET sku_id` ทำไม่ได้: FK ใน prod **ไม่ cascade** (มาจาก schema.sql ไม่ใช่ migration 003-005)

  (sales · machine_stock · slot_refill_events · slot_products_history · ship_fails · marketing_content — ตรวจแล้วชื่อเก่าเหลือ 0 ทุกตาราง)

- ⚠️ ลำดับสำคัญ: mapper ในเครื่องเปลี่ยนก่อนแถวใหม่มี = รอบซิงค์ถัดไปปัดยอดทิ้ง (FK) ·
  ย้ายแถวก่อน push = cron GitHub (โค้ดเก่า) เขียน id เก่ากลับ · sale_key = `txid-ลำดับ` ไม่มีชื่อ SKU จึงไม่นับซ้ำ
- mapper 7 ไฟล์ + payif_sales_sync · `PACKS_PER_BOX` key ใหม่ = 30 (ลืม = กล่องนับ 24) · ลำดับใบเติมของ (constants) +
