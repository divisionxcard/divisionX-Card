# ปุ่ม "เปิดหน้าเว็บ" ในบอท Telegram — มินิแอปล็อกอินเว็บ (11 พ.ย.)

## เจ้าของขอ
ส่งภาพบอท AssetX (ปุ่มล่างซ้าย กดแล้วมินิแอปหน้าล็อกอินเด้งขึ้น) — "เลียนแบบปุ่ม … กดแล้วมีมินิแอปเด้งขึ้นมา เข้าเว็บไซต์ได้เลย
โดยกรอกรหัสผ่านตามปกติ ใช้ได้ทั้งมือถือและพีซี" · ย้ำว่าไม่ได้ต้องการหน้าไดอารี่ · เลือกใส่บอท **DVX Job (@dvx_marketing_bot)**

## ทำอะไร
- **ปุ่มเมนูบอท** — `scripts/set_telegram_web_button.py --bot job` (Bot API `setChatMenuButton` แบบ `web_app` · ค่าเริ่มของทุกแชตส่วนตัว)
  ลิงก์ https://division-x-card.vercel.app/ · ถอดคืนเป็นปุ่มคำสั่ง: `--remove` · ดูทุกบอท: `--show`
  · Telegram ตอบ ok ทันทีแต่อ่านกลับได้ค่าใหม่หลัง ~10–15 วิ — สคริปต์รอให้แล้ว
- **`components/TelegramMiniApp.jsx`** (ใส่ใน root layout) — โหลดสคริปต์ telegram-web-app.js **เฉพาะตอนเปิดจากใน Telegram**
  (ดูจาก `#tgWebApp…` ในลิงก์ / `TelegramWebviewProxy` / จำไว้ใน sessionStorage) → `ready()` · `expand()` (มือถือเปิดมาครึ่งจอ) ·
  `disableVerticalSwipes()` (ปัดลง = เลื่อนหน้า ไม่ใช่ปิดมินิแอป) · ลูกค้าเปิดเว็บปกติไม่โหลดอะไรเพิ่ม
- **header ความปลอดภัย** (`next.config.js`) — เดิม `X-Frame-Options: DENY` + `frame-ancestors 'none'` (ตรวจความปลอดภัย 16 ต.ค.)
  แอปมือถือ/Telegram Desktop/Unigram เปิดมินิแอปในหน้าต่างของมันเอง ไม่ติดค่านี้ แต่ **Telegram Web ฝังใน iframe** →
  เปลี่ยนเป็น `frame-ancestors https://web.telegram.org` (เว็บอื่นยังฝังไม่ได้) · ถอด XFO เพราะระบุโดเมนที่ยอมไม่ได้
- ล็อกอินด้วยชื่อผู้ใช้/รหัสผ่านเว็บตามปกติ — ไม่ได้ผูกบัญชี Telegram · บัญชีทีมการตลาดล็อกอินแล้วไปหน้า /marketing ตามเดิม

## ตรวจแล้ว
- `npm run build` ผ่าน · Vercel deploy สำเร็จ · header จริงบน production: `frame-ancestors https://web.telegram.org` ไม่มี XFO (หน้า / และ /stock)
- พรีวิวหน้าเว็บแบบที่ Telegram ส่งมา (มีพารามิเตอร์มินิแอปต่อท้าย) จอคอม/มือถือ: หน้าล็อกอินขึ้นปกติ ไม่มี JS error
- `getChatMenuButton` ของ DVX Job = web_app "เปิดหน้าเว็บ" · บอทอีก 2 ตัวยังเป็นปุ่มคำสั่งเหมือนเดิม
- **ยังไม่ได้ลองกดจากแอป Telegram จริง** (มือถือ/คอม) — รอเจ้าของลอง

## ข้อจำกัด
- ปุ่มมินิแอปขึ้นเฉพาะแชตส่วนตัวกับบอท — ในกลุ่ม Telegram ไม่แสดง
- ปุ่มเว็บแทนที่ปุ่มรายการคำสั่ง (คำสั่ง /xxx ยังพิมพ์ได้)
- ใน webview ของ Telegram ปุ่มที่เปิดหน้าต่างใหม่ (`window.open` — Print/PDF) อาจไม่ทำงาน หรือเด้งออกไปเบราว์เซอร์ภายนอก

## แก้ตามเจ้าของ: ต้องเป็นกลุ่ม DVX_Admin (11 พ.ย. บ่าย)
- เจ้าของแจ้งว่าตอบผิด — ต้องการปุ่มใน**กลุ่ม DVX_Admin** · บอท DVX Job อยู่ในกลุ่มนี้อยู่แล้ว (เป็นแอดมิน ปักหมุดได้)
- ข้อจำกัด Telegram: ปุ่มเมนูมินิแอป · ปุ่ม inline `web_app` · ปุ่มแผง `web_app` ใช้ได้**เฉพาะแชตส่วนตัว** ·
  ในกลุ่มทางเดียวคือปุ่มลิงก์ `https://t.me/dvx_marketing_bot?startapp` ที่เปิด "แอปหลัก" ของบอท — ต้องเปิด Main Mini App ใน BotFather (ไม่มี API)
- `mkt-webhook`: ปุ่มใต้ช่องพิมพ์เปลี่ยนชื่อเป็น "🌐 เปิดหน้าเว็บ @dvx_marketing_bot" (ชื่อเก่ายังรับ) · กดแล้วบอทตอบปุ่ม
  "🌐 เปิดหน้าเว็บ" (มินิแอป) + "🧭 เปิดในเบราว์เซอร์" (สำรอง)
- `set_telegram_web_button.py --group-panel` แก้ปุ่มในแผงที่ปักหมุดอยู่ (ข้อความ #268 ของบอท · ไม่โพสต์ใหม่) · `--group-keyboard` ส่งแผงปุ่มชื่อใหม่ ·
  ทั้งคู่ปฏิเสธถ้าบอทยังไม่เปิดแอปหลัก (`getMe.has_main_web_app`)
- ปุ่มเมนูในแชตส่วนตัวกับ DVX Job ที่ตั้งตอนเช้ายังอยู่ (ไม่เสียหาย) · ถอดได้ด้วย `--bot job --remove`

## เปิดใช้ในกลุ่ม (11 พ.ย. เย็น)
- เจ้าของเปิดแอปหลักใน BotFather (ตอบ "Success! Mini App settings updated.") → `--show` เห็น `แอปหลัก True` ของ DVX Job
- `--group-panel --group-keyboard`: แก้ข้อความที่ปักหมุด #268 (ข้อความเดิมของบอท ไม่โพสต์ใหม่) + ส่งแผงปุ่มใต้ช่องพิมพ์ชื่อใหม่ 1 ข้อความ
- อ่านกลับด้วย `getChat.pinned_message`: ปุ่ม "🌐 เปิดหน้าเว็บ" → `t.me/dvx_marketing_bot?startapp` · "🧭 เปิดในเบราว์เซอร์" → เว็บ
- Bot API อ่าน URL ของแอปหลักกลับไม่ได้ (มีแค่ `has_main_web_app`) — ถ้าเปิดแล้วไม่ใช่หน้าเว็บเรา ให้ตั้ง URL ใหม่ใน BotFather
- **ยังไม่ได้ลองกดจากมือถือ/คอมจริง** — รอเจ้าของลอง

## กดแล้วเด้งเลย ไม่มีข้อความตอบ (11 พ.ย. ค่ำ)
เจ้าของขอ "กดปุ่มแล้วเด้งมินิแอปขึ้นมาได้เลย ไม่ต้องมีข้อความตอบกลับ" · ถาม agent ของ AssetX แล้ว — ปุ่มของ AssetX อยู่ใน**แชตส่วนตัว**
(แบบเดียวกับปุ่มเมนูที่ DVX Job มีอยู่แล้ว)

ค้นเอกสาร Telegram ล่าสุด (Bot API 10.4 · 9 พ.ย. 2026) + ซอร์สแอปทางการ ด้วย workflow 4 มุม + ตัวตรวจซ้ำ:
- **ปุ่มใต้ช่องพิมพ์ในกลุ่มเปิดมินิแอปตรงไม่ได้** — `KeyboardButton.web_app` "Available in private chats only" · ไม่มีช่อง url ·
  ปุ่มข้อความล้วน "will be sent as a message" → บอทต้องตอบเสมอ · ไม่มีรุ่นไหนตั้งแต่ 2024 ผ่อนข้อนี้
- `InlineKeyboardButton.web_app` / ปุ่มเมนู / widgets (10.4) ใช้ได้แค่แชตส่วนตัวเหมือนกัน · attachment menu เฉพาะผู้ลงโฆษณารายใหญ่
- **ปุ่มลิงก์ `t.me/<bot>?startapp` ใช้ได้ในกลุ่ม** — เปิดแอปหลัก "in the current chat"
- **แถบปักหมุดโชว์ปุ่มของข้อความที่ปักหมุด** เมื่อมี**ปุ่มเดียวพอดี (1 แถว × 1 ปุ่ม)** — ดูจากซอร์ส Android/iOS/Desktop/Web A
  (ไม่มีใน changelog/บล็อก · Desktop มีตั้งแต่ เม.ย. 2022) → แผงเดิมมี 2 แถวเลยไม่โชว์

  **Desktop ถามทุกครั้ง**ที่กดปุ่มของบอทที่ไม่ verified (Ctrl+คลิกข้ามได้) — ลิงก์ที่เห็นเป็นตัวอักษรถามแค่ครั้งแรก

- ป้ายปุ่มบนแถบยาวได้ราว 120px (Desktop) — "🌐 เปิดหน้าเว็บ" ยังพอดี
