# ช่องภาพในการ์ดคอนเทนต์ — และเหตุผลที่ไม่ใช้ AI สร้างภาพ

## บริบท (why)
เจ้าของขอ "ช่องแสดงภาพด้านข้างแต่ละการ์ด เพื่อดูตัวอย่างก่อนกดอนุมัติ"
ซึ่งตรงกับโฟลว์ที่วางไว้ว่าจะมีขั้น **AI สร้างภาพประกอบ**

แต่พอไปตรวจความเป็นไปได้จริง เจอว่าคำตอบที่ดีกว่าไม่ใช่ "ให้ AI สร้างภาพ"

## 🔍 ตรวจ 3 ทางก่อนตัดสินใจ

### 1. Gemini สร้างภาพ → ❌ free tier ไม่ให้
```
gemini-3.1-flash-image  → "You exceeded your current quota"  (โควตาฟรี = 0)
gemini-2.5-flash-image  → เหมือนกัน
imagen-4.0-fast         → "no longer available to new users"
```

### 2. Pollinations (ฟรี ไม่ต้องมี key) → ⚠️ คุณภาพเอาแน่ไม่ได้
ทดสอบ 3 ภาพด้วย prompt แนวแบรนด์ (ฟ้านีออน+สายฟ้า บนกรมท่า):

| ภาพ | ผล |
|---|---|
| ตู้กดการ์ด One Piece | ❌ **มีตัวหนังสือมั่ว**เต็มไปหมด · สีเพี้ยนเป็นส้ม ทั้งที่สั่ง "no text" |
| ซองการ์ด Pokemon | ✅ ตรงแบรนด์ ฟ้านีออนบนกรมท่า ใช้ได้ |

เอาแน่ไม่ได้แบบนี้ = เอาไปโพสต์เพจจริงไม่ได้ ต้องนั่งตรวจทุกภาพอยู่ดี

### 3. รูปจริงที่มีอยู่แล้ว → ✅ **เลือกอันนี้**
```
SKU ที่ใช้งานอยู่ 41 ตัว
  มีรูปซองจริง  : 39   ← Supabase Storage
  มีรูปกล่องจริง : 38
```

> **AI ไม่รู้ว่าการ์ดชุด OP-13 หน้าตายังไง มันเดาเอา** — แต่เรามีรูปจริงอยู่แล้ว
> คอนเทนต์การ์ดสะสม คนอยากเห็นของจริง ไม่ใช่ภาพที่โมเดลจินตนาการขึ้น

## สิ่งที่ทำ
- กดเลือกไอเดียที่โยง SKU → **แนบรูปจริงให้ทันที** (ฟรี · ตรงของจริง · ไม่ต้องรอ 45 วิ)
- การ์ดที่ยังไม่มีรูป → ปุ่ม **"ใช้รูป <SKU>"** หรือวางลิงก์เอง
- hover รูปแล้วมีปุ่มเอาออก · PATCH `media_url` ได้ผ่าน API (ส่ง `""` เพื่อลบ)
- layout: ภาพซ้าย 144px · เนื้อหาขวา · มือถือเรียงลงมา

## 🐛 บั๊กที่เจอตอนทำ
`patch()` เดิม**ลบการ์ดออกจากคิวทุกครั้งที่แก้อะไรก็ตาม** — เพราะเขียนไว้สมัยที่มีแต่
อนุมัติ/ทิ้ง พอเพิ่มการแก้รูป กดแล้วการ์ดหายทั้งที่ยังไม่ได้อนุมัติ

→ แยกเป็น **เปลี่ยน status = ออกจากคิว · แก้อย่างอื่น = อัปเดตในที่**
และต้องคง `sku`/`idea` embed ไว้ด้วย เพราะ PATCH ไม่ได้คืน embed กลับมา
ถ้าไม่คงไว้ ปุ่ม "ใช้รูป SKU" จะหายหลังกดครั้งแรก

## ค้าง
- ยังไม่ได้กดจากหน้าเว็บจริง (ไม่มี admin credential) — ทดสอบถึงระดับ DB + compile
- **AI สร้างภาพยังไม่ได้ทำ** — ถ้าจะเอาจริงต้องเสียเงิน (Gemini paid) หรือรัน
  Stable Diffusion บนเครื่อง (ซึ่งเจอปัญหาเดียวกับ Ollama คือ Vercel ต่อไม่ถึง)
  เก็บไว้พิจารณาตอนทำคอนเทนต์ที่ไม่มีสินค้าเจาะจง เช่นโพสต์เกาะกระแสข่าว
