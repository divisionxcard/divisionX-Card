# ปุ่มให้ AI เขียนตายเพราะ Gemini ล้น — ทำให้มันฟื้นเองได้

เจ้าของแจ้งว่าเขียนคอนเทนต์ไม่ได้ ขึ้นว่า
*"This model is currently experiencing high demand. Spikes in demand are usually temporary."*

## ต้นตอ — ไม่ใช่ระบบเราพัง แต่ระบบเราไม่ยอมลองใหม่

`askGemini` ใน [route.js](../../deploy/app/api/marketing/content/generate/route.js) เดิม
**ยิงครั้งเดียว โมเดลเดียว** ล้มปุ๊บโยน error ขึ้นหน้าเว็บทันที
ทั้งที่อาการ "คนใช้เยอะจนล้น" เป็นของชั่วคราว รอไม่กี่วินาทีหรือเปลี่ยนรุ่นก็ผ่านแล้ว

ยืนยันว่าเป็นของชั่วคราวจริง: ยิงทดสอบตอนแก้ `gemini-flash-latest` ตอบปกติ

## สิ่งที่แก้ — แยกความล้มเหลว 4 แบบที่เดิมเหมารวมเป็นก้อนเดียว

| อาการ | ความหมาย | ทำอะไร |
|---|---|---|
| 503 · high demand · overloaded | ชั่วคราว | รอ 1.5s แล้ว 3s ลองซ้ำ |
| 429 `PerDay` | โควตารายวันหมด | **สลับโมเดลทันที** — โควตานับแยกตามโมเดล รอไปก็ไม่หาย |
| 429 `PerMinute` | ยิงถี่เกิน | รอแล้วลองซ้ำ |
| 404 no longer available | Google ปลดรุ่น | สลับโมเดล + ไปแก้รายชื่อในโค้ด |

`MAX_TOKENS` (คิดเยอะจนไม่เหลือโควตาเขียน) ก็สลับไป flash-lite ที่คิดน้อยกว่า
แทนการยิงซ้ำรุ่นเดิมซึ่งจะเจอผลเดิม

## ของแถม — ในโค้ดมีชื่อโมเดลที่ตายไปแล้ว

ก่อนใส่ชื่อลง chain ยิงทดสอบทีละตัวกับ key จริง:

```
gemini-flash-latest        ✅
gemini-flash-lite-latest   ✅
gemini-2.0-flash-lite      ❌ 404 no longer available   ← อยู่ใน MODEL_CHAIN ของ idea_angles.py
gemini-2.5-flash           ❌ 404
gemini-2.5-flash-lite      ❌ 404
gemini-pro-latest          ❌ 429 ตั้งแต่ครั้งแรก (free tier ไม่มีโควตา)
```

`idea_angles.py` จึงมี chain ที่ตัวสุดท้ายใช้ไม่ได้มาตลอด — เวลาโควตาสองตัวแรกหมด
มันจะไปตายที่ตัวที่สามแทนที่จะถอยไป Ollama เอาออกแล้ว

> ย้ำบทเรียนเดิมที่เคยบันทึกไว้: **อย่าเชื่อ ListModels** มันคืนรุ่นที่ถูกปลดแล้วมาด้วย
> ต้องยิงจริงเท่านั้น

## ทดสอบ (กับ Gemini ของจริง ไม่ใช่ mock)

ดึงเฉพาะ `askGemini` ออกมา eval — route เป็น ESM + import ของ Next เรียกตรงไม่ได้

1. เรียกปกติ → ผ่าน
2. ตั้ง `gemini_model` เป็นรุ่นที่ตายแล้ว → **สลับไปรุ่นที่ใช้ได้เองอัตโนมัติ**
3. จำแนกชนิด error → ถูกทุกแบบ (503/overloaded = ชั่วคราว · PerDay ≠ PerMinute)
4. key ผิด → ล้มใน 0.2 วิ ไม่วน retry ให้เสียเวลาเปล่า

> กับดักตอนเขียน harness: ไฟล์ในโปรเจกต์เป็น **CRLF** ถ้าไม่แปลงก่อน การหา `\n\n`
> จะไม่เจอ แล้วตัวตัดบล็อกจะกวาดไปทั้งไฟล์ ได้ error ว่า `askGemini` ถูกประกาศซ้ำ
> อีกอัน: **direct eval โยน function declaration เข้าสโคปที่เรียก** ตั้งชื่อ const ซ้ำจะชนกันทันที

## เรื่องที่เจ้าของถามต่อ — ให้ Hermes เขียนแทน Gemini เลยได้ไหม

ตรง ๆ ไม่ได้ **เพราะอยู่คนละเครื่อง** — ปุ่มบนหน้าเว็บรันบน Vercel (คลาวด์)
ส่วน Hermes รันบนเครื่องเจ้าของ เหตุผลเดียวกับที่ Ollama ใช้บน Vercel ไม่ได้

ทางที่เป็นไปได้จริงคือใช้ **Nous Portal Inference API** (OpenAI-compatible) เป็น provider เพิ่ม
ในตัว route ซึ่งไม่ผูกกับเครื่องไหน — ต้องเช็กก่อนว่าแพ็กเกจ FREE ออก API key ให้หรือเปล่า
