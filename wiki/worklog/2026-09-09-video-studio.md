# สร้างโรงงานวิดีโอเอง เพราะของที่ซื้อมาไม่รู้จักสินค้าเรา

เจ้าของสมัคร **Hero AI Creator Studio** มาลองทำคลิปสั้น แล้วให้ผมเขียนสคริปต์ให้
ผลที่ได้เป็นบทเรียนที่คุ้มค่าเงินมาก — และเป็นเหตุผลที่ต้องสร้างเอง

## สิ่งที่เกิดขึ้นกับเครื่องมือที่ซื้อมา

สคริปต์ 12 บรรทัดผ่านเข้าไป ได้คลิป 42 วินาทีกลับมา **เสียงกับซับใช้ได้**
แต่พอดูไทม์ไลน์ของภาพประกอบ:

```
modern hospital lobby wide · doctor explaining medi... · patient receiving prescription hand
fitness tracker on wrist · medical professional smiling portrait · clean clinic waiting area
```

คลิปตู้กดการ์ดสะสม ได้หมอกับใบสั่งยามาทั้งเรื่อง

ต้นเหตุ: ตัวแปลงสคริปต์เป็นคำค้นอ่านคำว่า **"ซอง" เป็นซองยา** และ **"ตู้" เป็นเครื่องจ่ายยา**
`patient receiving prescription hand` คือมันแปล *"ซองหล่นลงมา อยู่ในมือคุณ"* ตรงตัว

ส่วนภาพที่ AI ของมันวาดเองก็ได้ **ตู้น้ำอัดลม** กับ **ผู้ชายใส่สูท** บนพื้นครีม
และคนสองคนสีเบจส่งของให้กัน (บรรทัดจริงคือ "จะแกะตรงนั้นเลยก็ได้")

> **คลังสต็อกและโมเดลทั่วไปไม่รู้จักสินค้าเรา** — และการ์ดจอที่ใหญ่ขึ้นก็แก้ไม่ได้
> เพราะปัญหาไม่ใช่คุณภาพการวาด แต่คือมันไม่เคยเห็นตู้ของเรา

## เรามีของที่มันไม่มี

พอตั้งโจทย์ว่า "ความสมจริงมาจากไหน" คำตอบอยู่ในโปรเจกต์เราอยู่แล้ว —
[[poster_render.py|2026-08-08-thai-text-rendering]] แก้ปัญหานี้ไปตั้งแต่ตอนทำโปสเตอร์
คอมเมนต์ในโค้ดเขียนไว้ตรง ๆ:

> *ผลพลอยได้: ซองการ์ดในภาพเป็นรูปถ่ายของจริง ไม่ใช่ของที่ AI วาดขึ้นเอง
> (ถ้าให้ AI วาดซองเอง จะกลายเป็นสินค้าปลอมที่ไม่มีอยู่จริง)*

ของที่มีอยู่แล้ว: รูปตู้จริง 2 มุม · รูปซอง/กล่องจริงทุก SKU ใน Supabase ·
FLUX รันบนเครื่อง · เทมเพลต HTML ที่วาดตัวอักษรไทยถูก 100%

**โรงงานวิดีโอคือระบบโปสเตอร์ที่เพิ่มแกนเวลาเข้าไป** ไม่ใช่ของใหม่ทั้งหมด

## แบ่งงานตามที่แต่ละฝ่ายเก่ง

```
รูปถ่ายจริง → ตู้ ซอง กล่อง          ของที่ไม่มีใครมีนอกจากเรา
FLUX        → ฉาก แสง บรรยากาศ      ห้ามให้วาดสินค้า เดี๋ยวได้ของปลอม
Chromium    → ตัวอักษรไทยทุกตัว      ถูก 100% ทั้งสระซ้อนและวรรณยุกต์
Gemini TTS  → เสียงพากย์
whisper     → เวลารายคำ
ffmpeg      → การเคลื่อนไหว เสียง การประกอบ
```

**อ่านเสียงรวดเดียวทั้งสคริปต์ ไม่ใช่ทีละบรรทัด** เพราะ TTS ต้องเห็นประโยคถัดไป
ถึงจะวางน้ำเสียงกับจังหวะหายใจถูก แล้วค่อยใช้ whisper หาว่าบรรทัดไหนอยู่วินาทีใด —
นี่คือความต่างระหว่าง "ซับตรงเสียง" กับ "ซับที่เดาเวลาเอา" ซึ่งอย่างหลังจะเลื่อนสะสม

## สองบั๊กที่ทำให้ "เสร็จแล้ว" ทั้งที่ผิด

ทั้งคู่โผล่มาตอนเริ่มใช้เวลาจริงจาก whisper (ตอนทดสอบด้วยการแบ่งเวลาเท่า ๆ กันไม่เจอ)

### 1. ตัวจับคู่เวลาเดินหน้าเร็วเกินจริง

เขียนครั้งแรกแบบเทียบทีละอักขระ ถ้าไม่ตรงก็ "มองหาไปข้างหน้าอีก 12 ตัว"
ภาษาไทยมีอักขระซ้ำเยอะมาก ตัวชี้เลยกระโดดข้ามไปเรื่อย ๆ จนกินข้อความหมด
**ตั้งแต่วินาทีที่ 23 ของคลิป 45 วินาที**

ผลคือ 11 บรรทัดแรกอัดกันอยู่ครึ่งแรก และบรรทัดสุดท้ายค้างบนจอ 21 วินาที —
ดูตัวเลขผ่าน ๆ เหมือนทำงานได้ ต้องพิมพ์ตารางเวลาออกมาดูถึงเห็น

แก้ด้วย `difflib.SequenceMatcher(autojunk=False)` ซึ่งหาการจับคู่ที่ดีที่สุดของ
ทั้งสายพร้อมกัน ไม่ตัดสินทีละตัว จึงไม่สะสมความผิดพลาด
(`autojunk=False` สำคัญ ไม่งั้นมันทิ้งอักขระที่พบบ่อยออกจากการเทียบ
ซึ่งในภาษาไทยคืออักขระเกือบทั้งหมด)

### 2. ภาพไม่ครอบช่วงที่คนพูดหายใจ

ความยาวฉากคิดจาก `end - start` ซึ่งไม่รวมช่วงเงียบระหว่างประโยค
(whisper จับได้จริง เช่น 3.72 → 4.16 คือเงียบ 0.44 วินาที)

`offset` ของ xfade จึงเลยความยาวที่ต่อได้ **ffmpeg ตัดท้ายทิ้งเงียบ ๆ ไม่ error**

| | |
|---|---|
| ที่ควรได้ | 45.0 วินาที |
| ที่ได้จริง | **5.97 วินาที** |
| ที่โปรแกรมพิมพ์ | ✅ เสร็จแล้ว 45.0 วินาที |

ทุกคำสั่ง ffmpeg คืน exit code 0 กว่าจะรู้ก็ตอนสั่งดึงเฟรมที่วินาทีที่ 18 แล้วได้
*"Output file is empty, nothing was encoded"*

แก้สองชั้น: ยืดฉากถึง**เวลาเริ่มของฉากถัดไป** (ครอบช่องว่างด้วย) และเพิ่ม
**ด่านตรวจความยาวจริงหลังเรนเดอร์** ให้โยน error ถ้าไม่ตรงกับเสียง —
เพราะบั๊กแบบนี้ต้องดังตอนเกิด ไม่ใช่ตอนคนเปิดไฟล์ดู

## ผลลัพธ์

| ขั้น | เวลา (คลิป 45 วิ) |
|---|---|
| Gemini TTS | ~4 นาที (แคชแล้วเป็น 0) |
| whisper จับเวลา (GPU) | 12 วินาที · 346 คำ |
| เตรียมภาพ | 2 วินาที |
| ซับ 22 ชิ้นผ่าน Chromium | 6 วินาที |
| ffmpeg ประกอบ | 35 วินาที |

ตรวจด้วยตาแล้วทั้งสองอย่างที่เสี่ยงที่สุด:
- **ซับไทย** — สระซ้อน วรรณยุกต์ ไม้ทัณฑฆาต ถูกหมด (`เหมือน` `ตู้` `เช็ก` `ใกล้` `ได้` `ทั่ว`)
  และ `*เน้นคำ*` ออกมาเป็นฟ้านีออนตาม brand identity
- **ซับตรงเสียง** — สุ่มดูวินาทีที่ 5.28 / 19.26 / 26.32 / 43.26 ตรงกับบรรทัดที่ควรพูดทุกจุด

ภาพที่ได้คือ**ตู้ DivisionX จริง ซองจริงเต็มช่อง โลโก้ DC เบอร์โทรจริง**
และเฟรมท้ายเป็นตู้ในห้างจริงพร้อมบรรยากาศร้านกาแฟ

## บทเรียน

**ก่อนซื้อเครื่องมือ ให้ถามว่ามันรู้จักของเราไหม** — Hero AI ทำเสียงกับซับได้ดีกว่าที่คิด
แต่ส่วนที่มันทำไม่ได้คือส่วนที่ *ต้องรู้จักสินค้าเรา* ซึ่งไม่มีเครื่องมือสำเร็จรูปตัวไหนรู้
