## 2. ป้ายบอกชั้นเป็นสีแดง

เจ้าของขอ "เพื่อความชัดเจน" — เดิมเป็นสีฟ้าเหมือนสีแบรนด์ทั้งหน้า เลยกลืนไปหมด

**ไม่ใช้ `--dx-danger` (#FF4466) ทั้งที่เป็นสีแดงในชุดสีแบรนด์**
วัดคอนทราสต์กับพื้นการ์ด `rgb(26,47,82)` ได้ **3.6:1** → ต่ำกว่าเกณฑ์อ่านง่าย 4.5:1

> แดงเข้มบนพื้นกรมท่า = แดงที่อ่านไม่ออก ซึ่งขัดกับเหตุผลที่ขอเปลี่ยนสีตั้งแต่แรก
> "สีแดง" บนพื้นเข้มต้องอ่อนกว่าที่สัญชาตญาณบอก

## 3. โลโก้ใหม่ + ขยาย

`54px → 62px (+15%) → 93px (+50% อีกรอบหลังเจ้าของเห็นของจริง)`
เฉพาะหน้านี้ · หน้าอื่นยังใช้ `/logo.png` เดิม

ตรวจที่ 93px ทั้ง 1280px และ 390px: แสดง 108×93 · ไม่ล้นกรอบ · ไม่มี horizontal overflow
ยังคมเพราะไฟล์เก็บไว้สูง 400px (เผื่อ retina 4 เท่า) — เกิน ~130px ค่อยพิจารณาเก็บไฟล์ใหญ่ขึ้น

### ⚠️ ตั้ง height ตรง ๆ จะได้ผลตรงข้ามกับที่สั่ง
ไฟล์ที่ได้มา 3000×3000 แต่ **ตัวโลโก้จริงกินแค่ 1473×1253 = 20.5%**
ที่เหลือ 79.5% เป็นขอบว่างโปร่งใส · CSS นับความสูงจาก *ขอบไฟล์* ไม่ใช่ *ขอบโลโก้*
→ `height:62px` จะได้โลโก้ที่เห็นจริง **~26px = เล็กลงกว่าเดิมเกือบครึ่ง**

ตัดขอบว่างออกก่อน (เว้นหายใจ 3%) แล้วค่อยตั้งความสูง
+ ย่อ 3000px → 400px · ไฟล์ 99 KB → 25 KB (ส่ง 3000px มาแสดง 62px คือเปลืองเปล่า)

**แถมแก้ปัญหาที่ไม่มีใครทัก:** `/logo.png` ตัวเก่ามีพื้นหลัง**ดำทึบ** บนพื้นกรมท่า
จึงเห็นเป็นสี่เหลี่ยมดำโป๊ะกลางหน้ามาตลอด · ตัวใหม่โปร่งใสจริง (ตรวจแล้ว)

### สเปกสำหรับออกแบบรอบหน้า
```
ความสูงไฟล์  372 px  (62 × 6 เผื่อ retina)
ความกว้าง    เท่าไหร่ก็ได้ — CSS ล็อกแค่ height, width:auto
ไฟล์         PNG พื้นโปร่งใส · ตัดชิดตัวโลโก้ อย่าเว้นขอบว่าง
```

## 4. แบนเนอร์หัวหน้าที่เจ้าของออกแบบเอง

เจ้าของออกแบบใน Claude Design แล้วส่งไฟล์มา — เป็น**แบนเนอร์เต็มใบ** (พาดหัว ไอคอนจุดขาย
แผงกล่องสินค้า ตู้จริง แถบติดต่อ) จึงมาแทน *บล็อกข้อความทั้งก้อน* ไม่ใช่แค่พื้นหลังอย่างที่คุยกันตอนแรก

### จอเล็กใช้ภาพนี้ไม่ได้ — คงข้อความ HTML ไว้  ⟵ **ยกเลิกแล้ว 13 ส.ค. ดูข้างล่าง**
ภาพอัตราส่วน 1.99:1 · ย่อลงกล่องกว้าง 354px บนมือถือแล้ว
พาดหัวเหลือ ~16px · บรรทัดเล็กเหลือ **~8px = อ่านไม่ออก**

**ลูกค้าส่วนใหญ่เปิดหน้านี้จากมือถือตอนยืนอยู่ในห้างเพื่อหาตู้** — จุดนี้ยอมไม่ได้
ตัวหนังสือจริงย่อ-ขยายตามจอได้ ภาพทำไม่ได้ → แยกเป็น 2 ทาง (≥720px ใช้ภาพ · เล็กกว่านั้นใช้ข้อความ)

### 📌 13 ส.ค. — เจ้าของเลือกให้โชว์ภาพทุกจอ (กลับมติข้างบน)
เจ้าของทักว่า "มือถือภาพไม่แสดง" · อธิบายว่าเป็นของที่ตั้งใจ + เสนอ 4 ทาง
(คงเดิม / ออกแบบภาพเวอร์ชันมือถือเพิ่ม / ภาพพื้นหลัง+ข้อความทับ / โชว์ภาพเดิมเลย)
→ **เลือก "โชว์ภาพเดิมบนมือถือเลย"** ทั้งที่รู้ว่าตัวหนังสือในภาพจะเหลือ ~8px

เอา `@media (min-width:720px)` ออก · ภาพแสดงทุกจอ · บล็อกข้อความถูก `clip` ตลอดเวลา
(ยังต้องอยู่ใน DOM — `<h1>` กับจำนวนสาขาจากฐานข้อมูลคือสิ่งที่ Google อ่าน ภาพอ่านไม่ได้)

**สิ่งที่เสียไปบนมือถือ:** แถบติดต่อล่างภาพ (LINE / 086-386-3219) เหลือ ~7px อ่านไม่ออก
→ ไม่ถือว่าคอขาดบาดตาย เพราะ footer ของหน้ามี chip ติดต่อเป็น HTML จริงอยู่แล้ว
LINE กดได้ · เบอร์เป็น `tel:` กดโทรออกได้ · ขนาด 14px

**เพิ่ม `srcSet` ตอนเดียวกัน** — เดิมมือถือกล่องกว้าง 354px แต่โหลดไฟล์ 1339px เต็ม ๆ
ทำตัว 800w (105 KB) คู่กับ 1339w (252 KB) → จอ DPR2 **ประหยัด 147 KB (58%)**
`sizes` อิงสูตรกล่องจริง `min(1080, 100vw) − 36` ไม่ได้เดา

ตรวจด้วยการเรนเดอร์จริง 4 จอ — ทุกจอ h1 ยังอยู่ใน DOM · ไม่มี horizontal overflow:

| จอ | ภาพที่เบราว์เซอร์เลือก | ขนาดที่แสดง | สูงกล่อง |
|---|---|---|---|
| 390 @2x | `branches-hero-800.jpg` | 352×177 | 179px |
| 390 @3x | `branches-hero.jpg` | 352×177 | 179px |
| 768 @2x | `branches-hero.jpg` | 730×367 | 369px |
| 1280 @1x | `branches-hero.jpg` | 1042×525 | 527px |

⚠️ **`logo-white.png` (25 KB) ยังโหลดทุกจอแต่ไม่มีใครเห็นแล้ว** — มันอยู่ในบล็อกที่ `clip`
เดิมมือถือยังเห็น ตอนนี้ไม่เห็นทั้งคู่ · ยังไม่เอาออกเพราะเจ้าของเพิ่งไล่ปรับขนาด 3 รอบ
(54→62→93px) ถ้าไม่ใช้แล้วค่อยลบทั้ง `<img>` + `.bx-logo` + สเปกออกแบบข้างบน

### 📌 13 ส.ค. — เจ้าของสั่งเอาโลโก้ออก ✅
ลบ `<img class="bx-logo">` + กฎ `.bx-logo` + ไฟล์ `deploy/public/logo-white.png`
(ตรวจแล้วทั้งโปรเจกต์อ้างถึงที่เดียว · กู้คืนจาก git ได้ถ้าเปลี่ยนใจ)

**คงบล็อกข้อความที่เหลือไว้** — `<h1>` / บรรทัดรอง / จำนวนสาขา ยังต้องอยู่ใน DOM ให้ Google อ่าน
เอาออกเฉพาะโลโก้เพราะ `alt="DivisionX Card"` ไม่ได้บอกอะไรเกินกว่า `<h1>` กับ `<title>` อยู่แล้ว
= ตัด 25 KB ต่อการเปิดหน้า 1 ครั้ง โดยไม่เสีย SEO อะไรเลย

ตรวจเรนเดอร์จริง 1280px + 390px: โหลดแค่ `branches-hero.jpg` ไฟล์เดียว ·
h1 ยังอยู่ใน DOM · การ์ด 13 ใบครบ · ไม่มี horizontal overflow · ความสูงกล่องเท่าเดิม (527 / 179px)

⚠️ สเปกออกแบบโลโก้ข้างบนยังใช้ได้ ถ้าวันหน้าจะเอาโลโก้กลับมาที่หน้าอื่น

### ซ่อนข้อความด้วย clip ไม่ใช่ display:none
`display:none` จะทำให้ `<h1>` หายจาก DOM ที่ Google อ่าน = **เสีย SEO ของหน้าสาธารณะ**
ตัวหนังสือที่ฝังในภาพ Google อ่านไม่ออก ต้องเหลือ h1 จริงไว้ + ใส่ `alt` ให้ครบความหมาย

### บีบไฟล์ 1,667 KB → 252 KB
ตรวจแล้วภาพทึบทั้งใบ (อัลฟาต่ำสุด 255) JPEG จึงไม่เสียอะไร · q88 progressive
เน็ตในห้างไม่ได้เร็ว 1.6 MB สำหรับภาพเดียวคือหนักเกินไป
+ ลบไฟล์ต้นฉบับออกจาก `public/` ไม่งั้นถูกเสิร์ฟออกเน็ตโดยเปล่าประโยชน์

### ⚠️ หนี้ที่เกิดขึ้นใหม่: "13 สาขา" ถูกฝังในภาพ
บล็อกข้อความ HTML นับจำนวนสาขาจากฐานข้อมูลเอง (`{BRANCHES.length}`) — เปลี่ยนตามจริงเสมอ
แต่ในภาพเป็นตัวเลขตายตัว **สิ้นเดือนที่ยกเลิก wwv02 แล้วเหลือ 12 ตู้ ภาพจะผิดทันที**

### บทเรียนของผม: อ่านคำว่า "รูปพื้นหลัง" แล้วรีบสร้างเครื่องมือ
