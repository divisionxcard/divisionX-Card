## แนวคิดในคลิป → เทียบกับระบบเรา

| แนวคิด | ระบบเรา (ก่อนวันนี้) |
|---|---|
| Generate ≠ Produce — ระบบผลิต ไม่ใช่ตัวสร้างตัวเดียว · AI เป็นคนคุมงาน | ✅ บท → เสียง → whisper → ภาพจริง/ฉาก → HyperFrames → ชั้นเสียง → อัป |
| Pipeline: research → script → scene → asset → edit → voice → subtitle → review | ✅ ครบ ยกเว้น **review** |
| Plan before generate: เสนอแนวคิด/บท/แผนฉาก/เลือกเครื่องมือก่อน | 🟡 ผู้กำกับเขียนแผนแล้วเรนเดอร์ต่อทันที ไม่มีใครเห็นก่อน |
| Cost estimate · spend cap · approval gate (approve/revise/reject) | 🟡 ส่วนใหญ่ฟรี จ่ายแค่ภาพพื้นหลัง AI ~1.4 บาท/คลิป |
| Render ≠ Done: ffprobe · frame sample · audio level · subtitle · delivery check | ❌ เรนเดอร์เสร็จ = done + ผูกเข้าคอนเทนต์ทันที |
| Free path: footage ฟรี · TTS ฟรี · Remotion · FFmpeg | ✅ รูปจริงของเรา + Pixabay + Gemini TTS + HyperFrames |
| คุณภาพขึ้นกับ provider · source · budget · human review | ✅ เจอเองแล้ว (Hero AI ได้ภาพซองยา · Sora/Veo ปิด) |

**ตรวจแล้วไม่เชื่อตามคลิป:** ฟุตเทจ "ฟรี" (Wikimedia) ใบอนุญาตต่างกันรายไฟล์ ต้องเช็กทีละไฟล์ (กติกาเดียวกับเพลง) ·
NASA/Archive.org ไม่เกี่ยวกับการ์ด · ตัว OpenMontage ไม่ต้องติดตั้ง — เอาแค่แนวคิดด่านตรวจ

เจ้าของเลือก (กดในแชท): **ด่านตรวจหลังเรนเดอร์** + **ดูแผนก่อนเรนเดอร์** · ไม่เลือก: เพดานค่า AI ต่อวัน · เขียนเป็นแบบแผนอย่างเดียว

## 1. ด่านตรวจหลังเรนเดอร์ (`agents/video/qa.py`)

ทำไม: ปัญหาที่หลุดถึงตาเจ้าของเป็นแบบที่ตรวจจากไฟล์ได้ทั้งนั้น — โลโก้หายตอนเรนเดอร์จริง (snapshot ปกติ) ·
คลิปพื้นหลังไม่มีเสียงทำทั้งงานล้ม · ฉากปิดยังเขียน "เช็กหน้าตู้"

ตรวจ 6 ข้อ (รายละเอียด `deploy/agents/video/README.md`): ไฟล์ · ภาพ (จอดำ/ภาพหาย) · โลโก้ · เสียง · ซับ · ตามบรีฟ
- **โลโก้** = Pearson ระหว่าง alpha ของไฟล์โลโก้จริงกับความสว่างของเฟรมตรงตำแหน่งที่เทมเพลตวาง —
  มีโลโก้ 0.89–1.00 · บริเวณที่ไม่มีโลโก้ในคลิปจริง −0.19…0.11 → เกณฑ์ ≥ 0.3 ผ่าน · < 0.15 ไม่ผ่าน
- **ซับ** = `hf_render.prepare()` เขียน `captions.json` (ผูก sha สคริปต์) · ตรวจ `aligned` — whisper ล้มแล้วซับแบ่งตามตัวอักษร
  เดิมเงียบ ๆ ไม่มีใครรู้
- **ไม่ผ่าน = ไม่ผูกคลิปเข้าคอนเทนต์** (คลิปยังเปิดดู/ดาวน์โหลดได้) · ภาพรวมเฟรม 12 ช่องต่อคลิป → R2 `video-qa/`

ทดสอบ:
- คลิปจริง `auto-20261023-bgtest` ผ่านครบ (8 วิ) · คลิปใหม่ `qa-local-test` (เสียงจริง) ผ่านครบรวมข้อซับ
- คลิปที่ทำให้พัง: จอดำ 3 วิ ❌ · เงียบทั้งคลิป ❌ · ไม่มีแทร็กเสียง ❌ · ไม่มีโลโก้ ❌ (0.00) · บทมี "เช็กหน้าตู้"+เบอร์เก่า+ยอดขาย ❌
- คลิปห้องตัดต่อ: เจอโลโก้ที่ของทับ (0.74)

## 2. ดูแผนก่อนเรนเดอร์ ("AI เสนอ คนอนุมัติ")

- ปุ่ม **"ดูแผนก่อน"** เป็นค่าเริ่มต้นทั้งโหมดให้ระบบออกแบบและเขียนสคริปต์เอง · "ทำเลย" ยังอยู่ · ห้องตัดต่อไม่ผ่านขั้นนี้
- runner `make_plan`: ผู้กำกับเขียนบท/หน้าตา/เสียง + `hf_bg.decide()` เลือกพื้นหลัง (ไม่วาด ไม่โหลด) + `estimate()` → `planned`
- หน้า `/video`: บท · หน้าตา · พื้นหลัง (+ ฉากที่จะให้ AI วาด) · ค่าใช้จ่ายรายข้อ → อนุมัติ / ยกเลิก
- อนุมัติแล้วเรนเดอร์ตามแผนเป๊ะ — **ห้ามจ่ายเกินแผน** (แผนฟรีแล้วฟุตเทจหาไม่เจอ = ลายกราฟิก ไม่ตกไปวาด)
- Actions ข้าม ffmpeg/whisper/Chromium/Node ตอน `plan.stage = plan` (Preflight อ่านจากแถว)
- ทดสอบ: วางแผนบนเครื่อง (อ่านอย่างเดียว) ได้บท 7 บรรทัด ~21 วิ · ~1.4 บาท · หน้าเว็บด้วย Chrome จริง จอคอม/มือถือ ไม่ล้นจอ ·
  ⚠️ ตัวทดสอบรอบแรกหาการ์ดแผนบนมือถือไม่เจอ — สถานะจำลองค้างจากรอบจอคอมที่กดอนุมัติไปแล้ว (บั๊กตัวทดสอบ)
