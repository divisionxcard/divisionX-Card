# เอนจิ้นฉากกราฟิกเคลื่อนไหว — จาก "สไลด์รูปถ่าย" สู่ motion design

โจทย์จากเจ้าของ (คำต่อคำ): *"อยากได้ระบบที่ AI ออกแบบเป็นอนิเมชั่นที่สวยงาม
ไม่ใช่แค่เอารูปภาพมาแปะเหมือน PowerPoint นำเสนองาน"* — ถูกที่สุด ต่อให้มี
ท่ากล้อง/ทรานสิชัน มันก็ยังเป็น "รูปถ่าย+กล้องขยับ"

## ไอเดียหลัก: เรามีเครื่องมือทำ motion design อยู่แล้วโดยไม่รู้ตัว

ซับไทยของเราเรนเดอร์ผ่าน Chromium (subtitle.py) เพราะเป็นทางเดียวที่จัด
สระ/วรรณยุกต์ถูก → **Chromium ตัวเดียวกันเรนเดอร์ "ทั้งฉาก" ได้** — CSS
animation ทำแสง เงา อนุภาค ของลอย ตัวอักษรโครเมียม ได้หมด แล้วถ่ายเป็น
เฟรมส่ง ffmpeg (แนวเดียวกับที่ Remotion ทำ แต่เขียนเอง ~200 บรรทัด ไม่มี
dependency ใหม่ ไม่ติดไลเซนส์)

## กติกาที่ทำให้มันเวิร์กจริง (อยู่ในหัว motion.py)

1. **เฟรมต้อง deterministic** — ไม่ปล่อยอนิเมชันวิ่งเรียลไทม์แล้วรัวชัตเตอร์
   แต่หยุดทุกอนิเมชันแล้ว "หมุนเข็มนาฬิกา" ด้วย Web Animations API
   (`getAnimations().forEach(a => a.currentTime = ms)`) ก่อนถ่ายทีละเฟรม
2. เทมเพลตใช้ **CSS animation เท่านั้น** (rAF/SMIL เข็มนาฬิกาหมุนไม่ถึง)
   และ**ห้าม Math.random** — อนุภาคใช้ mulberry32 seed คงที่
3. **เวทีคือกราฟิก สินค้าคือรูปถ่ายจริง** — img param ผ่าน visuals.resolve
   ตามหลักเดิม (โมเดลวาดสินค้าเรา = ได้ของปลอม)
4. **แคชด้วย hash(เทมเพลต+พารามิเตอร์+ความยาว)** — ถ่ายเฟรมคือส่วนช้าสุด
   (~40 วิ/ฉาก 2.5 วิ) วนแก้ซับ/เสียงกี่รอบก็ไม่เรนเดอร์ฉากซ้ำ

## เทมเพลตแรก 2 ตัว

- **intro** — สายฟ้าผ่ากลางจอ วาบแสง วงแหวนกระแทก ชื่อโครเมียม (แสงวิ่งผ่าน
  ตัวอักษรวนไป) — ใช้เป็น visuals ฉากแรก เสียงประโยคแรกเล่าทับ
- **showcase** — เวทีสินค้า: ซองจริงลอย+เอียง แสงนีออนหายใจ เงาพื้น
  ลำแสงเฉียง อนุภาคลอย สายฟ้าวาบเป็นจังหวะ พาดชื่อโครเมียม + ป้ายแคปซูล

ทั้งคู่ "loop-friendly": หลังช่วงเข้า (~1.4 วิ) เหลือแค่ไอเดิล — ฉากยาวเท่าไหร่ก็ดูดี

## เชื่อมระบบ

- spec ใหม่ `tpl:<ชื่อ>?img=&title=&tag=` ใช้ได้ทุกที่ที่ visual ใช้ได้
  (plan.visuals และ edit.scenes[i].visual) — CONTRACT.md อัปเดตแล้ว
- make_video: ฉาก tpl ข้าม zoompan/ท่ากล้อง (ขยับเอง) · visuals.prepare
  ถ่าย snapshot นิ่งให้ timeline/พรีวิว
- ห้องตัดต่อ: radio "ฉากกราฟิกเคลื่อนไหว ✨" ในแท็บฉาก — เลือกเทมเพลต
  + สินค้า + พาดชื่อ + ป้าย · ฉาก tpl ซ่อนตัวปรับท่ากล้อง

## ทดสอบ

- เรนเดอร์ cliptest ทั้งตัวโดยฉาก 0→intro, ฉาก 2→showcase: ผ่าน (compose 100 วิ
  รอบแรก — สองฉาก tpl ยังไม่มีแคช) · แกะเฟรมเห็นทั้งสายฟ้า/วงแหวน/ชื่อโครเมียม
  และเวที "อันดับ 1"+OP-17 พร้อมซับซ้อนถูกชั้น
- UI: radio ✨ ติดถูกฉาก · ช่องค่า prefill ตรง spec · ฉากรูปถ่ายได้ท่ากล้องคืน ·
  ไม่มี JS error
