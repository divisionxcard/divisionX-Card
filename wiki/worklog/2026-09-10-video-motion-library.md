# คลังลูกเล่นวิดีโอ — ท่ากล้อง 7 · ทรานสิชัน 12 · ซับเด้งเข้า

เจ้าของติ (ถูกต้อง): *"ระบบยังเป็นการเอาภาพมาเรียงกันซ้ำ ๆ จนจบคลิป
ไม่มีลูกเล่นอนิเมชั่นใหม่ ๆ เลย"* — ก่อนหน้านี้ทุกฉากคือซูมเข้ากลางภาพ 8%
+ เฟดตายตัว + ซับโผล่นิ่ง ๆ ทั้งคลิป

## เพิ่มอะไร (ffmpeg ล้วน ไม่มี dependency ใหม่)

1. **ท่ากล้อง 7 แบบ** (`compose._motion_exprs` — สูตร zoompan ต่อท่า):
   zoom-in · zoom-out · punch (พุ่งเร็ว 0.35 วิแล้วค้าง) · pan-lr/rl · drift-down/up
   — สวิตช์ `zoom = 0 = ภาพนิ่ง` ของเดิมยังชนะทุกท่า
2. **ทรานสิชัน 12 แบบ** — xfade ที่คัดว่าดูดีบน 9:16 · ชื่อนอกคลังถูกปัดกลับเป็น
   fade กัน ffmpeg ล้มเพราะค่าที่คนพิมพ์เองใน plan.json
3. **ซับ/พาดหัวลอยเด้งเข้า** — overlay y เป็นสูตรตามเวลา (ลอยขึ้น 16/24px ใน 0.18 วิ)
4. **ผู้กำกับอัตโนมัติ** (`make_video._auto_motion/_auto_transition`):
   เปิดเรื่องซูมเข้า · ฉากปิดถอยกล้อง · ภาพสินค้า punch สลับซูม · ภาพห้างแพนสลับทิศ
   · ทรานสิชันลูกเล่นคั่น "ทุกรอยต่อเว้นรอยต่อ" (ติดกันหมดดูวุ่นแบบมือสมัครเล่น)

## จุดออกแบบที่ต้องจำ

- **schema**: `plan.edit.scenes[i]` เพิ่ม `motion` / `transition` (ไม่ใส่หรือ
  `"auto"` = ผู้กำกับเลือก) — อัปเดต CONTRACT.md แล้ว
- **ตรรกะ auto ถูกกระจกสองฝั่ง**: python (make_video.py) ↔ JS (editorStore
  `autoMotion/autoTransition`) เพื่อให้พรีวิวสดตรงผลเรนเดอร์ — **แก้ฝั่งเดียวคือพัง**
  แผงฉากจึงโชว์ด้วยว่า "ฉากนี้ระบบเลือก: …" คนจะได้ไม่ต้องเดา
- พรีวิวประมาณทรานสิชันด้วย CSS keyframes (สไลด์/วงกลม/ปาด = clip-path ·
  radial/circleclose = เฟดแทน) — จังหวะกับทิศตรง ลวดลายละเอียดดูโหมด "ผลจริงล่าสุด"
- ท่าแพน/ไต่ต้องมีซูมค้างขั้นต่ำ 6% (`PAN_MIN_ZOOM` ทั้งสองฝั่ง) ไม่งั้นไม่มีเนื้อภาพให้กล้องเดิน

## ทดสอบ

- เรนเดอร์ cliptest ทั้งตัว ~23 วิ → แกะเฟรมดู: circleopen เห็นวงเปิดจริง ·
  แพนเห็นกล้องกวาด (สมอเรือโผล่ทั้งตัวระหว่างฉาก) · ความยาวตรงเสียงผ่านด่าน compose
- เบราว์เซอร์จริง: dropdown ครบ · เลือกแล้ว dirty ขึ้น · undo กลับเป็น auto ·
  transform แพนบนพรีวิว `scale(1.08) translateX(3.704%)` ตรงสูตร ·
  ชั้นภาพติดคลาส `tr_slideleft` ตอนข้ามรอยต่อ · ไม่มี JS error
- บั๊กที่เจอระหว่างทาง: `key={subIdx}` ชน `key={cur}` (sibling เลข 0 ทั้งคู่)
  → prefix เป็น `sub0`/`sc0`
