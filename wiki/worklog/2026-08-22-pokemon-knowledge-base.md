# คลังความรู้ Pokémon — และ metadata สินค้าที่ผิดมาตลอด

เจ้าของขอให้ทำแบบเดียวกับ [[2026-08-21-opcg-official-knowledge-base]] โดยส่ง
`th.portal-pokemon.com/card/` มา ซึ่งเป็นหน้า landing ลิงก์ไปตัวจริงคือ
**`asia.pokemon-card.com/th`** (robots.txt ว่างเปล่า · ทุกหน้าเป็น HTML จริง)

## สิ่งที่เจอก่อนได้ลงมือ — สินค้าเราไม่ใช่ภาษาที่ระบบบอก

ฐานข้อมูลระบุ SKU Pokémon ทั้ง 3 ตัวว่า `language='EN'` และ set_code `ME02/ME04/GHOST`

**เจ้าของส่งรูปซองจริงมาครบทั้ง 3 ซอง — ทุกซองเป็นภาษาญี่ปุ่น:**

| ซองจริง | รหัส | SKU |
|---|---|---|
| ハイクラスパック MEGA ドリームex · ランダム10枚入り | M2a | PKM Dream EX |
| 拡張パック ニンジャスピナー · ランダム5枚入り | M4 | PKM Ninja |
| 拡張パック アビスアイ · ランダム5枚入り | M5 | PKM Ghost |

จำนวนใบต่อซองบนซองตรงกับ `packs_per_box` ในระบบด้วย (10 ไฮคลาส · 5 ชุดเสริม) — ยืนยันซ้ำอีกชั้น

**ทำไมของเดิมอันตราย:** `ME02` กับ `ME04` เป็นรหัสจริงของ**ไลน์อังกฤษสากล**
(ME02 = Phantasmal Flames) ซึ่งเป็นสินค้าคนละตัว ใครมาอ่านทีหลังหรือ AI หยิบไปเขียน
จะได้ข้อมูลผิดโดยไม่มีสัญญาณเตือน

**ต้นตอ:** migration 034 กับ 045 ใส่ `language='EN'` เป็นค่า default ให้ทุกตัว
ไม่ใช่ข้อมูลจากซัพพลายเออร์ (สังเกตได้ว่า NRT มีตัวที่เป็น `'CN'` จริง = ฟิลด์นี้มีความหมาย)

แก้ผ่าน PostgREST เป็น `M2a/M4/M5` + `JA` — ตรวจก่อนแล้วว่าไม่มีใครอ่าน `set_code` ฝั่ง Pokémon
(`opcg_kb.py` กรอง `franchise=eq.OP` · `generate/route.js` ส่งเข้า knowledgeBlock เฉพาะตอน isOnePiece)

## ⚠️ ข้อจำกัดที่ทำให้คลังนี้ต่างจาก One Piece

เว็บทางการไทยเป็น **ไลน์ภาษาไทย** แต่ซองเราเป็น **ญี่ปุ่น** — เกมเดียวกันแต่คนละการพิมพ์

และที่สำคัญกว่านั้น **ไลน์ไทยรวมชุดญี่ปุ่นสองชุดเป็นชุดเดียว**:

```
ไทย MA5 "เงามืดคุกคาม" (164 ใบ) = M4 ニンジャスピナー (83) + M5 アビスアイ (81)
                                   = ซอง Ninja           = ซอง Abyss Eye
```

เราขายเป็น **2 สินค้าแยกกัน** แต่ข้อมูลไทยแยกไม่ออก และเลขการ์ดคนละระบบ (ไทย xxx/164 · ญี่ปุ่น xxx/120)

| ใช้ได้เต็มที่ | ห้ามใช้ |
|---|---|
| ชื่อการ์ดไทย · HP · ประเภท · ท่าต่อสู้ · ความสามารถ | เลขการ์ด · รหัสชุด |
| จุดอ่อน/ต้านทาน/หนี · วิวัฒนาการ · กฎการเล่น | บอกว่าใบไหนอยู่ซองไหน · บอกว่าลูกค้าจะเห็นชื่อไทยบนการ์ด |

ฝังเป็น `_language_warning` / `_set_warning` ใน JSON และเป็นคำเตือนท้ายทุกบล็อกที่ส่งเข้า prompt

## ไฟล์ที่ได้

| ไฟล์ | เนื้อหา |
|---|---|
| `pkm_cards.json` | **488 ใบ** 2 ชุด (MA5 238 · MA3 250) ดึงพลาด 0 |
| `pkm_rules.json` | **Q&A 1,077 ข้อ** — กฎทั่วไป 189 · คำวินิจฉัยเฉพาะการ์ด 888 · + สอนมือใหม่ 14 ย่อหน้า |
| `pkm_kb.py` | ตัวสร้าง · `--sets` `--list-sets` `--rules` `--all-sets` |
| `pkmKnowledge.js` | ตัวโหลด + แปลงรหัสญี่ปุ่น→ไทย + เลือกการ์ดเด่น + จับ Q&A ตามหัวข้อ |

ต่อเข้า `generate/route.js` แล้ว — เลือกบล็อกตาม franchise (OP / PKM) ไม่เกี่ยวก็คืนค่าว่าง

## บั๊กที่แก้ระหว่างทาง

**1. ชื่อการ์ดติดขั้นวิวัฒนาการมาด้วย** — `<h1>` มี `<span class="evolveMarker">` ซ้อนอยู่
ได้ "พื้นฐาน มาชิมาชิระ" แทน "มาชิมาชิระ" — ถ้าไม่จับ ชื่อการ์ดจะผิดทั้ง 488 ใบ

**2. Q&A ล้มทั้งงานเพราะหน้าเดียวพลาด** — เว็บตอบ 502 ที่หน้า 51 หลังไล่ 50 หน้ารวด
ตัวดึงเดิมทิ้งของที่เก็บมาแล้วทั้งหมด → แก้ให้บันทึกเท่าที่ได้พร้อมบอกว่าหยุดเพราะอะไร
และหน่วงนานขึ้นเฉพาะส่วนนี้ (รอบใหม่ไล่ครบ 57 หน้าไม่โดนแล้ว)

**3. นับการ์ดเกินจริง** — MA3 ลิสต์ 486 รายการแต่เลขการ์ดไม่ซ้ำแค่ 250
การ์ดใบเดียวกันถูกลิสต์หลายครั้ง (คนละ id คนละการพิมพ์) → ยุบเหลือใบจริง นับที่เหลือเป็น `printings`

**4. Q&A ที่ส่งเข้า prompt เป็นเคสซับซ้อนเกินไป** — 888 จาก 1,077 ข้อเป็นคำวินิจฉัยของการ์ดใบใดใบหนึ่ง
เช่น *"ถ้า ปิปปีex ของลิเลีย มี [แฟรี่โซน] ทำงานอยู่ จุดอ่อนจะ x4 ไหม"* ยาวมาก กินที่ในพรอมต์
และไม่ใช่สิ่งที่ลูกค้าถาม → แยก `kind` เป็น "กฎทั่วไป" กับ "คำวินิจฉัยเฉพาะการ์ด"
แล้วให้ตัวเลือกหยิบเฉพาะกฎทั่วไปเป็นค่าตั้งต้น

ผลต่างชัดเจน — ถามว่า "จุดอ่อนคืออะไร" ก่อนแก้ได้คำวินิจฉัย 4 ข้อที่อ่านไม่รู้เรื่อง
หลังแก้ได้ *"จุดอ่อน คืออะไร? → คือประเภทที่โปเกมอนตัวนั้นอ่อนแอต่อการโจมตี…"*

**5. คำถามติดบล็อก "การ์ดที่เกี่ยวข้อง"** — แยกออกเป็นฟิลด์ `related_cards`

## เรื่องที่ต้องระวังต่อไป

เจ้าของยืนยันว่า **ยังสั่งของญี่ปุ่นเข้ามาลงตู้อยู่** (24 ส.ค. 2026)

ถ้าวันหนึ่งเปลี่ยนไปลงของไทย (MA5 ออก 19 มิ.ย. ราคา 49 บาท/ซอง ถูกกว่าญี่ปุ่น):
- ข้อจำกัดเรื่องภาษาหายไปทั้งหมด ข้อมูลจะตรงเป๊ะ อ้างเลขการ์ดได้
- แต่ **Ninja กับ Abyss Eye จะกลายเป็นสินค้าเดียวกัน** ต้องยุบ SKU
