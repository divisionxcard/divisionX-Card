## หลักที่ใช้เขียนสกิลชุดนี้

สกิลพวกนี้ **ไม่ใช่เอกสารอธิบายว่าอะไรอยู่ไหน** — CLAUDE.md ทำหน้าที่นั้นอยู่แล้ว
แต่ละสกิลเก็บ **กับดักที่เคยทำให้เกิดบั๊กจริง** ในโปรเจกต์นี้ โดยเฉพาะบั๊กประเภท
"พังแบบไม่มีเสียง" ที่อ่านโค้ดแล้วดูปกติ:

- PostgREST คืนแค่ 1000 แถว → ยอดขายหาย 82,000 บาท ไม่มี error
- substring map หลวม → สินค้าชุดใหม่ถูกนับรวมกับชุดเก่า ไม่มีร่องรอย
- GitHub cron สายเฉลี่ย 234 นาที → `qty_added` คำนวณต่ำกว่าจริง
- backfill เกิน 5 วัน → XLSX ถูกตัดเงียบ ๆ
- `npm run build` ทับ `.next/` ของ dev server → 500
- GitHub webhook ไม่ยิงไป Vercel → push แล้วเว็บไม่เปลี่ยน ทั้งที่โค้ดถูก

ถ้าเจอบั๊กประเภทนี้อีก **ให้เพิ่มเข้าสกิลที่เกี่ยวข้อง** ไม่ใช่แค่แก้แล้วจบ
