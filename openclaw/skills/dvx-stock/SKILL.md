# สต็อกหน้าตู้ (รายช่อง)

ใช้เมื่อผู้ใช้ถามว่าตู้ไหนมีของอะไรเหลือเท่าไหร่ ช่องไหนว่าง หรืออยากดูผังของในตู้

ต่างจาก `dvx-restock` ตรงที่ skill นี้ตอบว่า **"ตอนนี้ในตู้มีอะไรอยู่"** (ข้อมูลดิบรายช่อง)
ส่วน `dvx-restock` ตอบว่า **"ต้องเติมอะไรก่อน"** (เอาความเร็วขายมาคิดด้วย)
ถ้าผู้ใช้ถามเชิงตัดสินใจว่าเอาอะไรไปเติม → ใช้ `dvx-restock`

## คำสั่ง

```bash
cd "c:/Projects/divisionX Card" && py deploy/agents/dvx_query.py stock [options]
```

| ต้องการ | คำสั่ง |
|---|---|
| ทุกตู้ เฉพาะช่องใกล้หมด | `stock --low` |
| ตู้เดียว ทุกช่อง | `stock --machine chukes01` |
| ตู้เดียว เฉพาะใกล้หมด | `stock --machine chukes01 --low` |
| ปรับเกณฑ์ใกล้หมด | `stock --low --low-threshold 3` |

- ไม่ใส่ `--machine` = ทุกตู้ · **ไม่ใส่ `--low` จะยาวมาก (ตู้ละ ~58 ช่อง)**
  ถ้าผู้ใช้ถามกว้าง ๆ ให้ใช้ `--low` ก่อนเสมอ แล้วค่อยเจาะเป็นรายตู้
- `--machine` รับ `machine_id` หรือคำค้นจากชื่อสาขา (เช่น `--machine ศาลายา`)

## ตอบผู้ใช้ยังไง

บรรทัดแรกของ output บอกว่าข้อมูล sync มาเมื่อไหร่ — **บอกผู้ใช้ด้วยเสมอ** เพราะเป็นข้อมูลถ่ายภาพนิ่ง
ไม่ใช่ real-time ถ้าขึ้น ⚠️ (เก่ากว่า 24 ชม.) ให้เตือน แล้วเสนอ skill `dvx-sync` เพื่อดึงใหม่

🔴 = ช่องว่างหมดแล้ว · 🟠 = ใกล้หมด · ตัวเลขคือ เหลือ/ความจุ

## ข้อควรรู้

- หน่วยคือ **จำนวนชิ้นในช่อง** — ช่องที่ชื่อสินค้ามีคำว่า "Box" นับเป็นกล่อง ไม่ใช่ซอง
  เวลาสรุปให้ผู้ใช้อย่ารวมกล่องกับซองเป็นตัวเลขเดียวกัน
- แสดงเฉพาะช่องที่ `is_occupied` = ช่องที่ตั้งสินค้าไว้ · ช่องที่ปิดใช้งานจะไม่ขึ้น
