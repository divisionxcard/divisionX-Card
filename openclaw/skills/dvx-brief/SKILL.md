# สรุปการตลาด + ร่างคอนเทนต์

ใช้เมื่อผู้ใช้ขอสรุปภาพรวมการตลาด ขอคำแนะนำว่าควรดันอะไร หรือขอไอเดีย/แคปชั่นสำหรับโพสต์

## เช็คก่อน: Ollama ต้องรันอยู่

skill นี้ใช้ LLM ในเครื่อง (ฟรี ไม่เสียค่า API) ถ้า Ollama ไม่ได้เปิดจะรันไม่ผ่าน

```bash
curl -s http://localhost:11434/api/tags
```

ถ้าต่อไม่ได้ → บอกผู้ใช้ให้เปิดแอป Ollama ก่อน อย่าไปเรียก API เจ้าอื่นแทนเอง

## คำสั่ง

```bash
cd "c:/Projects/divisionX Card"

# สรุปการตลาดรายสัปดาห์ (ดันอะไร แก้อะไร งบโฆษณา เติมด่วน)
py deploy/agents/weekly_marketing_brief.py --dry-run

# ร่างแคปชั่นจาก SKU ที่กำลังมา
py deploy/agents/content_suggester.py --dry-run --count 3
```

`--dry-run` สำคัญ — ถ้าไม่ใส่จะ **ส่งเข้ากลุ่ม Telegram การตลาดจริง** (และ content_suggester
จะเขียนไฟล์ `deploy/tasks/content_suggestions.json` ด้วย) ใส่เสมอ ยกเว้นผู้ใช้สั่งชัดว่าให้ส่ง

ตัวเลือกเสริม: `--model qwen2.5:14b` (ฉลาดขึ้น ช้าลง) · `--limit 5` (จำนวน SKU ต่อหมวด)

## ข้อมูลมาจากไหน

อ่าน insight ต่อ SKU ที่เก็บไว้ใน `wiki/skus/*.md` ซึ่งสร้างโดย `sku_profile_agent.py`
**ไม่ได้ดึงยอดขายสด** — ถ้าผู้ใช้บอกว่าข้อมูลดูเก่า ให้เสนอรีเฟรชก่อน (ใช้เวลาหลายนาที ต้องขออนุญาต):

```bash
py deploy/agents/sku_profile_agent.py
```

## ตอบผู้ใช้ยังไง

- brief เป็นภาษาไทยพร้อมใช้ — ส่งต่อได้เลย แต่ถ้ายาวมากให้สรุปหัวข้อหลักก่อน
- แคปชั่นที่ได้เป็น **ร่างให้คนรีวิว** ไม่ใช่ของอนุมัติแล้ว — บอกผู้ใช้ให้ตรวจก่อนเอาไปโพสต์เสมอ
- โทนแบรนด์คือ "เปิดซอง เปิดดวง" — ถ้าจะช่วยแก้แคปชั่นให้ ให้คงโทนนี้ไว้
