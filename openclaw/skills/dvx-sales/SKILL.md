# ยอดขาย DivisionX

ใช้เมื่อผู้ใช้ถามถึงยอดขาย รายรับ ตู้ไหนขายดี SKU ไหนขายดี หรือเทียบยอดระหว่างวัน

## คำสั่ง

```bash
cd "c:/Projects/divisionX Card" && py deploy/agents/dvx_query.py sales [options]
```

| ต้องการ | คำสั่ง |
|---|---|
| วันนี้ | `sales --days 1` |
| เมื่อวาน | `sales --date 2026-08-03` |
| 7 วันล่าสุด | `sales --days 7` |
| ช่วงที่ระบุ | `sales --from 2026-07-01 --to 2026-07-31` |
| ตู้เดียว | `sales --days 7 --machine chukes01` |
| SKU ไหนขายดี | `sales --days 7 --by sku --top 10` |
| แนวโน้มรายวัน | `sales --days 14 --by day` |

- `--machine` ใส่ `machine_id` (chukes01, wwv03, pf01) หรือคำค้นจากชื่อสาขาก็ได้ เช่น `--machine ชลบุรี`
  ถ้าคำค้นตรงหลายตู้ สคริปต์จะบอกว่ากำกวมพร้อมรายชื่อ → ถามผู้ใช้ว่าหมายถึงตู้ไหน
- `--by machine` (default) = แยกตามตู้ · `--by sku` = อันดับสินค้า · `--by day` = ไล่รายวัน
- ทุกวันที่เป็น **เวลาไทย** อยู่แล้ว ไม่ต้องแปลง timezone เอง
- ไม่รู้ว่ามีตู้อะไรบ้าง → `py deploy/agents/dvx_query.py machines`

## ตอบผู้ใช้ยังไง

output เป็นข้อความไทยพร้อมใช้อยู่แล้ว — สรุปให้สั้นลงได้ แต่ **อย่าแก้ตัวเลข** และคงหน่วยเดิม
(บาท / ซอง / ธุรกรรม) ถ้าผู้ใช้ถามกว้าง ๆ ว่า "ยอดขายเป็นไง" ให้เริ่มจาก `--days 7 --by machine`
แล้วเสนอเจาะต่อว่าอยากดูรายวันหรือราย SKU

## ข้อควรรู้

- ยอดขาย sync วันละครั้งตอนเที่ยงคืน (ยอด**เมื่อวาน**) → ถาม "วันนี้" มักได้ 0
  ถ้าเจอกรณีนี้ให้บอกผู้ใช้ตรง ๆ ว่ายังไม่ได้ sync แล้วเสนอใช้ skill `dvx-sync`
- ตัวเลข "ธุรกรรม" นับจาก `transaction_id` ที่ไม่ว่าง — บางตู้ไม่ส่งค่านี้มา ตัวเลขจึงต่ำกว่าจริงได้
  ถ้าผู้ใช้ถามเจาะเรื่องจำนวนบิล ให้ออกตัวข้อนี้ด้วย
- ตัวเลขนี้เป็น **รายรับก่อนหัก** ค่าธรรมเนียม payment gateway (VMS 1.5% · WorldWide 0.5%)
