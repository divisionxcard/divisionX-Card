# เตือนเติมสต็อก (Restock Guard)

ใช้เมื่อผู้ใช้ถามทำนองว่า "ต้องเติมอะไรบ้าง" "ตู้ไหนของหมด" "พรุ่งนี้เอาอะไรไปเติม"
"มีอะไรขาดไหม" หรือขอรายการเตรียมของก่อนไปเติมตู้

## คำสั่ง

```bash
cd "c:/Projects/divisionX Card" && py deploy/agents/restock_guard.py --dry-run
```

`--dry-run` สำคัญ — ถ้าไม่ใส่ สคริปต์จะ **ส่งข้อความเข้ากลุ่ม Telegram การตลาดจริง**
ให้ใส่เสมอ ยกเว้นผู้ใช้สั่งชัดว่า "ส่งเข้ากลุ่มเลย"

ปรับเกณฑ์ได้เมื่อผู้ใช้ขอให้เข้ม/ผ่อนกว่าเดิม:
- `--threshold-days 2` — เตือนล่วงหน้ามากขึ้น (default 1 วัน เพราะเติมได้วันละรอบตอนห้างปิด)
- `--min-velocity 1` — รวมของที่ขายช้าลงมาด้วย (default 2 ซอง/วัน)

## การอ่านผล

| สัญลักษณ์ | ความหมาย |
|---|---|
| 🔴 | หมดแล้ว — กำลังเสียยอดขายอยู่ตอนนี้ ต้องเติมก่อนเพื่อน |
| 🟠 | จะหมดภายในวันนี้ |
| 🟡 | เสี่ยงหมดก่อนรอบเติมถัดไป |

ถ้าไม่มีอะไรเข้าเกณฑ์ สคริปต์จะบอกว่า "ไม่มี SKU ฮิตเสี่ยงหมด" — ตอบไปตรง ๆ ว่าไม่ต้องเติมด่วน

## ตอบผู้ใช้ยังไง

output มี HTML tag (`<b>` `<i>` `&lt;`) เพราะเดิมเขียนไว้ส่ง Telegram — **ตัด tag ทิ้งก่อนตอบ**
แล้วเรียบเรียงเป็นรายการต่อตู้ ให้เรียง 🔴 ขึ้นก่อนเสมอ

ถ้าผลว่างเปล่าหรือขึ้นว่าไม่มี SUPABASE_URL ให้บอกว่าอ่าน `deploy/.env.local` ไม่ได้

## ข้อควรรู้

- คำนวณจาก **สต็อกหน้าตู้ที่ sync ล่าสุด** (วันละ 2 รอบ: 00:05 กับ 09:00 น.) เทียบกับ velocity 14 วัน
  → ถ้าเพิ่งเติมของไปแล้วยังไม่ sync ตัวเลขจะยังเป็นของเก่า ใช้ skill `dvx-sync` สั่ง sync ก่อนได้
- ดูของเหลือรายช่องแบบละเอียด → skill `dvx-stock`
