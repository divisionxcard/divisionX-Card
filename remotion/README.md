# ทำวิดีโอสั้นด้วยโค้ด (Remotion)

วิดีโอ 9:16 สำหรับ Reels / TikTok ที่ประกอบจาก **รูปสินค้าจริง + ข้อความจากเรา**
เรนเดอร์ด้วย Chromium จริง ตัวหนังสือไทยจึงถูก 100% เสมอ

## ทำไมต้องแยกโฟลเดอร์ ไม่รวมใน `deploy/`

`deploy/` คือแอปที่ Vercel ต้องติดตั้ง dependency ทุกครั้งที่ deploy
Remotion มาพร้อม Chrome Headless Shell ~113 MB ซึ่งไม่มีประโยชน์บนเซิร์ฟเวอร์เว็บ
และจะทำให้ build ช้าลงกับกินโควตาฟรีโดยเปล่าประโยชน์ — งานเรนเดอร์วิดีโอทำในเครื่องอยู่แล้ว

> โฟลเดอร์ `Video/` (ตัว V ใหญ่) คนละอันกัน — นั่นเก็บไฟล์วิดีโอดิบและถูก gitignore ไว้

## ⚠️ เรื่องลิขสิทธิ์ที่ต้องรู้ก่อนใช้เชิงพาณิชย์

Remotion **ไม่ใช่โอเพนซอร์สเสรี** — ใช้ฟรีสำหรับบุคคลและบริษัทที่มีพนักงานไม่เกิน 3 คน
ถ้าบริษัทโตกว่านั้นต้องซื้อ company license ดูเงื่อนไขปัจจุบันที่ remotion.dev/license

## ใช้ยังไง

```bash
cd remotion

npm run studio        # เปิดหน้าตัดต่อในเบราว์เซอร์ — แก้แล้วเห็นผลทันที
npm run compositions  # ดูรายชื่อคลิปทั้งหมด
npm run render -- src/index.ts PackReveal out/clip.mp4
```

เรนเดอร์คลิป 6 วินาที 1080×1920 ใช้เวลาราว **10 วินาที** บนเครื่องนี้

ภาพนิ่งเฟรมเดียว (ไว้เช็กงานเร็ว ๆ ไม่ต้องรอเรนเดอร์ทั้งคลิป):
```bash
npx remotion still src/index.ts PackReveal out/frame.png --frame=60
```

## โครงไฟล์

```
src/index.ts        จุดเริ่ม — ลงทะเบียน root
src/Root.tsx        ทะเบียนคลิปทั้งหมด (เพิ่มคลิปใหม่ที่นี่)
src/PackReveal.tsx  คลิปตัวอย่าง: ซองลอยขึ้นพร้อมสายฟ้า แล้วขึ้นพาดหัว
remotion.config.ts  ตั้งค่าการเข้ารหัสวิดีโอ
```

## กติกาที่ต้องรักษา (เหมือนฝั่งโปสเตอร์)

- **ใช้รูปซองจริงจากคลังเท่านั้น** (`sku-images` บน Supabase) ห้ามให้ AI วาดซองขึ้นมาเอง
  เคยเจอแล้วว่าโมเดลภาพเปลี่ยนสีซองและทำโลโก้ BANDAI เพี้ยน
- **ตัวเลขทุกตัวมาจากฐานข้อมูล** ไม่ใช่พิมพ์มือ
- อัตลักษณ์ภาพ: ฟ้านีออนไฟฟ้า + สายฟ้า + โครเมียม บนกรมท่า — **ไม่ใช่ดำ-ทอง**

## ยังไม่ได้ทำ

- ฟอนต์ไทยยังใช้ฟอนต์ระบบ (Segoe UI/Tahoma) ถ้าจะให้ตรงแบรนด์ควรฝังฟอนต์เองด้วย `@remotion/fonts`
- ยังไม่ได้ต่อกับฐานข้อมูล — ตอนนี้ส่งข้อความ/รูปผ่าน `defaultProps` ด้วยมือ
  ขั้นถัดไปคือดึงจาก `marketing_content` เหมือนที่ `poster_render.py` ทำ
