# โรงงานวิดีโอสั้น DivisionX

สคริปต์ข้อความ → คลิป 9:16 พร้อมโพสต์ (เสียงพากย์ไทย + ซับตรงเสียง + ภาพจริงของเรา)

```bash
py deploy/agents/video/make_video.py --plan แผน.json
```

---

## ทำไมถึงสร้างเอง

9 ก.ย. 2026 ทดลอง **Hero AI Creator Studio** กับสคริปต์จริงของเรา ผลคือ:

| สิ่งที่มันทำได้ดี | สิ่งที่มันทำไม่ได้ |
|---|---|
| เสียงพากย์ไทย · ซับตัดคำถูก · ประกอบคลิป | **ภาพ** — ได้ `modern hospital lobby`, `patient receiving prescription hand` มาทั้งคลิป |

ตัวแปลงคำค้นตีความ **"ซอง" เป็นซองยา** และ **"ตู้" เป็นเครื่องจ่ายยา** ส่วนภาพที่ AI
วาดเองก็ได้ตู้น้ำอัดลมกับผู้ชายใส่สูท

**คลังสต็อกกับโมเดลทั่วไปไม่รู้จักสินค้าเรา** และการ์ดจอที่ใหญ่ขึ้นก็แก้ไม่ได้ —
สิ่งที่แก้ได้คือรูปถ่ายของจริง ซึ่งเรามีอยู่แล้ว

## หลักการเดียวกับ poster_render.py

```
รูปถ่ายจริง → ตู้ ซอง กล่อง          ของที่ไม่มีใครมีนอกจากเรา
FLUX บนเครื่อง → ฉาก แสง บรรยากาศ    ห้ามให้วาดสินค้า เดี๋ยวได้ของปลอม
Chromium     → ตัวอักษรไทยทุกตัว     ถูก 100% ทั้งสระซ้อนและวรรณยุกต์
ffmpeg       → เวลา การเคลื่อนไหว เสียง
```

⚠️ **ห้ามให้ ffmpeg/libass วาดซับไทยเอง** — สระบน สระล่าง วรรณยุกต์ต้องซ้อนกัน
ถ้า shaping ผิดจะเลื่อนหรือทับแบบที่ตาเห็นทันทีแต่โปรแกรมไม่ฟ้อง
โปรเจกต์นี้โดนบั๊กตัวอักษรไทยมาแล้วหลายรอบ (U+0E3A ทำยอดนับผิด 31 รายการ)

## ไฟล์แผน

สิ่งเดียวกับที่หน้าเว็บจะ POST มาในอนาคต — ตั้งใจให้ไม่ต้องเขียนตรรกะซ้ำสองที่

```json
{
  "project":  "op17-intro",
  "script":   "บรรทัดแรก\nบรรทัดสอง",
  "visuals":  ["machine:hero", "sku:OP 17", "file:C:/ถ่ายเอง/กดตู้.jpg"],
  "headline": "ข้อความค้างบนจอช่วงต้น",
  "voice":    "Aoede",
  "style":    "brand",
  "music":    null,
  "xfade":    0.35
}
```

**1 บรรทัด = 1 ฉาก** (กติกาเดียวกับ Hero AI ที่เจ้าของคุ้นมือ)

⚠️ ทุกบรรทัดถูกอ่านออกเสียง — emoji แฮชแท็ก และวงเล็บกำกับฉากจะถูกตัดทิ้งอัตโนมัติ
ไม่ใช่แค่เตือน เพราะถ้าปล่อยผ่านจะได้เสียงอ่านว่า "แฮชแท็กวันพีซทีซีจี"

### แหล่งภาพ

| spec | ได้อะไร |
|---|---|
| `file:C:/path/รูป.jpg` | **ดีที่สุด** — ที่ถ่ายเองจากตู้จริง |
| `machine:hero` / `machine:scene` | รูปตู้จริงที่ถ่ายไว้แล้วใน `deploy/public/machine/` |
| `sku:OP 17` | รูปซอง/กล่องจริงจาก Supabase (ได้สิทธิ์ใช้แล้ว) |
| `flux:คำสั่งวาดฉาก` | FLUX วาดบนเครื่อง — **ใช้วาดฉากเท่านั้น ห้ามวาดสินค้า** |

## ขั้นตอนภายใน

| ขั้น | ทำอะไร | เวลา (คลิป 45 วิ) |
|---|---|---|
| 1 | แบ่งสคริปต์เป็นฉาก | ทันที |
| 2 | Gemini TTS อ่านรวดเดียว | **~3-4 นาที** ← ช้าสุด |
| 3 | whisper จับเวลารายคำ | ~30 วิ (ครั้งแรกโหลดโมเดล ~1GB) |
| 4 | เตรียมภาพเป็น 9:16 | ~3 วิ |
| 5 | Chromium เรนเดอร์ซับ | ~6 วิ |
| 6 | ffmpeg ประกอบ | ~35 วิ |

**อ่านเสียงรวดเดียวทั้งสคริปต์ ไม่ใช่ทีละบรรทัด** เพราะ TTS ต้องเห็นประโยคถัดไป
ถึงจะวางน้ำเสียงกับจังหวะหายใจถูก แล้วค่อยใช้ whisper หาว่าบรรทัดไหนอยู่วินาทีใด

ทุกขั้นมีแคช — แก้ภาพไม่ต้องจ่าย TTS ใหม่

## กับดักเรื่องเวลาที่พลาดง่ายสุด

`xfade` ทำให้คลิปรวม**สั้นลง** `(n-1) × ระยะเกย` ถ้าไม่ชดเชย ซับกับเสียงจะค่อย ๆ
เลื่อนออกจากกันจนท้ายคลิปหลุดเป็นวินาที — `make_video.py` จึงต่อเวลาแต่ละฉากเกินมา
เท่าระยะเกย แล้ววาง offset ที่ "เวลาเริ่มของฉากถัดไป" ผลคือความยาวรวมเท่าเสียงพากย์เป๊ะ

## ต้องมีอะไรบ้าง

- **ffmpeg + ffprobe** ใน PATH หรือที่ `%LOCALAPPDATA%\ffmpeg\ffmpeg-*/bin`
- **`.venv-image`** — torch (CUDA), faster-whisper, playwright **1.44.0**
  (ต้องตรงรุ่นกับ chromium ที่โหลดไว้แล้ว รุ่นใหม่กว่าจะขอโหลดเบราว์เซอร์ใหม่)
- **GEMINI_API_KEY** ใน `deploy/.env.local`
- การ์ดจอไม่บังคับ — ไม่มีก็ตกไปใช้ CPU หรือสั่ง `--no-align` ได้

## สั่งงานผ่านเว็บ

```
หน้า /video  →  POST /api/video/render  →  แถวใน video_jobs (queued)
                                        →  workflow_dispatch video-render.yml
                                                    ↓
                            runner: publish.py claim → build → upload → done
                                                    ↓
                          หน้าเว็บ poll /api/video/jobs?id= จนขึ้น done แล้วเล่นคลิปได้เลย
```

| ชิ้น | ไฟล์ |
|---|---|
| ตารางคิว | `backend/database/migrations/075_video_jobs.sql` |
| ตัวรันบน runner | `publish.py` (`python -m agents.video.publish --job <id>`) |
| workflow | `.github/workflows/video-render.yml` |
| API | `deploy/app/api/video/{render,jobs}/route.js` |
| หน้าเว็บ | `deploy/app/video/page.jsx` + `deploy/components/VideoStudio.jsx` |
| เพลง | `music.py` + `deploy/tasks/video_music.json` |

**เรนเดอร์บน GitHub Actions ไม่ใช่ Vercel** ด้วยเหตุผลเดียวกับ `poster-render.yml`
(ซับไทยต้องให้ Chromium จริงวาด · คลิปหนึ่งตัวยาวเกิน serverless ทุกแบบ)

⚠️ **runner ไม่มีการ์ดจอ** → `flux:` วาดไม่ได้ และ `file:C:\...` ก็ไม่มีบน ubuntu
ใช้ได้แค่ `machine:` / `sku:` / ไฟล์ที่อยู่ในรีโป · whisper ตกไปรันบน CPU (ช้ากว่าแต่ได้)

secrets ที่ต้องมี — มีอยู่ในรีโปครบแล้วทั้งหมด: `GEMINI_API_KEY` `SUPABASE_URL` `SUPABASE_SERVICE_KEY`

## ห้องตัดต่อ (`/video/editor` — เฉพาะเครื่อง dev)

แก้คลิปที่เรนเดอร์แล้วแบบเห็นผลทันที: ซับรายใบ · จุดตัดฉาก · สลับ/เปลี่ยนภาพ ·
Ken Burns ต่อฉาก · พาดหัว · สไตล์ซับ · โลโก้ — แล้วกดเรนเดอร์ใหม่จากในหน้า

```
.video-work/<project>/  ←→  /api/video/local/*  ←→  หน้า /video/editor
   plan.json ("edit")         (dev เท่านั้น)          (แก้ → เรนเดอร์ซ้ำ ~30 วิ)
```

- ทุกการแก้คือ `plan.edit` — สัญญาอยู่ใน `deploy/components/editor/CONTRACT.md`
- **ผู้กำกับอัตโนมัติ**: ท่ากล้อง 7 แบบ (ซูมเข้า/ออก · punch · กวาดซ้าย-ขวา · ไต่ขึ้น-ลง)
  + ทรานสิชัน 12 แบบ เลือกให้เองตามบทบาทฉาก (เปิดซูมเข้า ปิดถอยกล้อง ของเน้น punch
  ภาพห้างแพน · ลูกเล่นคั่นทุกรอยต่อเว้นรอยต่อ) — override รายฉากได้จากแท็บ "ฉาก"
  · ซับ/พาดหัวลอยเด้งเข้า ไม่โผล่นิ่ง ๆ · คลังท่าอยู่ `compose.py` (MOTIONS/TRANSITIONS)
- **ฉากกราฟิกเคลื่อนไหว** (`motion.py` + `motion_templates/*.html`): ออกแบบฉากเป็น
  HTML/CSS animation แล้วให้ Chromium ถ่ายทีละเฟรมแบบ deterministic → ffmpeg ประกอบ
  · spec: `tpl:showcase?img=sku:OP 17&title=อันดับ 1&tag=...` — เวทีคือกราฟิก
  แต่สินค้าเป็นรูปถ่ายจริงเสมอ · เทมเพลตแรก: `intro` (สายฟ้าแบรนด์) + `showcase`
  (เวทีสินค้านีออน) · แคชด้วย hash — แก้ซับ/เสียงไม่ต้องเรนเดอร์ฉากซ้ำ
  · กติกาเทมเพลต: CSS animation เท่านั้น (ห้าม rAF/SMIL) + PRNG seed คงที่
- **ซับคาราโอเกะ** (`sub_style.karaoke` · สวิตช์อยู่แท็บ "ซับ"): ไล่สีตามคำที่พูดไปแล้ว
  โดยใช้เวลารายคำจาก whisper ที่เก็บไว้ใน `words.json` (ผูกกับ stamp ของเสียง)
  · รอบแก้ที่ข้าม whisper ยังไล่สีตรงจังหวะได้เพราะอ่านจากแคชนี้
  · ไม่มีเวลารายคำ → ถอยไปไล่ทีละ ~4 อักขระแบบเฉลี่ย (ยังดูเป็นคาราโอเกะ)
  · แลกด้วยเวลาเรนเดอร์ซับที่นานขึ้น (คลิป 21 วิ → ซับ 12 ใบกลายเป็น 144 เฟรม ~25 วิ)
- **แท็บ "เสียง"**: เลือกเสียงพากย์ 5 เสียง + อารมณ์การอ่าน (`voice_style` — ทดสอบกับ
  ไทยแล้ว 10 ก.ย. 2026: ไม่อ่านตัวคำสั่งออกเสียง และจังหวะอ่านเปลี่ยนตามจริง)
  · เปลี่ยนเสียงแล้วเรนเดอร์ = TTS ใหม่ และตัวเรนเดอร์**ทิ้ง edit.timing/subtitles
  ให้เองอัตโนมัติ** (จังหวะอ่านเปลี่ยน เวลาที่แก้มือกับเสียงเก่าใช้ไม่ได้ — จับใหม่ด้วย whisper)
- `edit.timing` ทำให้ข้าม whisper → รอบแก้-เรนเดอร์เร็ว (เสียงก็แคชอยู่แล้ว)
- **"เสียงคือนาฬิกา ภาพคือผู้ตาม"** — สลับฉากคือสลับภาพ เสียงเล่าเรียงเดิมเสมอ
- พรีวิวประกอบสดจาก `frames/` + `voice.wav` + ซับ HTML — ไม่ใช่ mp4
  (mp4 เบิร์นซับไปแล้ว ซ้อนกันจะเห็นซับสองชั้น)
- รันบน Vercel ไม่ได้โดยออกแบบ — `/api/video/local/*` ตอบ 404 บน production
