# รูปตู้จริง — ใช้ในโปสเตอร์

ตัวสร้างโปสเตอร์ (`deploy/agents/poster_render.py`) จะหยิบไฟล์ในโฟลเดอร์นี้ไปใช้

| ไฟล์ | ใช้ทำอะไร | รูปแบบที่ควรใช้ |
|---|---|---|
| `machine-hero.jpg` | ตัวตู้เป็นพระเอกในภาพ | ถ่ายตรง เห็นสินค้าเต็มตู้ แสงสว่าง |
| `machine-scene.jpg` | พื้นหลังบรรยากาศ (เบลอ+หรี่) | ถ่ายเฉียง เห็นบรรยากาศห้างรอบตู้ |

ไม่มีไฟล์ก็ไม่พัง — โปสเตอร์จะใช้พื้นกรมท่าไล่สีแทน

**ต้อง commit เข้า repo** เพราะตัวเรนเดอร์รันบน GitHub Actions ซึ่ง checkout จาก repo
(อย่าใหญ่เกิน ~500KB ต่อไฟล์ ย่อก่อนใส่ได้)
